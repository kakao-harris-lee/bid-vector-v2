# 문면 게이트의 **금지 꼴** — 이 파일이 한 자리다(M13/13A · 팀장 착수 판정 2026-11-18).
#
# 운영자가 보는 글자에 개발 코드가 있는지 판정하는 정규식의 정본이다. 두 층이 **같은 바이트를
# 읽는다** — 소스 층(`scripts/screen-copy-vocabulary.test.mjs`)과 렌더 층
# (`src/screens/screenCopy.test.tsx`). 사본을 두지 않으려고 데이터 파일로 뺐다: 렌더 층은
# `src/**` 안에 살아야 하고(DOM 을 그린다) 소스 층은 저장소 문서를 읽어야 해서(capability map)
# 두 층이 한 모듈을 import 할 수 없다 — `gate:src-tree`(W-4)가 `src` 밖 import 를 막는다.
#
# **판정은 꼴이 한다.** 등록부(capability map §0.6 접두사 표 + OPEN ID 전수)는 「이 꼴들이 실제
# ID 를 덮는다」는 **포함 단언**에만 쓴다. 계약 문면의 「등록부 ∪ 꼴」을 이렇게 좁힌 근거는
# `reports/evidence/m13/ux-copy/design-review.md` (1) 과 팀장 착수 판정에 있다 — 등록부를 금지
# 집합으로 쓰면 유도 집합이 **줄어드는** 우회(§0.6 에서 접두사 한 줄을 지우거나 바꿔치우는 것)에
# 열린다. 포함 단언은 그 방향에서 붉는다.
#
# 형식: 한 줄에 `<이름> :: <정규식 source>`. `#` 로 시작하는 줄과 빈 줄은 무시한다. 각 줄은
# `new RegExp(source, 'gu')` 로 컴파일된다 — 플래그를 줄에 적지 않는다(두 층이 같은 플래그를
# 쓰는 것이 이 파일의 요점이다).
#
# 줄을 더하거나 고치면 **음성 대조**(두 층 모두에 있다)를 함께 본다. 좁히는 변이는 포함 단언이
# 잡고, 넓히는 변이는 음성 대조가 잡는다.

# capability ID 와 같은 꼴 **전수**. 접두사 목록에 기대지 않는다 — 두 글자 이상 접두 + 번호.
# 음성: D-day `D-0`·`D-14`(한 글자 접두) · 합성 공고번호 `SYN-M9-0`(`M9` 뒤가 숫자가 아니다).
대문자 접두 ID :: \b[A-Z]{2,}-\d+\b

# OPEN ID. 끝을 열어 둔다(`OPEN-M9-DDAY-CALENDAR` 처럼 토막이 여럿이다).
OPEN ID :: OPEN-[A-Z0-9][A-Z0-9-]*

# 마일스톤/slice 표기. **슬래시가 가른다** — 합성 공고번호 `SYN-M9-0` 이 음성 대조다.
마일스톤 표기 :: M\d+/

# 결정 ID. **둘째 하이픈이 가른다** — D-day `D-0`·`D-1`·`D-14` 가 음성 대조다.
결정 ID :: \b[DR]-[0-9A-Za-z]+-[0-9A-Za-z]+\b

# 요구표 행 ID. 음수 금액이 이어 붙으면 가짜로 서는 꼴이라(「…R」 + 「-4,000원」) 렌더 층은
# 텍스트 노드 단위로 읽는다 — 그 대조가 두 층 모두에 있다.
요구표 행 ID :: R-\d\b
