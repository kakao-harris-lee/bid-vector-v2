# `config/quality/gate-tests.properties`).
#
# 여기 적힌 test 파일은 W-7(`npm run gate:tests`)이 **실행 결과**로 단언한다: W-6 가 실제로 돌리는
# 명령에 JSON reporter 를 붙여 돌린 뒤, 그 결과에 이 파일이 있고 passed ≥ 1 · skipped 0 · todo 0 ·
# failed 0 인지 본다. 설정 문자열(AST 의 `include` 리터럴)로는 수집 여부가 서지 않았다 —
# `test.exclude` 한 줄 · 미끼 `include` 속성 · `describe.skip` · `package.json` 의 CLI 경로 필터가
# 모두 그 단언을 지나면서 게이트 test 를 수집에서 뺐다(실측).
#
# 형식: 한 줄에 `web/` 기준 상대 경로 하나. `#` 로 시작하는 줄과 빈 줄은 무시한다.
