# M14 / wf-today-start (14B) — 처분과 근거

계약 `milestone-14.md` 의 14B 행과 대조표 B·A 행, M13 잔여 둘의 처분이다. 착수 실측의 수치는
`commands.md` 가 정본이고 여기 옮겨 적지 않는다.

## 계약 14B 행

| 항목 | 처분 | 근거 (실측) |
| --- | --- | --- |
| 머리 요약(「감시 조건 통과」 · 분모 `total`) | **정렬** | 이름이 「감시 조건 통과」이고 분모는 서버의 `total` 이다. 분자(곧 마감)는 **상한을 넘지 않을 때만** 붙는다 — 분자는 받은 행에서만 셀 수 있어 한 문장에 걸면 보지 못한 건까지 센 척한다. 짝 test 가 두 방향을 잠그고 변이 M5 가 가드를 지운다 |
| 상한 초과 공시 유지(M13 잔여 ⓐ) | **유지** | 머리 요약과 **함께** 선다(짝 test). 그 공시는 「통과 n건 · 지금 m장」 + 설정 링크 그대로다 |
| 칩은 인자에 닿는 것만 | **정렬** | 축 셋은 **이미 전부** 서버 파라미터였다. 「전체」만 더했다(뜻은 이미 있는 `clearAll` · 새 인자 0 · 새 정책 상수 0). 구간 프리셋은 더하지 않았다(13E 가 적은 사유 그대로) |
| 카드 재배치 | **정렬 + 칸 하나 데이터로 막힘** | 제목과 판정이 한 줄, 사실 줄이 「기관 · 기초금액」 한 줄, 오른쪽에 D-day 와 담기. **「방식」은 그리지 않는다** — 응답 스키마에 칸이 없다 |
| 모바일 압축 카드 | **정렬** | 좁은 폭에서 압축 금액이 서고 사실 줄은 숨는다(와이어프레임의 그 자리). 정확 금액 노드는 **건드리지 않았다** |
| 압축 금액 꼴(신설) | **정렬** | 「약」 표지 · **내림** · 카드에서 정확 금액에 닿는 길(2층 라벨 아래층) · 금액 어휘 키 증분 0. 셈은 정수 연산만 지난다(부동소수 나눗셈은 경계에서 위로 튀고 그 튐이 곧 올림이다) |
| 검색 결과 카드의 자격(범위 밖 승계) | **범위 밖 + 상태 문면** | 「제안 목록에서만 판정합니다」. **빈 자리로 두지 않는 것**이 요점이다 — 빈 자리는 「판정했고 통과」로 읽힌다(변이 M7) |
| 시작하기 번호 절 다섯 | **정렬** | 와이어프레임의 다섯 신원 그대로이고 **쓰기 단위는 바뀌지 않았다**(팀장 판정 ①). 절 3 이 네 단계를 「한 곳에서」 담는다. 여정 spec 의 앵커 전부 생존 |
| 상태 알약 | **정렬** | 쓰기 절의 알약은 **그 절 항목들의 가장 약한 상태**다(새 어휘 0 · 판정은 서버의 세 목록). 준비 중 알약은 절이 **선언**한다 |
| 레일 「지금 맞는 공고 미리보기」 | **정렬** | 기존 제안 질의 그대로(새 operation 0 · 새 인자 0). 비는 이유는 서버 상태 표가 말한다. 보이는 것보다 많으면 그 사실과 오늘의 공고로 가는 길을 준다 |
| M13 잔여 ⓗ(홈 기본 상태) | **닫힘(측정)** | 한 행 안에서 **두 상태**를 돈다. 변이 M13 이 기본 상태에만 서는 컨트롤을 잡는다 — 앞 판 게이트는 그것을 **볼 수 없었다** |

## 게이트 — 이 slice 가 세우거나 넓힌 것

| 축 | 무엇을 막나 | 비공허 | 양성 대조 |
| --- | --- | --- | --- |
| 압축 금액의 내림·표지 | 없는 돈을 보이는 것 · 버린 자리를 숨기는 것 | 자리 이름이 한글 금액 표와 **같은 집합**인지 센다 | M1 · M2 |
| 압축의 정확 금액 경로 | 근사만 남고 정확 금액에 닿는 길이 사라지는 것 | 아래층 노드를 **id 로 찾아** 글자를 읽는다 | M3 |
| 머리 요약의 상한 가드 | 보지 못한 건까지 센 척하는 것 | 분모·분자 두 수를 따로 단언한다 | M4 · M5 |
| 자격 슬롯 | 빈 자리가 「통과」로 읽히는 것 | 제안 카드에는 그 문면이 **없음**도 함께 단언 | M7 |
| 준비 중 절 | 약속·입력칸을 그리는 것 | 절마다 따로 센다(한 상자로 재면 셋이 서로를 가린다) | M8 |
| 절 알약 | 서버 판정 아닌 수를 보이는 것 | 미완·완료 두 방향 | M9 |
| 배치 게이트 레일 축(넓힘 · 스모크) | 세션 없이 그려지는 출하 레일이 **측정 밖**에 있는 것 | 본 레일 계수 ≥ 1 | M11 · M12 |
| 레일 축(신설 · 여정) | **데이터가 있어야 서는** 레일이 측정 밖에 있는 것 | 폭마다 따로 센 계수 ≥ 1 | M14 · M15 |
| 터치 게이트 홈 두 상태(넓힘) | 기본 상태의 컨트롤이 측정 밖인 것 | 칸마다 하한이 전수 단언 **앞**에 선다 | M13 |

## 이 slice 가 남기는 OPEN 후보

| OPEN 후보 | 무엇이 열려 있나 |
| --- | --- |
| ⓐ 「조건 지우기」와 「전체」 칩이 **같은 일**을 한다 | 걷으려면 등재된 게이트 test 의 주장 둘을 바꿔야 해서 승인 경계다. 오늘 해는 없고 중복만 남는다 |
| ⓑ 레일 축의 비공허 하한이 **둘 다 1 이다** | 14C·14D 가 레일을 붙이면 그 수를 올려야 하는데, 올리는 것은 그 레인의 일이고 이 slice 가 강제할 자리가 없다(계수가 늘어도 하한은 1 로 통과한다) |
| ⓒ 「곧 마감」의 경계가 **화면의 값**이다 | 서버가 선언한 축이 아니다(주 경계도 날 수도 계약에 없다). 짝 test 가 방향을 잠그지만 값 자체는 이 화면의 정책이다 |
| ⓓ 모바일 카드가 **기관을 싣지 않는다** | 와이어프레임의 선택이다. 기관은 제목을 눌러 워크시트에서 본다 — 좁은 폭에서 그 사실이 보이지 않는다 |
| ⓔ 레일 미리보기의 줄 수가 **화면의 값**이다 | 제안 operation 에 쪽·정렬 인자가 없어 곁다리 크기를 화면이 정한다. 전체는 오늘의 공고가 든다 |
| ⓕ 금액 부속 문면이 **basis 를 두 번** 말한다 | 라벨 「기초금액」과 provenance 글자의 첫 토막이 같다. 이 slice 가 만든 것이 아니고(M9 D-3 의 조립), 건드리면 표시 계약을 바꾸는 일이다 |
