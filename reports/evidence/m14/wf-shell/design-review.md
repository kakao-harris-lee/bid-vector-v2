# M14 / wf-shell (14A) — 설계 검토 (Phase 2.5)

계약 `milestone-14.md` 「게이트」 절의 셋을 검토한다 — **배치 단언 · 부재값 · 대비**. 순서는
하네스가 정한 (0) 위협 모델 경계 → (1) 열거인가 구성인가 → (2) 우회 ≥ 5 → (2b) 값 획득 축 →
(3) 과잉·미달이다. 수정 라운드마다 (2b) 를 갱신한다.

---

## (0) 위협 모델 경계

**세 게이트가 막는 것은 「운영자가 화면을 믿게 만드는 거짓」이다.** 공격자는 없다. 상대는
**다음 라운드의 나와 14B·14C·14D 레인**이고, 그들이 좋은 뜻으로 빠르게 고칠 때 게이트가
조용히 눈을 감는 자리를 막는다.

| 게이트 | 거짓의 모양 | 경계 **안** | 경계 **밖** |
| --- | --- | --- | --- |
| 배치 | 「와이어프레임대로 섰다」고 보고했는데 좁은 화면에서 레일이 본문을 가리거나 가로로 넘친다 | 출하 번들의 **상자 좌표** | 미적 판단(여백·굵기) · 서체 |
| 부재값 | 「없다」와 「아직 모른다」가 같은 얼굴이라 운영자가 0 건으로 읽는다 | 부재를 **낳는 타입**과 그것을 그리는 길 | 서버가 왜 그 칸을 비웠는가(14E · 범위 밖) |
| 대비 | 토큰을 와이어프레임 값으로 갈아 끼웠는데 읽을 수 없는 쌍이 생긴다 | `index.css` **그 파일의** 토큰 값 | 컴포넌트가 어느 토큰을 고르는가(그 축은 짝 test) |

**세 게이트 모두 「선언을 읽는 층」이 아니라 「거동을 재는 층」에 선다.** 배치는 브라우저의
상자, 부재값은 렌더한 DOM 과 전수 훑기, 대비는 출하 CSS 파일의 파싱이다.

## (1) 열거인가 구성인가

| 게이트 | 축 | 열거/구성 | 근거 |
| --- | --- | --- | --- |
| 배치 | 화면 모집단 | **구성** | 기존 자리 표(`routes.tsx`) ↔ 화면 표 등식이 이미 서 있다. 새 목록을 만들지 않고 그 등식에 얹는다 |
| 배치 | 레일 모집단 | **구성** | 「두 단을 세우는 컴포넌트가 단 표지」를 DOM 에서 전수로 집는다. 화면 이름을 적지 않으므로 14B·14C·14D 가 레일을 붙이면 **그 순간 모집단에 든다** |
| 부재값 | 금지 어휘 | **구성 + 차감 하나** | 전수 훑기(`src`·`e2e`·`scripts`)에서 생성 타입 한 디렉터리만 뺀다. 그 차감의 사유는 계약이 적었다(승인 경계) |
| 부재값 | 사유 모집단 | **열거(닫힌 표)** | 사유는 **유한하고 선언적**이다. `as const satisfies Record<Reason, …>` 라 사유가 늘면 표가 컴파일에서 멈춘다 — 열거가 낡는 자리가 아니다 |
| 대비 | 쌍 모집단 | **구성** | 파일에서 `--color-*-skin` 을 훑어 짝 `*-ink` 를 유도한다. test 에 쌍 목록을 적지 않는다 |
| 대비 | 블록 모집단 | **구성** | 라이트·다크 **두 블록을 파일에서 찾는다**. 하나라도 못 찾으면 붉다 |

**열거를 고른 유일한 자리**(부재 사유)가 낡지 않는 이유: 그 표는 **런타임 값의 출처**이기도
하다. 표에 없는 사유로 부재를 만들 수 없으므로, 열거와 실물이 갈릴 자리가 없다.

## (2) 우회 — 게이트를 초록으로 두고 거짓을 넣는 길

### 2.1 배치 단언

| # | 우회 | 무엇이 막는가 |
| --- | --- | --- |
| B-1 | 사이드바를 **그리지 않는다**(조건 하나로 숨긴다). 비교할 것이 없으니 비교 단언은 공집합으로 초록 | **비공허**: 비교 **앞에** 사이드바 노드 계수 ≥ 1 과 폭 > 0 을 단언한다 |
| B-2 | 레일을 그리되 **폭 0** 으로 둔다. 좌표 비교는 그대로 참 | 같은 비공허 — 레일도 폭 > 0 |
| B-3 | 1280px 에서 본문을 **비운다**. 넘침 0 · 한 단이 참 | 390px 쪽에 **본문이 비어 있지 않음**(보이는 자손 계수)을 함께 센다 |
| B-4 | 레일을 본문 **앞**에 둔다(DOM 순서를 뒤집는다). 시각 배치는 CSS 로 되돌린다 | 좌표로 잰다 — **DOM 순서가 아니라 상자**다. 390px 에서는 **문서 순서**를 따로 센다(한 단에서는 좌표가 상하라 좌우 비교가 뜻을 잃는다) |
| B-5 | 넘치는 요소를 **`overflow:hidden` 조상** 안에 둔다. 문서 가로 넘침은 0 | 넘침을 **문서 폭**이 아니라 **보이는 요소의 오른쪽 끝 전수 최댓값**으로 잰다(잘린 띠가 아니라 요소의 상자) |
| B-6 | 두 단을 **컴포넌트를 쓰지 않고** 손으로 짠다 → 표지가 없어 모집단 밖 | **미달로 남는다**(§3). 완화: 원시 요소가 표지를 **자기가** 달고, 화면은 그것을 끌 수 없다 |
| B-7 | spec 파일 이름을 바꿔 수집에서 뺀다 | 스모크 등록부(`smoke-specs.txt`)의 양방향 등식 |
| B-8 | 뷰포트를 1280 이 아닌 값으로 돌려 사이드바가 안 서는 폭을 피한다 | 측정 **첫 줄**에서 `page.viewportSize()` 를 단언한다(터치 타깃 게이트의 선례) |

### 2.2 부재값

| # | 우회 | 무엇이 막는가 |
| --- | --- | --- |
| A-1 | 금지 문면을 **상수에 넣어** 이름만 바꾼다 | 훑기는 **글자**를 센다 — 상수에 넣어도 그 파일에 글자가 있다 |
| A-2 | 글자를 **조각내어** 이어 붙인다(`'값 ' + '없음'`) | 소스 훑기는 지나간다. **렌더 층**이 잡는다 — 그려진 DOM 의 텍스트에서 센다. **그 층은 fixture 에 매인다**(여기 마운트한 자리만 본다) |
| A-3 | 부재가 **하나도 없는** fixture 로 렌더 층을 돌린다 → 「0 건」이 늘 참 | 같은 렌더에서 **사유 문면 계수 ≥ N** 과 **사유 전수가 한 번씩** 서는 것을 함께 단언한다 |
| A-4 | 사유 표의 문면을 금지 문면과 **같게** 만든다(사유는 있는데 글자가 같다) | 표의 값이 금지 어휘를 **담지 않음**을 단언한다(부분 일치 포함 — 계약의 「지어낸 기본값 없음」이 부분 일치로 걸린 자리가 선례다) |
| A-5 | 「아직 모른다」 자리에 **「없다」 사유**를 넣는다(타입은 통과) | 알림함 배지의 **응답 전** 단언이 그 차이를 잰다 — 응답 전 문면 ≠ 응답 후 부재 문면 |
| A-6 | 훑기에서 디렉터리를 **하나 더 뺀다**(차감을 넓힌다) | 차감 목록이 **한 자리**이고 짝 test 가 그 목록의 크기를 단언한다 |
| A-7 | 금지 어휘를 **`title`·`aria-label` 속성**으로 옮긴다 | 렌더 층이 텍스트 **와** 두 속성을 함께 읽는다(13A 문면 게이트의 선례와 같은 축). 양성 대조가 그 자리를 든다 |
| A-8 | 훑기 뿌리를 좁힌다(`src` 만 본다) | 뿌리 셋(`src`·`e2e`·`scripts`)이 **한 자리**이고 짝 test 가 그 집합을 단언한다. 「필터는 파일 분할을 따라가라」 |

### 2.3 대비

| # | 우회 | 무엇이 막는가 |
| --- | --- | --- |
| C-1 | 값을 test 에 **복사**해 두고 파일은 바꾼다 | 파싱 대상이 **그 파일**이다. test 에 색 리터럴을 두지 않는다 |

| C-10 | 측정 모집단에서 **카드 선이 슬그머니 돌아온다** | 모집단에 그 이름이 **없다는 것**을 단언한다(글이 아니라 거동) |

## (2b) 값 획득 축 — 새 public 표면 전수

이 slice 가 여는 표면과, 각 표면으로 **값을 얻는 길**이 무엇에 막히는가. 「경계로 처리」 행도
실측한다.

| 새 표면 | 값을 얻는 길 | 막는 것 |
| --- | --- | --- |
| `display/absence.ts` — 사유 표 · 부재 값 생성자 | 표 밖 사유로 부재를 만들기 | `Record<Reason,…>` 전수 · 생성자가 유니온만 받는다(컴파일) |
| 〃 | 부재 값을 **손으로 지어** 글자를 끼우기 | 값이 **사유만** 들고 글자는 표가 낸다 — 글자를 싣는 칸이 없다 |
| `components/AbsentValue` — 부재의 유일한 얼굴 | 이 컴포넌트를 **쓰지 않고** 손으로 span 을 그리기 | 소스 훑기 + 렌더 층(§2.2) |
| `components/TwoColumn` — 두 단 | 표지를 **끄기** | 표지를 컴포넌트가 달고 prop 으로 열지 않는다 |
| 〃 | 컴포넌트를 **쓰지 않고** 두 단을 짜기 | **미달**(§3 · B-6) |
| `components/PageHeader` · `SummaryTile` · `KeyValueRow` · `StatusPill` | 클래스를 덧붙여 크기·색을 덮기 | `className` prop 을 두지 않는다(공유 `Button`·`Card` 의 선례) |
| `StatusPill` | 색**만으로** 상태를 말하기 | 라벨 문자열이 **필수**다(옵셔널이 아니다) |
| 셸의 사이드바 | 자리 표를 거치지 않고 링크를 **손으로** 더하기 | 두 탐색이 같은 자리 집합을 그리는 기존 셸 test 의 등식 |
| 셸의 입찰함 배지 | 계수를 **클라이언트가 추론**하기(상태로 거르기) | 배지는 `kind` 하나로 부른 응답의 **길이**만 쓴다 — 짝 test 가 그 등식을 든다 |
| **`--color-control-line`**(팀장 판정 2026-11-20) — 컨트롤의 경계 토큰 | 컨트롤이 **다른 토큰**(카드 선)을 써서 3:1 측정을 비껴간다 | 짝 게이트가 **어느 요소의 class 인가**를 AST 로 본다(내장 컨트롤 태그 전수) + 공유 버튼은 **어조 표를 값으로** 잰다(그 축은 className 이 식이라 AST 가 보지 못한다 — 변이 실측) |
| 〃 | 카드 테두리를 측정 밖으로 두었으니 **카드가 바탕에 녹는다** | 면 차이(1.09:1)를 **래칫**으로 함께 센다 |
| `components/KeyValueRow`(개명) | 옛 이름이 남아 같은 물건에 두 이름이 산다 | `tsc` — 옛 이름의 export 가 없다 |
| `object` 커널 주입 자리 | 해당 없음 | 이 slice 에 Kotlin `object` 가 없다 |

## (3) 과잉인가 미달인가

**과잉으로 보고 하지 않는 것**

- 「두 단을 손으로 짜는 것」을 AST 로 금지하지 않는다. 오늘 위반 0 이고, 금지하면 레이아웃
  유틸리티 두 줄마다 게이트를 설득해야 한다 — 14B·14C·14D 의 속도를 비용으로 치른다.
- 서체·여백·굵기를 재지 않는다(착수 판정이 서체를 대조 대상에서 뺐다).
- 큰 글자 3:1 예외 축을 세우지 않는다(§2.3 C-7).

**미달로 남기고 적는 것**

| 미달 | 왜 남기나 | 어디서 드러나나 |
| --- | --- | --- |
| 두 단을 컴포넌트 없이 짜면 레일 축이 그것을 못 본다 | 위 과잉 판단 | 운영자 시각 검토(완료 조건 4) · 각 화면 PR 의 앞·뒤 캡처 |
| 레일을 쓰는 **출하 화면이 14A 시점에 없다** | 화면 배치는 14B·14C·14D 소유 | 레일 축의 비공허를 **합성 마운트**로 세우고, 출하 화면은 표지 전수라 뒤 레인이 붙이는 순간 자동으로 든다 |
| 소스 훑기는 **글자**를 센다 — 런타임 조립은 렌더 층에만 걸린다 | 13A 문면 게이트가 같은 경계를 이미 선언했다 | 렌더 층의 fixture 가 닿는 범위 안에서만. **그 층은 r2 에 실제로 세웠다**(v M-2 — r1 의 이 표는 아직 없는 층을 있다고 적었다) |
| 대비는 **토큰 값**을 재고 컴포넌트의 **고름**을 재지 않는다 | 고름은 짝 test 의 축(`satisfies` 전수) | 어조 표를 바꾸면 그 test 가 붉는다 |

## 결정 — 구현의 모양

### D-1 부재값: 사유를 지닌 타입

`display/absence.ts` 한 자리에 **닫힌 사유 표**를 둔다. 오늘 실제로 일어나는 사유는 **둘**이다.

| 사유 | 뜻 | 오늘 그 자리 |
| --- | --- | --- |
| 응답이 그 칸을 싣지 않았다 | 응답은 왔고 칸이 비었다 | 공고의 발주기관·기초금액 · 결과의 금액 축 · 워크시트의 기초금액 방식 · 시각 칸 전부 |
| 아직 응답 전이다 | 질의가 끝나지 않았다 | **알림함 배지** — 오늘 이 자리가 「없다」와 같은 얼굴이라 운영자가 0 건으로 읽는다 |

부재 값은 **사유만** 든다. 글자는 표가 낸다 — 값에 글자를 싣는 칸이 없으므로 「사유는 붙이고
글자는 옛것」이 타입에서 설 수 없다. 공유 상수 넷(`ABSENT_INSTANT`·`ABSENT_AMOUNT` 외 둘)은
**지운다**.

**호출부 43 자리의 서명을 바꾸지 않는다**(실측: 시각 13 · 금액 3 · 용어 줄 27). 사유를 모든
