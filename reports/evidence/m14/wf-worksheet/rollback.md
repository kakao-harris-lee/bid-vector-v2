# M14 / wf-worksheet (14C) — rollback

**실측 HEAD: `224f23337c9f32ba970a8bf9ebed57ff2101879e`** — 이 slice 의 **마지막 산출물 커밋**
(evidence 셋을 담은 커밋)이다. 이 파일을 담는 커밋은 그보다 뒤에 오므로 실측 HEAD 와 판정 SHA 는
언제나 다르다. verifier 가 보는 것은 그 둘의 같음이 아니라 **그 사이에 되돌림 대상이 움직였는가**다.

**전칭식** — 실측 HEAD 와 판정 SHA 사이에서 복원 대상 경로가 움직였다면, 움직인 경로는 전부
**원천(`056f405c`)에 없는 신설 파일**이다(이 `rollback.md` 가 그런 파일이다). 열거와 원천 부재
확인은 verifier 가 한다.

## 되돌리는 방법

range revert 가 아니라 **in_scope 경로 한정 복원**이다. 목록은 기계 산출이고 라운드마다 다시
뽑는다 — 손으로 적은 목록은 뒤 라운드가 만든 파일을 빠뜨린다.

```
git diff --name-status 056f405c9e5659b9a068288f1104f9e04a6de016..<판정 SHA> \
  | awk '{print $2}' | sort > /tmp/14c-restore.txt
xargs -a /tmp/14c-restore.txt \
  git restore --source=056f405c9e5659b9a068288f1104f9e04a6de016 --staged --worktree --
```

## 복원 원천

**착수 base `056f405c9e5659b9a068288f1104f9e04a6de016` 하나다**(고정 SHA — 움직이는 `origin/main`
을 쓰지 않는다). 이 레인은 머지 전이고 **다른 slice 를 병합하지 않았으므로** 원천을 바꿀 사유가
없다. 원천을 바꾸지 않았으니 **셋째 단언은 해당 없음**이다(그 단언은 복원 원천을 바꿀 때 잰다).

**머지 차례에 달라지는 것**: 그때 `docs/discovery/capability-map.md` 에 §12.3 하위 절을 더하고
main 을 병합하므로, 복원 원천이 **병합된 main 커밋**으로 바뀐다. 그 커밋에서 목록과 ①~⑥ 을
다시 뽑고, 그 자리에서 **셋째 단언**(복원 대상 blob 이 두 원천에서 같은가)과 지도의
「내 절 0 · 남의 절 보존」을 함께 잰다.

## 실측 (임시 clone, 저장소 밖)

`224f2333` 을 체크아웃한 버릴 clone 에서 ①~⑥ 을 돌렸다.

| 단계 | 결과 |
| --- | --- |
| ① 복원 명령 | 종료 코드 **0** |
| ② D/M 수 | **D 3 · M 5**(합 8 = 기계 산출 목록의 줄 수와 같다) |
| ②' **내 표지 0 · 남의 표지 보존** | `PageHeader` 의 제목 자리 표지가 복원 **전 1** → **후 0**. 같은 파일의 14A 표지 둘(요약 · 행동)은 **각각 1** 로 남는다(앞뒤를 모두 쟀다 — 뒤만 재면 공허하다) |
| ③ 복원 경로의 원천 대비 diff | **빈 출력** |
| ③' **트리 동일성** | 저장소 **전체**의 `git diff 056f405c` 가 **빈 출력** · 남은 미추적 **0** |
| ④ compile | `typecheck` 0 · `lint` 0 |
| ⑤ test | 파일 **70** · test **1669** 통과(= 착수 base 의 수. 이 레인의 1680 과 차이 **11** 이 이 slice 가 더한 `it` 수와 같다) |
| ⑥ 게이트 | `gate:tests` 0 · `gate:src-tree` 0 · `api:types:check` 0 · `build` 0 · `gate:boundary-canary` 0 |

**갈음은 「HEAD 초록」이 아니라 트리 동일성이다**(③'). 되돌린 트리가 원천과 **바이트로 같으므로**
그 트리의 거동은 원천의 거동이고, e2e 두 레인을 다시 돌려 얻을 새 정보가 없다. 그래도 ⑤·⑥ 의
수를 함께 적는다 — 동일성 단언이 틀렸다면 그 수가 먼저 어긋난다.

**⑤ 의 첫 실행이 한 번 붉었다**(1 실패 · 1668 통과). 같은 트리에서 **연이어 세 번** 돌렸고 셋 다
1669 전부 통과(종료 0)였다. 첫 실행의 실패한 test 이름은 붙잡지 못했다 — 요약만 남기고 흘렸다.
그래서 「무엇이 흔들렸는지」는 **열린 채**로 적는다(M10 후속에 같은 레인의 흔들림 서명 둘이 이미
등재돼 있다). 이 자리의 판단에는 영향이 없다: 되돌린 트리는 원천과 바이트로 같으므로, 그 흔들림은
**이 slice 가 아니라 원천의 성질**이다.
