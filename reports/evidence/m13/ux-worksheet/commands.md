## 구현 라운드 실측 — 넘겨받은 게이트 넷

**A 핸들러 축.** 착수에 잰 우회 열셋 가운데 **열둘이 RED** 가 됐다(남은 하나는 요소 생성 호출 —
판정 대기). 음성 대조(문서·창 수신자)는 그대로 초록이다. 뒤집는 도중 **출하 트리 둘이 붉었다** —
표 조회(`TABLE[key](…)`)가 「멤버 이름을 증명할 수 없는 자리」에 걸린 것이고, 그 갈래의 수신자
조건을 「요소일 수 있을 때만」으로 좁혀 0 으로 돌아왔다.

**B 레이블 축.** M-11 의 세 꼴(display 없음 · `contents` · 레이블 안 컴포넌트)과 새로 고안한 둘
(`inline`·`hidden`, 변형 접두 display)이 RED 다. 출하 트리 세 자리는 그대로 초록이다(전부 `flex`).

**C 터치 타깃 측정.** 합성 페이지 아홉 자리 가운데 **넷이 고치기 전에 붉었고**(조상 넘침 숨김 ·
조상 `contain:paint` · 조상 `clip-path` · 손가락 축) 다섯 음성 대조는 양쪽에서 초록이다. 출하
트리는 여정 전건 초록이다.

**D 훑기 뿌리.** 출하 CSS **17,153 → 16,797 B**. 사라진 규칙 **일곱**은 전부 출하 소스가 쓰지 않는
것이고(넷은 자바스크립트 메서드 이름이 후보로 잡힌 꼴이다) **새로 생긴 규칙은 0** 이다. 출하가
쓰는 자리는 변형까지 그대로 남았다(그려지는 것은 바뀌지 않는다). 13B 가 거둔 죽은 규칙 하나도
이 뿌리에서 자동으로 빠진다.
