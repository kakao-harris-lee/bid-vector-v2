## 설계 검토 실측 — 넘겨받은 게이트 넷 (`design-review.md` 의 표가 가리키는 수)

`npm ci` exit 0 뒤, **게이트 자신의 입구**로 쟀다(심은 것이 아니다).

**A 핸들러 축** — 합성 원문을 재는 입구에 꼴 열여섯을 넣었다. **열셋이 초록**(= 오늘의 우회)이고
양성 대조(요소 수신자)는 RED, 음성 대조(문서 수신자)는 초록이다. 13B verifier 가 초록으로 적은
한 꼴(`prototype` 경유 호출)은 **내 탐침 선언에서는 RED** 다 — 수신자가 증명 불가로 접힌다.
선언이 다르면 결과가 다른 자리라 그대로 적는다. 출하 트리 실측: 요소에 거는 배선 **0**
(문서 수신자 한 자리뿐), 요소 복제 호출 **0**, `on*` 대입 **0**, 객체 합치기·속성 쓰기 **0**,
공유 카드의 요소 생성 호출 하나는 props 리터럴에 `on*` 키 **0**.

**D 훑기 뿌리** — 실제 컴파일러와 실제 훑기 엔진으로 두 설정을 받았다. 오늘은 훑기 뿌리가
**자동 탐지**(컴파일 결과가 뿌리를 비워 두고 호출자가 준 뿌리에서 탐지한다)이고, 뿌리를 묶은 뒤는
**꺼짐 + 출하 소스 기준 패턴 둘**(출하 꼴 · test 제외)이다. 묶은 뒤 후보 **1166**, 그 가운데
출하 소스가 쓰는 최소 높이 토큰은 **들고**, 13B 가 남긴 죽은 규칙의 어휘는 **빠진다**.
`index.html` 의 class **0**(경계 확인).

**B·C** 는 13B verifier 의 실측을 인용했고(17px 꼴 셋 · 조상 잘라내기 셋 · 손가락 축 하나),
