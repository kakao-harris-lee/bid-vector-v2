# M13 / ux-worksheet (13C) — 설계 검토: 넘겨받은 게이트 넷

13B 에서 넘어온 게이트 항목을 **구현 전에** 검토한다(팀장 착수 판정 §2). 네 절이고 각 절은
(0) 위협 모델 경계 → (1) 열거인가 구성인가 → (2) 우회 → (2b) 값 획득 축 → (3) 과잉·미달 이다.
워크시트 본작업(복사·병기·확인·하한 여유·접기·담기)은 이 문서의 대상이 아니다.

**공통 전제.** 넷 모두 **오늘 출하 트리 위반 0** 에서 출발한다(A·D 는 이 라운드에 직접 쟀고
B·C 는 13B verifier 가 쟀다). 그래서 좁히는 방향의 변경에 production 비용이 없다. 수치와 조건은
`commands.md` 가 정본이다.

**실측 방법.** A 와 D 는 **게이트 자신의 입구**로 쟀다 — A 는 합성 원문을 재는 입구에 꼴 열여섯을
넣었고, D 는 실제 컴파일러와 훑기 엔진으로 「후보 집합」을 두 설정에서 받았다. 심은 것이 아니라
게이트가 쓰는 그 함수로 쟀다.

---

## A. 핸들러 축 — 참조와 수신자로 뒤집는다 (v M-7b · cr Q-2 · Q-3①)

### (0) 위협 모델 경계

이 축이 막는 것은 **터치 타깃 게이트의 선택자 모집단을 벗어난 누르는 자리**다. `<div onClick>`
처럼 적으면 손가락은 닿는데 선택자에 걸리지 않고, 키보드로도 닿지 않는다.

- **신뢰의 방향**: 출하 트리(`src/**`, test 제외)의 TS 프로그램. 증명할 수 없는 자리는 위반 쪽이다.
- **막지 않는 것**: `document`·`window` 수신자. 그 둘은 요소가 아니라 **누르는 자리를 만들지
  않는다** — 대신 그 면제는 「문서 전체에 위임 핸들러를 달아 화면을 누르는 자리로 만드는 꼴」을
  열어 둔다. 오늘 그 자리가 실제로 하나 있다(셸의 Escape 처리) 그리고 그것은 **키 처리이지 누르는
  자리가 아니다**. 이 사실을 알려진 제한으로 적는다 — 「막혔다」고 적지 않는다.
- **경계 밖**: web 밖 코드 · test 파일 · 런타임에 문자열로 조립한 이벤트 이름.

### (1) 열거인가 구성인가

지금 술어는 **두 자리가 열거**다 — 부른 대상을 **이름 글자**로 비교하고(`'cloneElement'`),
수신자를 「`Element` 를 상속하면 위반」이라는 **허용 쪽 기본값**으로 본다. 둘 다 **넓히는 것만으로**
빠져나간다. 뒤집으면 좁히는 쪽이 기본이 된다.

| 축 | 지금 | 뒤집은 뒤 |
| --- | --- | --- |
| `cloneElement` | 호출 자리의 callee 이름이 그 글자인가 | **앵커 심볼과 같은 심볼의 참조가 어디에 나타나는가** |
| 수신자 | `Element` 를 상속하면 위반 | **증명 가능한 `Document`·`Window` 만 면제**, 나머지 전수 위반 |
| 멤버 이름 | 점 접근과 **글자 리터럴** 대괄호 접근 | 점 접근 · 대괄호 접근(리터럴이 아니면 증명 불가) · **구조 분해 바인딩** |
| 대입 | `=` 토큰 하나 | 복합 대입 전수 · `Object.assign` 의 `on*` 키 · `setAttribute('on*', …)` |

**앵커 심볼은 저장소의 선례를 쓴다.** 카드 모집단 게이트가 「타입 이름도 선언 경로도 쓰지 않고
합성 앵커의 식에서 심볼을 얻는다」로 지은 그 자리와 같은 꼴로, `react` 의 그 선언을 들여오는 **한
줄짜리 앵커 원문**을 오버레이에 두고 그 심볼과의 **동일성**을 본다. 모듈 경로 글자를 술어로 쓰지
않는다(글자 하나로 열리는 꼴을 되살리지 않는다).

### (2) 우회 — 게이트 자신의 입구로 쟀다

열여섯 꼴 가운데 **열셋이 초록**이다(= 오늘의 우회). 두 대조는 의도대로다.

| # | 꼴 | 오늘 | 닫는 층 |
| --- | --- | --- | --- |
| — | `document.addEventListener` (음성 대조) | 초록 | 그대로 면제(증명 가능한 `Document`) |
| — | `el.addEventListener` (양성 대조) | RED | 그대로 |
| n1 | `const m = 'addEventListener'; el[m](…)` | **초록** | 멤버 이름: 대괄호 인자가 리터럴이 아니면 **증명 불가 → 위반** |
| n2 | `const { addEventListener } = el; addEventListener.call(el, …)` | **초록** | 멤버 이름: **구조 분해 바인딩**도 그 멤버의 참조다 |
| n3 | `const t: EventTarget = el; t.addEventListener(…)` | **초록** | 수신자 뒤집기 |
| n4 | 같은 꼴을 `Node` 로 | **초록** | 수신자 뒤집기 |
| n5 | `function X<T extends HTMLElement>(node: T)` | **초록** | 수신자 뒤집기(제약을 풀 필요가 없다 — 기본이 위반) |
| n6 | `EventTarget.prototype.addEventListener.call(el, …)` | RED | 내 탐침 꼴에서는 수신자가 증명 불가로 접혀 이미 RED 다 — 13B verifier 의 r6 꼴과 **결과가 다르다**(그쪽 선언에서는 초록이었다). 뒤집은 뒤에는 어느 꼴이든 RED |
| n7 | `const g: GlobalEventHandlers = el; g.onclick = f` | **초록** | 수신자 뒤집기 |
| n8 | `el.onclick ??= f` | **초록** | 대입 꼴: 복합 대입 토큰 전수 |
| n9 | `Object.assign(el, { onclick: f })` | **초록** | 대입 꼴: 대상이 면제 수신자가 아니면 `on*` 키가 위반 |
| n10 | `el.setAttribute('onclick', '…')` | **초록** | 대입 꼴: 첫 인자가 `on*` 리터럴이면 위반(증명 불가 수신자 포함) |
| n11 | `const cl = cloneElement; cl(<div/>, { onClick })` | **초록** | 참조 축 |
| n12 | `const { cloneElement: cl } = React` | **초록** | 참조 축 |
| n13 | `cloneElement.call(null, <div/>, { onClick })` | **초록** | 참조 축 |
| n14 | `createElement('div', { onClick })` | **초록** | 아래 「선언된 경계를 닫을 것인가」 |

재수출(`export { cloneElement as cl } from 'react'`)은 13B verifier 가 **RED** 로 실측했고(별칭
해소), 참조 축에서도 RED 다. 13B checklist 제한 2 가 그것을 「값으로 옮기는 길」로 묶은 것은
v L-9 가 지적한 문면 오류다 — **13C 의 checklist 가 새 분류로 적는다**(13B evidence 는 편집 0).

**선언된 경계를 닫을 것인가 — n14.** 13B 는 `createElement` 를 「JSX 가 아니다」로 경계에 두었다.
그런데 같은 기전이다: 비-상호작용 태그에 `onClick` 을 **props 객체로** 넘긴다. 둘의 차이는
**증명 가능성**이다 — `cloneElement` 는 이미 만들어진 요소에 props 를 **덧붙이므로** 태그를 볼 수
없고(그래서 참조 자체가 위반), `createElement` 는 **첫 인자가 태그**라 같은 타입 판정을 그대로
적용할 수 있다. 그래서 비대칭이 원칙에 맞는다: **증명할 수 있을 때는 판정하고, 없을 때는 거절한다.**
오늘 출하 트리의 그 호출 하나(공유 카드가 내장 태그 유니온을 그리는 자리)는 props 리터럴에 `on*`
키가 **0** 이라 닫아도 초록이다(실측). **제안: 닫는다.** 판정을 받으면 같은 라운드에 든다.

### (2b) 값 획득 축

이 게이트가 내보내는 표면 전수와, 그 표면으로 **판정을 비울 수 있는가**를 본다.

| 표면 | 호출자가 주는 값 | 비우는 길과 막는 자리 |
| --- | --- | --- |
| 트리 훑기 입구 | 디렉터리 | 빈 훑기는 이미 **던진다**(선례 그대로 유지) |
| 합성 원문 입구 | 원문 + **곁 모듈** | 호출자가 `react` 모듈 원문을 주므로 **앵커 심볼이 없는 프로그램**을 만들 수 있다 → 앵커가 해소되지 않으면 **던진다**(fail-closed). 이 한 줄이 이 절의 핵심이다 — 던지지 않으면 대조 test 하나가 모든 참조 판정을 조용히 끈다 |
| 태그 판정(기존 export) | 검사기 · 태그 노드 | 그대로. 레이블 축이 이것을 재사용한다(사본 금지) |
| 면제 집합 셋(기존 export) | — | HTML 이 정한 것이고 **늘리지 않는다**. 늘리는 변경은 그 자체가 리뷰 대상이다 |
| 새 면제(`Document`·`Window`) | — | **타입 이름 글자가 아니라 심볼**로 본다. 이름으로 보면 `interface Document extends HTMLElement` 한 줄로 열린다 — 그 꼴을 대조에 둔다 |

### (3) 과잉·미달

- **과잉**: `EventTarget`·`Node` 로 **선언한** 정상 코드가 위반이 된다. React 의 `e.target` 이
  계약상 `EventTarget` 이라 그 자리가 대표적이다. 탈출구는 **좁힘**이다(`instanceof HTMLElement`
  뒤에 쓰면 통과한다) — 이 축은 「요소일 수 있는 것」을 전부 보수적으로 세고, 좁히는 쪽이 코드가
  할 일이다. 오늘 출하 트리 비용 0.
- **과잉**: 대괄호 접근의 인자가 리터럴이 아니면 **멤버 이름을 모르는데도** 위반이다(`el[key]` 가
  `className` 이어도 걸린다). 좁히는 방향이고 오늘 0 이다. 필요한 날의 탈출구는 「그 자리를 점
  접근으로 적는다」이고, 그것이 이 축이 바라는 모양이다.
- **미달**: `document`·`window` 면제가 **위임 핸들러**를 열어 둔다(위 (0)). 상자로 재는 축이
  아니므로 이 축에서 닫을 수 없다 — 등재한다.
- **미달**: 런타임에 조립한 이벤트 이름(`el['on' + 'click'] = f`)은 대괄호 인자가 리터럴이
  아니므로 **위반으로 걸린다**(과잉 쪽). 반대로 `eval`·`new Function` 경로는 이 축 밖이다.
- **미달**: 이 축은 `src/**` 만 본다. web 밖과 test 는 보지 않는다(선례 그대로).

## B. 레이블 축 — 「최소 높이를 든다」가 실제로 서는가 (v M-11)

### (0) 위협 모델 경계

e2e 상자 측정이 **닿지 못하는 자리**(입찰함의 결과 기록 폼 라디오 — fixture 가 그 폼을 열지 않는다)
를 **원문에서** 지키는 축이다. 그래서 이 축의 판정은 화소가 아니라 규칙이고, 규칙이 실효를
보증하지 못하면 그 한 자리가 조용히 열린다.

### (1) 열거인가 구성인가

**열거가 불가피한 자리가 하나 있다** — Tailwind 어휘다. 상자를 세우는 display 를 CSS 계산값으로
볼 수 없으므로(원문 축이다) 어휘 집합을 적어야 한다. 그래서 구성은 **기울기**로 세운다:
`min-height` 가 **서는** display 어휘(`flex`·`grid`·`block`·`inline-flex`·`inline-block`·
`flow-root`·`table`)를 **허용**으로 두고, 그 밖(어휘가 **없는 경우를 포함**)은 증명 불가 →
의무 미이행이다. `contents`·`inline`·`hidden` 은 그 「밖」에 자동으로 든다 — 금지 목록을 따로
적지 않는다(목록이 둘이면 갈린다).

### (2) 우회

| 꼴 | 오늘(13B verifier 실측) | 닫는 층 |
| --- | --- | --- |
| `<label className="min-h-11">` (flex 없음 → 17px) | 초록 | display 어휘 요구 |
| `className="contents min-h-11"` | 초록 | 같은 층(허용 밖) |
| 레이블 안 첫 labelable 이 컴포넌트가 내는 `button` | 초록 | **컴포넌트를 labelable 일 수 있다고 본다**(보수) |
| `className` 이 식(`cn(...)`·템플릿) | 이미 위반 | 그대로(제한 21) |
| 44px 을 다른 어휘로(`h-12`·`min-h-[44px]`·`py-3`) | 이미 위반 | 그대로 — **탈출구 없음**(제한 20). 이 라운드에 **넓히지 않는다**: 어휘를 늘리면 「덮어쓰는 어휘」 판정과 곱해져 조합이 는다 |
| display 를 `style={{display:'flex'}}` 로 | 초록(미등재) | **증명 불가 → 의무 미이행**으로 접는다(새로 고안한 꼴) |
| display 를 CSS 파일에서 주기 | 초록 | **미달** — 원문 축이 볼 수 없다. 등재 |

### (2b) 값 획득 축

- 새 export 는 **display 어휘 집합** 하나다. 그 집합을 호출자가 주지 못하게 **모듈 상수**로 둔다
  (인자로 받으면 대조 test 가 그것을 비울 수 있다).
- 태그 판정은 A 의 export 를 **재사용**한다(13B verifier M-10 처방 그대로) — 사본을 만들지 않는다.
- 훑기 입구의 빈 결과는 A 와 같은 자리에서 **던진다**.

### (3) 과잉·미달

- **과잉**: `min-h-11` 과 허용 display 를 **둘 다** 적어야 통과한다 — 오늘 세 자리는 전부
  `flex` 를 이미 들고 있어 비용 0(구현 라운드에 재확인한다).
- **미달**: CSS 파일에서 display 를 주는 꼴 · 조상이 `display:contents` 로 상자를 없애는 꼴.
  둘 다 상자 축(C)이 보는 자리이고, 입찰함 라디오에서는 **어느 축도 보지 못한다** — 그 한 자리의
  구조적 해법은 fixture 가 그 폼을 열어 상자로 재는 것이고(13B 제한 16 이 그렇게 적었다) 그 파일은
  13D 소유다. 이 slice 는 넓히지 않고 등재한다.

## C. 터치 타깃 측정 — 조상이 자르면, 손가락이 밀 수 있으면 (v M-8 · L-4)

### (0) 위협 모델 경계

재려는 것은 **보이고 눌리는 띠의 높이**다. 측정 자리는 브라우저 상자이고, 경계는 「한 화면의 한
상태」(제한 13)다. 이 절은 그 경계를 넓히지 않고 **같은 상태에서 상자를 더 정확히** 잰다.

### (1) 열거인가 구성인가

구성이다. 조상 사슬을 올라가며 **자르는 상자**를 모아 **교집합**을 취하고, 그 교집합으로 높이를
잰다. 자르는 조상의 판정은 computed style 셋이다 — `overflow-x`/`overflow-y` 가 `visible` 이
아니거나, `clip-path` 가 `none` 이 아니거나, `contain` 이 paint 를 품는다.

**스크롤과 클리핑을 가르는 것이 이 절의 난점이다.** 세로로 스크롤되는 카드 안의 버튼은 지금
뷰포트에서 잘려 보여도 **밀면 닿는다** — 자른 것이 아니다. 그래서 교집합을 취할 때 **스크롤 가능한
축은 스크롤 범위까지 펴고**, 스크롤되지 않는 축만 자른다. 그 판정은 이미 이 spec 에 있는
「스크롤 여지」 술어를 재사용한다(사본 금지).

### (2) 우회

| 꼴 | 오늘(13B verifier 실측) | 닫는 층 |
| --- | --- | --- |
| 조상 `height:12px; overflow:hidden` 안의 44px 버튼 | 미달 0 · 부분 잘라내기 0 | 교집합 높이 |
| 조상 `clip-path: inset(0 0 70% 0)` | 같음 | 교집합 높이 |
| 조상 `contain: paint` | 같음 | 교집합 높이 |
| 조상 `touch-action: pan-y` 인 가로 스크롤 줄 | 예외가 그대로 선다 | 스크롤 예외에 **손가락으로 밀 수 있는가**를 더한다 |
| 자기 `clip-path` 부분 잘라내기 | 이미 RED | 그대로 |
| 고정 배치 뷰포트 밖 | 이미 RED | 그대로 |
| 조상 `transform: scale(.2)` | 상자가 줄어 **이미 RED**(새로 고안해 실측할 꼴) | 그대로 |
| 조상이 **스크롤 가능한데** 타깃이 범위 밖 | 이미 RED | 그대로 |

### (2b) 값 획득 축

- 이 축의 판정 함수는 spec **안**에 있고 public 표면이 아니다. 늘어나는 것은 없다.
- **하한 N 표**가 이 축의 값 획득 자리다: 모집단이 늘면 하한을 **올려야** 하고, 내리는 변경은
  게이트를 약하게 만든다. 13C 는 화면 C 에 컨트롤을 더하므로 **구현 라운드 실측으로 올린다**
  (팀장 판정 §3-5: 올리기만).
- 화면 표 등식(별 게이트)이 자리 표와의 집합 등식을 들고 있으므로 화면을 더하지 않는 이 slice 는
  그 등식을 건드리지 않는다.

### (3) 과잉·미달

- **과잉**: 정상적인 세로 스크롤 영역 안의 타깃이 잘린 것으로 세어질 수 있다 — 위 (1) 의
  「스크롤 축은 펴고 자르지 않는다」가 그것을 막는다. **음성 대조**를 둔다: 세로로 스크롤되는
  카드 안의 44px 버튼이 초록.
- **과잉**: `contain: paint` 는 성능 목적으로도 쓰인다. 그 안에 든 타깃이 **잘리지 않으면** 교집합이
  줄지 않으므로 초록이다 — 금지가 아니라 측정이다.
- **미달**: 조상의 `pointer-events: none` · `aria-hidden` · 겹친 형제로 **가려진** 자리는 이 축이
  보지 않는다(13B 제한 13 의 경계 그대로).
- **13D·13E 에 전하는 술어 문장**(팀장 §2 요청): **「타깃의 상자가 아니라, 조상의 overflow·clip·
  contain 을 반영한 가시 사각형으로 높이를 잰다. 가로 스크롤 예외는 그 줄을 손가락으로 밀 수 있을
  때만 선다.」** 새로 붉어질 수 있는 꼴은 ⓐ 고정 높이 조상에 `overflow-hidden` 을 둔 묶음 안의
  컨트롤 ⓑ `touch-action` 을 좁힌 가로 스크롤 줄 둘이다. 오늘 main 에는 그런 자리가 0 이다
  (구현 라운드에 실측해 `commands.md` 에 적는다).

## D. class 후보 훑기 뿌리 (13B 제한 27 · v L-10)

### (0) 위협 모델 경계

막으려는 것은 **출하 CSS 가 출하 소스 밖의 글자에서 자라는 것**이다. 오늘 훑기 뿌리가 `src/` 에
묶여 있지 않아, 게이트 test 에 **글자로** 적은 class 꼴이 후보가 되어 유틸리티로 실린다
(13B 라운드 4 가 자산 해시 변화로 발견했고, verifier 가 죽은 규칙 하나를 base 대조로 분리했다).
신뢰의 방향: **출하 소스만 후보를 만든다.** 경계 밖: `index.html`(class 0 — 실측) · 번들에 들어가지
않는 설정 파일.

### (1) 열거인가 구성인가

정본은 **CSS 선언**이다(Tailwind v4 는 CSS-first 이고 이 저장소는 설정 파일을 두지 않는다):
자동 탐지를 끄고(`source(none)`) 출하 소스 패턴을 `@source` 로 적고 test 꼴을 `@source not` 으로
뺀다. 게이트는 그 **글자를 확인하지 않는다** — **실제 컴파일러와 실제 훑기 엔진**으로 후보 집합을
받아 거동을 잰다.

**실측(이 라운드, 두 설정):**

| 축 | 오늘 | 뿌리를 묶은 뒤 |
| --- | --- | --- |
| 컴파일 결과의 훑기 뿌리 | 자동 탐지(`root` 가 비어 있다 — 호출자가 준 뿌리에서 탐지한다) | **꺼짐** + `src` 기준 패턴 둘(출하 꼴 · test 제외) |
| 후보 수 | — (뿌리가 호출자 쪽이라 이 자리에서 셀 수 없다) | **1166** |
| 출하 소스가 쓰는 어휘(최소 높이 토큰) | — | **후보에 든다**(비공허 대조) |
| 13B 가 남긴 죽은 규칙의 어휘 | 출하 CSS 에 **실려 있다**(verifier 가 base 대조로 분리) | **후보에서 빠진다** |

### (2) 우회

| 꼴 | 닫는 층 |
| --- | --- |
| `@source` 를 다시 넓힌다 | 게이트가 **훑은 파일 목록**을 출하 파일 집합과 등식으로 본다(A 의 출하 파일 술어 재사용) |
| 다른 CSS 파일에서 자동 탐지로 다시 들여온다 | 같은 등식 — 게이트는 **번들이 쓰는 그 CSS 입구**를 컴파일한다 |
| test 이름을 `.spec.tsx` 로 바꿔 제외 패턴을 피한다 | 같은 등식(출하 파일 술어가 그 파일을 출하로 보지 않는다 → 훑은 목록이 집합을 넘는다) |
| `@source inline(…)`(safelist 꼴)로 어휘를 직접 심는다 | **후보 집합 대조**가 센다(출하 소스에 없는 어휘가 후보에 들면 등식이 깨진다) |
| Vite 플러그인 옵션·postcss 설정으로 뿌리를 바꾼다 | **부분 미달** — 아래 (3) |
| src 밖 파일을 src 로 옮긴다 | 그것은 출하 파일이 되는 것이고, 경계 안이다(TS 프로그램 게이트가 함께 본다) |

### (2b) 값 획득 축

- 새 게이트 모듈이 내보내는 것은 **「그 CSS 의 훑기 뿌리와 후보 집합」을 내는 함수 하나**다.
  CSS 경로를 인자로 받으면 대조가 다른 CSS 를 먹일 수 있으므로, **번들 입구 CSS 를 모듈 상수**로
  두고 대조는 그 상수를 쓴다.
- **음성 대조의 표본 어휘**는 출하 소스가 **절대 쓰지 않을 꼴**로 둔다(상류가 그 이름을 채택하면
  음성 대조가 공허해진다 — 이 저장소의 선례 교훈). 표본은 게이트 test 파일 자신의 글자이고,
  그것이 후보에 들면 붉는다.
- 비공허 대조: 출하 소스가 **실제로 쓰는** 어휘가 후보에 든다.

### (3) 과잉·미달

- **과잉**: `src/` 안 test 가 쓰는 class 글자가 번들에서 빠진다. jsdom 은 CSS 를 적용하지 않으므로
  단위 test 의 단언에 영향이 없다(실측으로 확인한다 — vitest 전건).
- **미달**: 플러그인 옵션·postcss 축. 오늘 이 저장소에는 postcss 설정이 없고 플러그인은 인자 없이
  등재돼 있으며 그 등재 자체는 번들 경계 게이트가 AST 로 단언한다. 그래도 **그 게이트가 보는 것은
  경계 플러그인이지 Tailwind 플러그인의 옵션이 아니다** — 등재한다.
- **미달(추론 한 단계)**: 이 게이트가 재는 것은 **후보 집합**이고 출하 CSS 자체가 아니다.
  「후보가 줄면 출력도 준다」는 한 단계를 건너는 것이므로, 라운드 실측으로 **빌드 전후 CSS 대조**를
  함께 적는다(죽은 규칙이 빠지고 그 밖은 바이트가 같은지).
- **영구 게이트의 꼴에 대한 판정 요청**: 위 설계는 `vitest` 안에서 **실제 Tailwind 컴파일 + 훑기**가
  서는 것을 이 라운드에 실측했으므로(위 표) **성립한다**. 느린 축이 아니다(훑기 한 번).

## (2b) 보충 — **입력은 어디서 오는가**(팀장 조건 2026-11-18)

위 네 절의 (2b) 는 「**내보내는 표면**으로 판정을 비울 수 있는가」를 본다. 이 절은 그 짝인
「**들어오는 값**이 어디서 오는가」와 **경계로 처리한 행의 실측**을 한자리에 모은다 — 입력이
사본이나 목에서 오면 게이트는 자기 말만 재게 된다.

| 게이트 | 입력과 그 출처 | 경계로 처리한 것 | 그 행의 실측 |
| --- | --- | --- | --- |
| A 핸들러 | **TS 검사기의 타입**. 트리 훑기는 **실제 `tsconfig.json` 으로 연 프로그램**을 쓴다(설정 사본이 아니다 · 카드 모집단 게이트와 같은 자리를 공유한다). 합성 대조만 가벼운 프로그램이고 곁 모듈을 **호출자가** 준다 | ⓐ 출하 파일만(test 제외 — 훑기 술어가 그 집합을 낸다) ⓑ 런타임에 조립한 이벤트 이름·`eval` ⓒ 증명된 문서·창 수신자 | 출하 트리: 요소에 거는 배선 **0**(문서 수신자 한 자리뿐) · 요소 복제 **0** · `on*` 대입 **0** · 객체 합치기·속성 쓰기 **0** |
| B 레이블 | **원문 AST + 태그 타입 판정**(A 의 export 재사용 — 사본 없음). 상자가 아니다 | 이 축은 **규칙이지 측정이 아니다** — 화소는 C 가 잰다. CSS 파일에서 준 display 는 보지 못한다 | 출하 레이블 **세 자리 전부** 허용 display 를 이미 든다(그래서 비용 0) |
| C 터치 타깃 | **브라우저의 computed style 과 상자**. 출처 둘 — 390px 여정은 **출하 번들**(preview 서버)을, 합성 대조는 `setContent` 페이지를 잰다. 측정 함수는 **한 자리**를 공유한다 | 한 화면의 **한 상태**만 잰다(13B 제한 13) · 가려짐(`pointer-events`·`aria-hidden`·겹친 형제)은 밖이다 | 합성 아홉 자리에서 고치기 전 **넷이 초록**(= 우회)이었고 고친 뒤 RED · 음성 다섯은 양쪽 초록 |
| D 훑기 뿌리 | **Tailwind 컴파일 결과**(훑기 뿌리와 패턴)와 **훑기 엔진의 결과**(훑은 파일·후보). 둘 다 **번들 입구 CSS 그 파일**에서 나온다(모듈 상수) | 번들러 플러그인 옵션·postcss 축은 밖이다 · 재는 것은 **후보 집합**이고 출하 CSS 자체가 아니다 | 묶은 뒤 후보 **1219** · 훑은 파일 집합 == 출하 소스 집합 · 넓힌 뿌리에서 음성 표본이 후보에 **든다**(양성 대조) |

**새 갈래는 없다.** 네 입력 모두 그 게이트가 판정할 때 쓰는 **그 값**이고, 대조가 다른 값을
먹일 수 있는 자리는 위 네 절의 (2b) 가 각각 닫았다(앵커 fail-closed · 모듈 상수 · spec 내부 함수 ·
입구 CSS 상수).
