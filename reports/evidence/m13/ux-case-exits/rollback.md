# M13 / ux-case-exits (13D) — rollback

**실측 HEAD: `42eb72ea435d8022fc5d88a17e6007e63112f7ab`** (main 을 병합한 머지 커밋)
**복원 원천: `838fdb1bed723d57bdfdb675a3a3f2d309832c8a`** (병합된 main 의 고정 SHA)
**착수 base: `bd5cd039eaf70f6423cf85e3bf1923bb367fa16e`**

## 되돌리는 법

range revert 가 아니라 **in_scope 경로 한정 복원**이다.

```
git restore --source=838fdb1b --staged --worktree -- <아래 목록의 경로들>
```

목록은 손으로 적지 않는다 — `git diff --name-only 838fdb1b..<HEAD>` 가 **기계로 낸다**.
라운드마다 재산출하므로 이 파일에 경로를 베껴 적지 않는다(베껴 적으면 다음 라운드에 갈린다).

## 복원 목록의 건전성

| 축 | 결과 |

| 바뀐 경로 | **27**(신설 8 · 수정 19) |
| in_scope 항목 | 24 |
| **in_scope 밖 경로** | **0** — 바뀐 경로 전수가 in_scope 안이다 |
| 음성 대조 | in_scope 밖 경로 하나를 넣으면 **잡힌다** — 빈 등식이 공허하지 않다는 측정이다 |

수정 라운드 1 이 목록을 둘 늘렸다 — 이 파일 자신(신설)과 공유 어휘 게이트의 마운트 자리(수정).

## 공유 파일의 복원 — 셋째 단언과 표지 계수 (머지 차례)

복원 원천은 **고정 SHA `bd5cd039`** 다(움직이는 `origin/main` 을 쓰지 않는다). 이 slice 는 머지
차례에 main 을 병합하지 않았다 — main 이 착수 base 그대로이기 때문이다.

**셋째 단언 (원천이 바뀐 뒤 다시 쟀다)**: 복원 경로 **27** 가운데 두 원천에서 **blob 이 다른
경로는 0** 이다 — 19 는 양쪽에 있고 **해시가 같으며**, 8 은 양쪽에 **둘 다 없다**(이 slice 의
신설이다). 그래서 원천을 착수 base 에서 병합된 main 으로 바꿔도 **되돌림의 뜻이 바뀌지 않는다**.

그 대조의 술어는 **존재 여부를 먼저 가른다** — 없는 경로에서 해시를 묻고 그 출력을 값으로 쓰면
「둘 다 없음」이 「다름」으로 읽힌다(처음 잰 판이 그 꼴이었고, 신설 여덟이 전부 거짓 양성이었다).

main 병합은 **충돌 0** 이었고, 그 chore 가 만진 경로(컨테이너 빌드·취약점 허용 목록·그 chore 의
evidence)와 이 slice 의 복원 경로는 **교집합 0** 이다(기계 확인).

**「내 표지 0 · 남의 표지 보존」은 어휘 grep 이 아니라 항목 집합으로** 셌다 — capability map 의
하위 절 글자다.

| 축 | 복원 뒤 |
| --- | --- |
| 내 표지 `(t)` | **0** |
| 남의 표지 `(p)`·`(q)`·`(r)`·`(s)` | 각각 **1** |
| 하위 절 총수 | **19**(등재 전의 수) |

## 실측 뒤에 움직인 것 (verifier 가 대조할 자리)

실측 HEAD 와 판정 SHA 는 **언제나 다르다**(evidence 커밋이 뒤에 온다). 봐야 하는 것은 그 사이에
**되돌림 대상이 움직였는가**다.

> 실측 HEAD 이후 복원 대상 가운데 움직인 경로는 **전부 원천(base `bd5cd039`)에 없는 신설
> 파일**이다.

열거와 원천 부재 확인은 verifier 가 한다(이 파일은 전칭식만 든다). 그 경로들은 이 slice 의
evidence 파일이고, base 에 없으므로 복원은 그것들을 **지우는** 쪽이라 되돌림의 뜻이 바뀌지 않는다.
병합 커밋은 이 range 에 없다.

## 머지 뒤·머지 차례의 복원 원천

이 파일의 실측은 **머지 전** 기준이다. 머지 차례가 오면 복원 원천이 **그 시점에 병합된 main 의
고정 SHA**가 되고(움직이는 `origin/main` 을 쓰지 않는다), 그때 **셋째 단언**을 다시 재야 한다 —
복원 대상 blob 이 착수 base 와 새 원천에서 같은가. 다르면 새 원천 기준으로 ①~⑥ 을 다시 센다.

공유 자리(여정 등록부·fixture·게이트 등록부·캡처 도구·여정 공유 모듈·게이트 스크립트)는 다른
레인도 만지므로 그 재측정이 형식이 아니다. 머지 뒤에 되돌릴 일이 생기면 **PR revert** 가 경로다.
