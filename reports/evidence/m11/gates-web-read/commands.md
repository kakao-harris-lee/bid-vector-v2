# M11 / gates-web-read — 명령과 실측

실행 자리는 `web/`(명시가 없으면)이고 base 는 `94ee445b50cafa669af435e651d811cc551c67e8` 다.

## 착수 실측

**(7) 타입 단언 규칙 — 오늘 위반 0 인가.** 규칙
(`@typescript-eslint/consistent-type-assertions`, `assertionStyle: 'as'` ·
`objectLiteralTypeAssertions: 'never'`)을 `ESLint` 의 `overrideConfig` 로 `src/**` 에 얹어
합성 탐침과 저장소 전수를 함께 쟀다.

| 입력 | 매치 |
| --- | --- |
| `src/**/*.ts(x)` 전수 (저장소 오늘) | **0** |
| `{…} as const satisfies Record<…>` — 오늘의 표 꼴 | **0** |
| `[…] as const` | **0** |
| `{…} as Record<…>` — 이 항목이 막으려는 꼴 | **1** (`unexpectedObjectTypeAssertion`) |
| `<string>"a"` — 각괄호 꼴 | **1** (`as`) |
| `"a" as string` — 객체 리터럴이 아닌 단언 | **0** |
| `{…} satisfies T` | **0** |

즉 규칙은 **오늘의 표를 하나도 붉히지 않으면서** 그 표를 단언으로 바꿔치우는 꼴만 든다.
`as const` 가 면제라는 것이 이 항목이 서는 전제이고, 그것을 추측이 아니라 돌려서 쟀다.

**⑩ 데이터 파일 처방 — 오탐과 참 양성.** `git ls-files web` 추적 파일 **138** 가운데 AST 대상이
아닌 **데이터 파일 11** 에 처방(본문에서 `#` 로 시작하는 줄 제외 → allowlist 값 차감 → 단어 토큰)을
적용했다.

| 대상 | 매치 |
| --- | --- |
| 데이터 파일 11 전수 (처방 그대로) | **0** — 오탐 없음 |
| 같은 전수에서 `#` 줄 제외만 뺌 | **1** — 등록부의 주석 산문 한 줄 |
| P6 확장자 단독 값 | **1** |
| P7 별표 glob | **1** |
| P7b 중괄호 glob | **2** |
| P7c 확장자 목록 값 | **2** |
| 기존에 이미 들던 `이름.kt` 꼴 | **1** (회귀 없음) |

verifier r6 의 수치가 이 트리에서 그대로 선다.

**⑤ 런타임 층 — 원형이 서는가.** vitest setup 에서 읽기 API 를 감싸 **해석된 실경로**가 Kotlin
확장자(대소문자 무시)면 호출자를 보고, 소유 모듈이 아니면 던지는 원형을 세워 쟀다.

| 입력 | 결과 |
| --- | --- |
| 소유 모듈의 읽기 (`readKotlinSource('basis')`) | **통과** |
| 소비자가 절대 경로로 직접 읽기 | **던진다** |
| 별칭 import(`import { readFileSync as x } from 'fs'`) | **던진다** |
| 심볼릭 링크(`…/policy-source.txt` → Kotlin 원문) — ⑧ | **던진다** |

비용: 전건 **16.45s → 18.97s**(원형 기준). 통제군(같은 트리, 층 없음)과 같은 실행 수다.

**⑤ 가 ⑩ 을 덮는가**(팀장 지시 (3)). 데이터 파일이 **별표 glob** 을 들고 코드에는 확장자 토큰이
0 인 모듈 하나를 두고 **프로세스만 바꿔** 쟀다.

| 자리 | 결과 |

남는 꼴이 있으므로 처방을 더한다. 층을 **fs 표면 전부**로 넓힌 판으로 전건을 다시 돌려 **913
passed · 오탐 0**, 소요 **10.16s** 였고 같은 장비에서 **등 맞댄 통제군**(층 없음)이 **10.29s**
였다 — 비용은 측정 잡음 안이다. 위에 적은 16.45s 는 다른 프로젝트의 빌드가 같이 돌던 때의
값이라 비교 대상이 아니다.

**(7) 의 잔여 꼴.** 같은 자리에서 함께 쟀다.

| 입력 | 매치 |
| --- | --- |
| 변수를 거친 단언(`const raw = {…}; raw as T`) | **0** — 지나간다 |
| `{…} as unknown as T` | **0** — 지나간다(규칙이 `unknown`·`any` 를 면제한다) |
| 함수 반환 자리의 객체 리터럴 단언 | **1** |
| 타입 주석(`const X: T = {…}`) — 전수성이 유지되는 꼴 | **0** (음성 대조) |
| `eslint-disable-next-line` 한 줄 | **0** — 꺼진다 |
| 규칙을 `e2e/**`·`scripts/**`·뿌리 설정까지 넓혔을 때 오늘 위반 | 각각 **0** |

추적 파일의 `eslint-disable` 주석은 오늘 **0** 건이다.

**⑥ 모집단 — 한 홉인가.** 오늘의 모집단 수집은 변수 수집이 `readKotlinSource(…)` 를 **초기화식
그 자체**로 가진 선언만 담고, 인자 판정이 호출의 **최상위 인자**만 본다. 즉 두 홉 이상·별칭·
`.trim()`·spread·콜백은 모집단 밖이다 — 구현을 읽어 확인했고 `design-review.md`(M10) §4 (3)
미달 ⑥ 의 실측과 같다. **⑤ 층은 이 축에 닿지 않는다**(여는 호출이 그 사이에 없다).

모집단에 끌려 들어왔다 ② 소유 모듈의 선언을 검사 대상에 두면 **단언 함수 자신에게 자기를
부르라고 요구**한다 — 그래서 검사에서 소유 모듈을 뺀다.

## 변이 실측 — 축별

변이는 **바꿔치우기**다(커밋 뒤 심고, 잰 뒤 되돌린다). 각 축의 게이트 test 를 돌린 수다.

### ⑤ 「여는 행위」 층 (8 자리)

| 변이 | 결과 |
| --- | --- |
| `vite.config.ts` 의 setup 등재를 지움 | **3 failed** — 배선 자체가 측정된다 |
| 감싸기를 읽기 하나로 좁힘 | **1 failed** — promise 표면·`openSync`·스트림이 함께 든다 |
| 실경로 해석을 **적힌 경로**로 바꿔치움 | **2 failed** — 링크(⑧)와 glob 둘이 함께 |
| 확장자 술어를 **대소문자 구분**으로 | **1 failed** — ⑨ |
| 소유 모듈 비교를 지움(일률 허용) | **3 failed** |

**설계 교정 둘이 실측에서 나왔다.**
- **해석되지 않는 경로는 대상이 아니다.** 적힌 글자를 그대로 믿던 첫 판은 glob **패턴**
  (`…/*` + 확장자)을 거부했다 — 패턴은 열리는 파일이 아니고, 그것을 막는 것은 이 층이 버린
  **표기 술어로의 회귀**다. 막는 자리는 찾은 것을 **여는** 순간이다(그 꼴을 test 가 든다).
- **링크를 만드는 호출도 거부된다.** `fs` 표면 전수를 감싸므로 Kotlin 원문을 가리키는 링크 **생성**
  이 막힌다. 넓은 쪽으로 고른 범위이고 알려진 제한에 등재한다 — 그래서 ⑧ 탐침의 준비는 층 밖
  (`ln`)에서 한다.

| 변이 | 결과 |
| --- | --- |
| `#` 줄 제외를 지움 | **2 failed** — 등록부 주석의 산문이 오탐이 된다 |

### (7) 타입 단언 규칙 (10 자리)

| 변이 | 결과 |
| --- | --- |
| `objectLiteralTypeAssertions` 를 뺌 | **2 failed** |
| 대상을 `src` 로 되돌림 | **1 failed** — `e2e`·뿌리 설정 자리 |
| **함정 재현 ⓐ** — 끝 블록에서 심각도만 다시 준다 | **초록** — 아래 정정 |
| **함정 재현 ⓑ** — 끝 블록에서 **옵션을 바꿔 끼운다** | **2 failed**(내 대조) · 기존 lint 게이트 **8 failed** |

**등재된 flat config 함정의 조건을 정정한다.** 「블록을 더하면 앞 블록의 같은 규칙 옵션이
사라진다」는 **뒤 블록이 옵션을 줄 때만** 참이다 — 심각도만 주면 ESLint 가 **앞의 옵션을
보존한다**(ⓐ 가 그 실측이다). 그리고 이 항목의 블록은 기존 금지 블록들보다 **앞**에 있어 구조적으로
그것들을 덮어쓸 수 없다(ⓐ 가 초록인 둘째 이유). 두 사실 때문에 「기존 금지가 여전히 선다」 대조가
공허해 보일 수 있으므로 **ⓑ 로 이가 있음을 쟀다**.

## 하네스가 아니라 이 레인이 밟은 자리 둘

- **추적되기 전의 신설 파일은 게이트 밖이다.** 소유권 훑기가 `git ls-files` 전수라, `git add` 전에
  돌린 전건은 신설 파일을 **보지 않는다** — 그 초록은 거짓이었다(커밋 뒤 두 위반이 드러났다).
  이 레인은 그 뒤로 **staging 뒤에** 전건을 돈다.
- **식별자도 경로 토큰 술어의 대상이다.** 지역 변수 이름을 확장자 두 글자로 두면 그 이름 자체가
  위반이다 — 이름을 `extension` 으로 고쳤다.

## acceptance (전건)
