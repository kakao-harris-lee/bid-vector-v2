# M11 / gates-web-read — 설계 검토 (Phase 2.5)

두 축이다. **A** 는 Kotlin 원문 읽기 게이트의 잔여 다섯(⑤⑥⑧⑨⑩), **B** 는 타입 단언 규칙(7).
M10/10D 가 r0~r7 동안 꼴을 하나씩 열거한 자리라, 경계를 **먼저** 고정하고 각 우회를 그 경계로
가른다.

## (0) 위협 모델 경계 — 계약이 고정한 문장

계약(`milestone-11.md` 「11D 위협 모델 경계」)을 그대로 쓴다. **방어하는 것**: web test·스크립트가
**평범한 관용구로** Kotlin 원문을 읽게 되는 표류(경로 문자열·glob·데이터 파일·심볼릭 링크·대소문자).
**방어하지 않는 것**: 게이트를 알고 **의도적으로 숨기는** 저자(런타임 경로 조립·난독화, 게이트 파일·
vitest setup·eslint 설정 자체를 고치는 것). 경계 밖은 **등재로 답하고 수정 라운드를 열지 않는다.**

### 층이 둘이고 덮는 집합이 다르다 — 실측

| 층 | 무엇을 보는가 | 덮는 집합 |
| --- | --- | --- |
| **런타임**(⑤ — vitest setup 에서 fs 표면을 감싼다) | **여는 행위**. 표기를 보지 않고 **해석된 실경로**를 본다 | **vitest 프로세스 안**에서 일어나는 모든 열기 |
| **정적**(AST 토큰 · 데이터 파일 토큰) | **적힌 토큰**. 프로세스를 가리지 않는다 | **추적 파일 전수** |

둘은 포함 관계가 아니다. 같은 모듈을 프로세스만 바꿔 돌려 쟀다 — vitest 안에서는 던지고
`node` 로 직접 돌리면 **읽힌다**(`commands.md` 「⑤ 가 ⑩ 을 덮는가」). 여정 하네스가 실제로 그
자리에 있으므로(playwright globalSetup 이 Kotlin 정본을 읽는다) **vitest 밖은 가정이 아니라
실재**다. 그래서 ⑩ 은 ⑤ 로 갈음하지 않고 **정적 처방을 더한다**.

## (1) 열거인가 구성인가

**A — 구성이다.** 세 축 전부 「꼴을 적는」 자리를 없앴다.

| 축 | 열거였다면 | 이 판 |
| --- | --- | --- |
| 어느 API 로 여는가 | 읽기 함수 목록(`readFileSync`·`readFile`·`createReadStream`·`open`…) | `fs`·`fs.promises` 의 **함수 값 속성 전수**를 감싼다. 읽기/쓰기를 가르지 않는다 — 그 분류가 곧 목록이다 |
| 무엇을 여는가 | 경로 표기(끝 판정·`/` 요구·glob 꼴·대소문자) | **해석된 실경로**의 확장자. 표기가 사라지므로 ⑧(링크)·⑨(대소문자)가 함께 사라진다 |
| 누가 여는가 | 허용 파일 목록 | **소유 모듈 한 자리**와의 동일성(호출 프레임) |

**B — 규칙 하나다.** `objectLiteralTypeAssertions: 'never'` 는 꼴 목록이 아니라 「객체 리터럴에
단언을 붙이지 않는다」는 성질이다. 열거가 남는 자리는 **규칙이 서는 파일 집합**이고, 그것은
오늘 0 위반이므로 넓혀서 줄인다(§(3) 과잉 참조).

## (2) 우회 — 경계 안인가 밖인가

경계 안은 **닫고**, 경계 밖은 **등재**한다. 되돌리면 무엇이 RED 인지 함께 적는다(수치는 구현 뒤
`commands.md` 「변이 실측」).

| # | 우회 | 분류 | 무엇이 받는가 |
| --- | --- | --- | --- |
| 1 | 소비자가 자기 `readFileSync` 로 `.kt` 를 연다 | **닫음(런타임+정적)** | 호출자 동일성에서 던지고, 경로 토큰이 AST 술어에 선다 |
| 2 | **읽기 API 를 바꾼다** — `fs/promises`·`createReadStream`·`openSync`·`globSync` | **닫음(런타임)** | 표면 전수를 감싸므로 API 선택이 술어 밖이다 |
| 3 | **심볼릭 링크**가 Kotlin 원문을 가리킨다(⑧) | **닫음(런타임)** | 실경로를 보므로 링크의 확장자가 무의미하다 |
| 4 | **대소문자**(`.KT` · `i` 플래그)(⑨) | **닫음(런타임)** | 실경로 확장자를 대소문자 무시로 본다 |
| 5 | **데이터 파일**의 확장자 단독 값·별표/중괄호 glob(⑩) | **닫음(두 층)** | vitest 안은 런타임이, 그 밖은 `#` 줄 제외 + allowlist 차감 + 단어 토큰이 받는다 |
| 6 | **vitest 밖 프로세스**에서 연다(playwright spec·여정 하네스·게이트 스크립트) | **부분** | 런타임 층이 없다. **정적 층만** 받는다 — §(3) 미달 Ⅰ 로 등재 |
| 7 | `child_process` 로 읽는다(`execSync('cat …')`) | **닫음(정적)** | 셸 문자열도 AST 리터럴이라 경로 토큰이 선다 |
| 8 | `vite.config.ts` 평가 시점에 읽는다(setup 보다 앞) | **닫음(정적)** | 그 파일도 추적 AST 파일이라 토큰이 선다 |
| 9 | `vi.mock('node:fs')` · setup 에서 층을 뺀다 | **경계 밖(등재)** | 게이트 설정 자체를 고치는 것이다. 층 부재는 그 층의 양성 대조가 RED 로 만든다 |
| 10 | `Error.prepareStackTrace` 를 바꿔 호출자를 속인다 · 글자 단위 조립 | **경계 밖(등재)** | 의도적 은닉. 리뷰 소관(M10 미달 ① 승계) |
| 11 | **단언보다 뒤**에 사본을 덧씌운다 | **경계 밖(이월)** | M10 미달 ② 의 「단언 뒤」 칸. 「단언 **앞** · 줄 안 끊는 사본」 칸은 r2 의 동일성이 닫았다(실측) |
| 11b | 추출 **커널**을 직접 불러 단언을 건너뛴다 — r2 신설 | **닫음(import 그래프)** | 커널 참조자를 소유 파일과 그 단위 test 둘로 고정한다. 별칭·재수출·동적 import 가 전부 RED(변이 넷) |
| 11c | 단언을 **아예 부르지 않는** 새 추출 함수 | **등재 후보** | 두 홉으로 값을 받으면 모집단 등식도 조용하다(실측) |
| 12 | **(7)** 표를 `{…} as Record<…>` 선언으로 바꾼다 | **닫음(lint)** | 규칙이 객체 리터럴 단언을 든다(오늘 0 → 심으면 1) |
| 13 | **(7)** 변수를 거쳐 단언한다(`const raw = {…}; raw as T`) | **부분 — 미달 Ⅲ** | 규칙 밖이다(실측 0). 닫으려면 타입 정보가 필요하다 |
| 14 | **(7)** `{…} as unknown as T` | **부분 — 미달 Ⅲ** | 규칙이 `unknown`·`any` 를 면제한다(실측 0) |
| 15 | **(7)** 표를 `src/` 밖으로 옮긴다 | **닫음(범위)** | 규칙을 `e2e/**/*.ts`·뿌리 `*.ts` 까지 넓힌다(오늘 셋 다 0 위반) |

| 18 | 새 게이트 test 를 등록부에서 뺀다 | **닫음** | `gate:tests`(W-7)가 등록부 전수를 실행 결과로 단언한다 |

## (3) 과잉·미달

**과잉이 될 수 있는 것 — fs 표면 전부.** 읽기만 감싸면 충분해 보이지만, 읽기/쓰기를 가르는 순간
그 분류가 목록이 되고 목록 밖이 다음 라운드의 우회가 된다(M10 이 네 라운드 연속 그 자리였다).
전수를 감싸는 비용은 **쟀다** — 전건 913 passed · 오탐 0 · 소요 10.16s 로 등 맞댄 통제군 10.29s
와 잡음 안이다. 비용이 없으므로 넓은 쪽을 고른다. 다만 **저장소 밖 경로와 `node_modules` 아래는
실경로 해석을 건너뛴다** — 그 둘은 Kotlin 정본이 살 수 없는 자리이고, 건너뛰지 않으면 모든
모듈 적재가 실경로 호출을 탄다.

**과잉이 될 수 있는 것 — (7) 의 범위.** 계약 문면은 `src/**` 다. `e2e/**/*.ts` 와 뿌리 `*.ts` 까지
넓히면 우회 15 가 닫히고 **오늘 위반은 셋 다 0** 이라 값이 공짜다. `.mjs` 는 타입 단언이 없는
문법이라 넓혀도 공허하다 — 넓히지 않는다. **범위 판정은 팀장 소관이라 보고 뒤에 정한다.**

**미달 Ⅰ — 런타임 층은 vitest 프로세스 안이다.** playwright spec·여정 하네스·`node` 게이트
스크립트에는 층이 없다(실측). 그 자리는 정적 층만 받고, 정적 층이 **추적 파일 전수**라 새 파일도
자동으로 든다 — 다만 데이터 파일에서 읽은 경로를 셸로 넘기는 겹친 꼴은 두 층 모두 밖이다.
층을 그 프로세스들까지 넓히는 길(진입점마다 `--import`)은 **진입점 열거**라 고르지 않았다.

**미달 Ⅱ — ⑥ 은 (c) 로 닫혔고, 남는 것은 하나다**(r2 — 팀장 판정 (c)·(ㄱ)). ⑤ 는 *여는 행위*를,
⑥ 은 *이미 읽힌 텍스트의 흐름*을 본다 — 1안의 런타임 층은 그 사이를 보지 못한다. 그래서 기준을
**내준 텍스트와의 동일성**으로 올렸고, 손댄 텍스트는 ⑥ 이 열거하던 다섯 꼴 **전부**에서 같은
자리에서 던진다(실측). 꼴이 답을 바꾸지 않으므로 **그 축에서 꼴을 세는 일이 끝난다**.

**남는 하나**: 단언을 **아예 부르지 않는** 새 추출 함수. 모집단 등식은 그것을 **직접 인자** 꼴에서는
보고(1 failed) **두 홉** 꼴에서는 보지 못한다(27 passed) — 둘 다 변이로 쟀다. **등재 후보로
보고한다**(판정은 팀장).

**(c) 의 대가와 그 처분**: 동일성은 합성 Kotlin 조각을 「내주지 않은 텍스트」로 보므로, 추출 술어의
양성·음성 대조가 공개 입구에서 **술어가 돌기 전에** 거부됐다(열세 자리). (ㄱ) 이 술어를 재는 자리
(커널)와 출처를 재는 자리(입구)를 **다른 함수**로 갈라 둘을 함께 세운다. 그 분리가 만드는 새 입구는
위 (2b) 의 import 그래프 술어가 진다 — **그 술어가 없으면 ⑥ 이 그 자리에서 다시 열린다.**

**미달 Ⅰb — 층은 「여는 행위」이고 표기를 보지 않는다 — 그래서 열리지 않는 것도 보지 않는다**
(r3 실측). 해석되지 않는 경로를 거부하던 첫 판은 glob **패턴**을 막았는데, 그것은 이 층이 버린
표기 술어로의 회귀다. 지금은 **존재하는 파일의 실경로**만 본다 — 패턴·없는 경로는 아무것도 열지
않고, 그 꼴을 받는 것은 데이터 파일 쪽 정적 술어다. 반대로 `fs` 표면 전수를 감싼 대가로 Kotlin
원문을 가리키는 링크를 **만드는** 호출도 거부된다(넓은 쪽으로 고른 범위 · 알려진 제한).

**미달 Ⅲ — (7) 은 「직접 붙인 단언」까지다.** 변수를 거친 단언과 `as unknown as` 는 규칙 밖이다
(각각 실측 0). 닫으려면 타입 서비스(`projectService`)를 켜야 하고 그것은 lint 레인 전체의 비용
축이라 이 slice 의 판단이 아니다. **그래서 게이트의 주장을 그만큼 낮춰 적는다** — 막는 것은
「표 선언에 단언을 **직접** 붙이는 꼴」이다.
