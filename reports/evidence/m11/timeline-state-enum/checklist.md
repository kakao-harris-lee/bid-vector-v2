아니라 **등식의 넷째 자리**로 닫았다. 그래서 계약 안 상태 어휘 사본 **다섯이 전부** 등식 아래에
있다(넷은 이 slice 의 등식, 하나는 대사 쪽의 기존 등식).

## 2. 게이트의 힘 — 무엇이 RED 를 만드는가

변이는 **바꿔치우기**다. 적용 단언과 종료 코드는 `commands.md` 에 있다.

| 축 | 바꿔치우기 변이 | 받는 층 |
| --- | --- | --- |
| 계약 ↔ Kotlin (도착) | 도착 칸 어휘의 한 값을 바꿔치움(생성 타입도 재생성 — 바이트 등식은 초록) | 계약 test **그리고** W-3(표 키 등식 둘) |
| 계약 ↔ Kotlin (건 상태) | 건 상태 칸 어휘의 한 값을 바꿔치움 + 재생성 | 계약 test(D-11B-2 가 더한 단언) **그리고** W-3(표가 그 칸에서 유도된다) |
| 계약 ↔ Kotlin (목록 질의 탭) | 그 param 어휘의 한 값을 바꿔치움 | 계약 test **뿐** — **요청** 쪽 어휘라 web 표의 유도 경로에 없다 |
| 질의 인자 **탐색** | 그 param 의 이름을 바꿔치움 | 계약 test — 읽기가 빈 어휘를 답으로 내지 않고 **던진다**(그 성질이 없으면 넷째 줄이 공허하게 초록이다) |
| `null` 과 `nullable` 의 결합 ① | 출발 칸 어휘에서 `null` 원소를 걷음 | 계약 test **뿐** — `nullable: true` 가 남아 생성 타입은 `null` 을 그대로 내므로 **web 이 보지 못한다** |
| `null` 과 `nullable` 의 결합 ② | 출발 칸의 `nullable` 선언을 걷음 | 계약 test **뿐** — 어휘가 `null` 을 실어 생성 타입이 바뀌지 않는다 |
| 어휘를 **다시 염** | 도착 칸의 `enum` 을 걷어 `type: string` 으로 + 재생성 | 계약 test(어휘 읽기가 **던진다**) **그리고** W-3(좁음 가드가 `never`) |
| 표시의 한 자리 | 타임라인이 공용 조회 대신 **자기 폴백**(맨 색인 + 코드 원문)으로 되돌아감 | W-6 의 렌더 잠금 **뿐** — W-2·W-3 은 초록이다(좁혀진 유니온의 맨 색인은 합법이다) |
| 전수성의 **출처** | 표 키의 원천 별칭을 **손 유니온으로 바꿔치움** + 계약 어휘를 늘려 재생성 | W-3 — 등식이 **별칭을 거치지 않으므로** drift 를 본다. 별칭만 바꾼 트리는 lint·typecheck 초록이고(음성 대조) 그 상태로는 아무것도 막지 않는다 |

**가운데 두 축(결합 ①②)이 이 slice 가 더한 고유한 방어다.** 두 꼴 모두 생성 타입을 바꾸지 않아
web 전체가 초록이고, 그대로 두면 엄격한 검증기가 **실제로 나가는 `null`** 을 거부하거나 선언이
나르지 않는 값을 어휘가 허용한다.

## 3. 알려진 제한

① **계약 안 어휘 사본을 하나로 모으지 않았다** — 다섯 자리가 전부 등식 아래에 있지만 선언 자체는
여전히 다섯 벌이다. `$ref` 공용 스키마로 모으는 축은 금액 어휘 「하나의 출처」와 같은 부류이고
`milestone-11.md` 가 범위 밖으로 유지했다(scope.md out_scope).
② **조회는 런타임의 자유 문자열을 받는다** — 계약이 어휘를 닫아도 **배포 비틀림**으로 번들이
모르는 값이 닿을 수 있어 표 밖 처리와 그 대조(표 밖 토큰 · 프로토타입 키 다섯)를 유지했다.
③ **거동 변경 하나 — 표 밖 상태의 표시 문면.** 서버가 준 코드 원문 → 「알 수 없는 상태(코드)」.
닿는 경로는 ② 하나뿐이고 **wire 값·API 응답 값은 바뀌지 않는다**(팀장 승인 2026-11-13, D-11B-3).
렌더 층 잠금의 기댓값을 공용 조회에서 끌어오므로 그 단언은 **「두 자리가 같은 문면을 낸다」**를
재고, 화면이 자기 폴백으로 되돌아가면 멈춘다.
④ **「타임라인이 그 자리를 쓴다」는 렌더 층에서만 선다** — 모듈 밖에 자기 조회를 다시 세우는 것을
구조로 막는 층은 없다(명령 축도 같은 자리다). 표 밖 값은 계약이 어휘를 닫은 뒤 **타입으로 만들 수
없으므로** fixture 가 `string` 에서 좁힌다.
⑤ **어휘 읽기 헬퍼의 기존 사본들을 모으지 않았다** — 10B 알려진 제한 ③ 그대로. 또 하나를 만들지
않으려 `null` 축과 **질의 인자 축**을 둘 다 공용 자리에 더했고(질의 인자 읽기의 `private` 사본도
여럿 있다), 기존 사본을 모으는 것은 별 정리다.
⑥ **W-12·W-13 과 `check` job 의 S-20 은 로컬 미실행** — 버릴 Postgres 전제가 이 레인에 없다.
PR CI 가 그 자리다(10B 와 같은 자리, 팀장 승인 2026-11-11).
⑦ **공유 파일 하나를 만졌다** — §12.3 에 **절 하나를 끝에 덧붙였다**(M11 레인 다섯이 각자 덧붙이는
자리). **절 글자는 미정**이고 `(?)` 로 두었다 — 병합 때 그 시점의 다음 글자로 고치고 공유 파일의
합집합을 절 계수로 확인한다(팀장 계약 변경 2026-11-13). 게이트 등록부 둘은 만지지 않았다(새 test
파일·클래스가 0 이다).

## 4. 크기 게이트

**계량은 줄 수**다. 산출물은 `git diff --numstat <원천>..<실측 HEAD> -- . ':!reports/evidence'` 의
**바뀐 줄**(더한 줄 + 지운 줄), evidence 는 세 파일 `wc -l` 이다. 두 수를 `commands.md` 가 그대로
적는다 — 어느 수를 썼는지 적지 않으면 판정이 갈린다(10B cr r0 L-2).
