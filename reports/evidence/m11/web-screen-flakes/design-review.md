# M11 / web-screen-flakes — ① 설계 검토 (게이트, 구현 전)

대상은 `OPEN-M10-SCREEN-COVERAGE-INDIRECT-RENDER` 와 그 잔여 다섯이다. ②(불안정 두 서명)는
게이트 술어를 만들지 않으므로 이 검토의 대상이 아니다.

## (0) 위협 모델 경계

**방어하는 것 — 평범한 관용구의 표류.** 화면 카드가 금액·시각 어휘를 그리면서 DOM 어휘 게이트
(`screenVocabulary.test.tsx`)의 **마운트 목록 밖에 남는** 일. 기준은 「저자가 이 게이트를 의식하지
않고 쓴 React 코드」다 — 파일을 비공개 하위 컴포넌트로 쪼개기, `memo`·`forwardRef` 로 감싸기,
이름을 바꿔 내보내기, 클래스 컴포넌트, 어휘 함수를 콜백으로 **넘기기**, 표시 모듈에 어휘 함수를
새로 더하기. 이 여섯은 전부 **의도 없이** 게이트를 비우는 꼴이고, 그래서 방어 대상이다.

**방어하지 않는 것 — 게이트를 알고 숨기는 저자.** 어휘 이름을 런타임에 조립하기
(`display['instant' + 'DisplayOf']`), 카드를 모집단 디렉터리 밖(`src/components/**`)으로 옮기기,
`screen-card-coverage.mjs`·그 게이트 test·마운트 목록 자체를 고치기. 이것은 **등재로 답하고 수정
라운드를 열지 않는다**. 셋 다 diff 에 남고 리뷰 소관이다.

이 경계 밖 finding 은 수정이 아니라 이 절의 참조로 답한다. 경계를 바꾸려면 팀장 결정으로 이
문서를 개정한다.

## (1) 열거인가 구성인가

앞 판에서 **열거**였던 자리 셋과 이 라운드의 처분.

| 자리 | 앞 판 | 이 라운드 |
| --- | --- | --- |
| 내보내기의 **꼴** | `export` 수식자가 붙은 **함수 선언·화살표 초기값**만 열거 | **구성** — 모듈의 내보낸 **심볼**을 검사기에서 받아 선언으로 간다. 꼴을 묻지 않으므로 `memo`·개명 재수출·클래스가 함께 닫힌다 |
| 어휘에 **닿는 길** | 호출식의 **해소된 시그니처**만 | **구성** — 호출 해소 ∪ 맨 **참조**. 부르지 않고 넘기는 꼴이 같은 술어에 든다 |
| 그리는 **깊이** | 내보낸 선언의 **서브트리** 한 겹 | **구성** — 파일 안 지역 선언 그래프의 **전이 폐포**(고정점). 깊이 상수가 없으므로 「왜 1 인가」라는 매직 넘버가 생기지 않는다 |

여전히 **열거**로 남는 자리 하나와 그것을 받는 장치.

- `VOCABULARY_DECLARATIONS` — 어휘 함수 일곱의 **자리** 목록. 「표시 모듈의 내보낸 함수 전부」로
  구성하는 길은 M9 에서 실측됐고 의무 집합이 5 → 13 이 되며 질의 목이 필요한 패널·훅을 삼킨다.
  그래서 **집합을 넓히지 않고 목록이 뒤처지는 축만** 등식으로 막는다 — 어휘 모듈의 내보낸 함수
  전수 == 등재 ∪ **명시 제외**. 새 함수가 생기면 분류될 때까지 붉다.
- 그 **제외**가 다시 열거다. 그래서 제외마다 종류를 적고, 종류 하나(`INTERNAL_ASSEMBLER` —
  표시층 내부 조립자)에는 **구조 의무**를 함께 건다: `src/screens/**` 의 어느 파일도 그것을
  참조하지 않는다. 화면이 그 함수를 직접 부르기 시작하면 사유가 거짓이 되고 게이트가 붉어진다.

## (2) 우회 — 각각의 처분

앞 판이 이미 닫은 넷(별칭 · 재수출 · 네임스페이스 · 지역 변수)과 셋(선언 목록 썩기 · 마운트 목록에서
빼기 · 하위 디렉터리·`.ts`)은 그대로 둔다. 이 라운드가 받는 것과 남기는 것만 적는다.

1. **간접 렌더** — 내보낸 `Outer` 가 어휘를 부르는 **비공개 `Inner`** 를 그린다.
   → 전이 폐포가 받는다. 오늘 실재하고(`InboxScreen`), **두 겹**이라 한 겹으로는 닫히지 않는다.
2. **감싸 내보내기** — `export const X = memo(…)` · `forwardRef(…)`.
   → 내보낸 심볼 경유라 초기값 꼴을 묻지 않는다. 오늘 실재 0.
3. **개명 재수출** — `function Inner…; export { Inner as Card }`.
   → 같은 심볼 경유. 의무로 나는 이름은 **내보낸 이름**(`Card`)이다 — DOM 게이트가 마운트할 이름이
   그것이기 때문이다. 오늘 실재 0.
4. **클래스 컴포넌트** — `export class Card extends React.Component`.
   → 같은 심볼 경유 + 클래스 본문도 그래프의 노드다. 오늘 실재 0.
5. **함수 참조 전달** — `ats.map(instantDisplayOf)`.
   → 참조 축이 받는다. 오늘 실재 0.
6. **새 어휘 함수** — 표시 모듈에 어휘를 더해 그것만 쓴다.
   → 등재 등식이 받는다(§(1)). 집합을 넓히지 않는다.
7. **지역 그래프의 순환** — `A` 가 `B` 를, `B` 가 `A` 를 참조한다.
   → 고정점 계산에 방문 집합을 둔다. 순환은 React 에서 드물지 않다(상호 재귀 트리).
8. **타입만 내보내기** — `export type Card = …`.
   → 타입 선언은 그래프의 노드가 아니다(함수·클래스·변수만 담는다). 의무를 내지 않는 것이 맞다.
9. **다른 파일에서 재수출** — `export { Card } from '../components/Card'`.
   → **경계 밖**. 선언이 이 파일에 없으므로 폐포가 닿지 않는다. 모집단 **디렉터리** 축이고,
   팀장 결정으로 범위 밖 유지 + 신설 OPEN 등재다(scope.md §신설 OPEN).
10. **런타임 조립** — `display['instant' + 'DisplayOf'](x)`.
    → **경계 밖**(§(0) 「숨기는 저자」). 심볼 해소가 성립하지 않는다.

## (2b) 값 획득 축 — 새 public 표면 전수

이 모듈에 `object` 커널이 없으므로(JS 모듈이다) 축은 「내보낸 표면마다, 그것을 지나지 않고 같은
값을 얻는 길이 있는가」다. **「경계로 처리」 행도 실측한다.**

| 표면 | 새것인가 | 지나지 않고 같은 값을 얻는 길 | 처분 |
| --- | --- | --- | --- |
| `VOCABULARY_DECLARATIONS` | 기존 | — | 그대로 |
| `vocabularyComponentsOf(program, source)` | **의미 변경**(시그니처 동일) | 소비자가 자기 훑기를 쓰는 길 — 이 모듈의 소비자는 게이트 test 하나이고 그 파일이 in_scope 다 | 그대로 |
| `collectScreenVocabulary(webRoot, overlay)` | 기존 | — | 그대로 |
| `VOCABULARY_MODULE_EXCLUSIONS` | **신설** | 제외를 늘려 새 함수를 조용히 통과시키는 길 | **열거이고 diff 에 남는다** — 경계 밖(「게이트 파일 자체를 고치는 저자」). 다만 종류 `INTERNAL_ASSEMBLER` 는 구조 의무가 붙어 사유가 거짓이면 붉다 |
| `vocabularyRegistryGaps(program, webRoot)` → `{unclassified, stale, leaked}` | **신설** | ⓐ 어휘 모듈 **밖**에 새 어휘 함수를 두는 길(`display/newThing.ts`) ⓑ 제외 함수를 화면이 **간접으로** 부르는 길(표시층 다른 함수를 지나) | ⓐ **실측했다** — 오늘 어휘 호출은 `src/screens/**`·`src/display/**` 밖에 0 이고, 새 표시 모듈을 만드는 것은 ①의 축이 아니라 모집단 축이다(위 9 번과 같은 신설 OPEN). ⓑ **의도다** — 표시층 내부에서 조립되는 것이 그 함수의 일이고, 그 조립 결과를 내는 함수(`amountDisplayOf`)는 이미 등재돼 있다 |
| `screenProgram` · `mountedCardsOf` · `missingVocabularyDeclarations` · `screenFilesIn` | 기존 | — | 그대로 |

## (3) 과잉·미달

**미달이었던 자리**: 깊이. 계약 문면의 「한 겹」은 오늘 실재하는 유일한 꼴을 닫지 못한다
(`InboxScreen` → `NotificationGroupBlock` → `NotificationRow`). 팀장 결정으로 전이 폐포로 간다.

**과잉이 아닌 근거 — 집합이 늘지 않는다(TS 실측, 같은 프로그램, 22 파일).**

| 규칙 | 마운트 의무 | 화면 바구니 |
| --- | --- | --- |
| 오늘 | 5 | 1 — WorksheetScreen |
| 한 겹 | 5 | 1 |
| **전이 폐포(채택)** | **5 (불변)** | **2 — + InboxScreen** |

마운트 목록(`GATE_MOUNTED_CARDS`)은 **건드리지 않는다**. 늘어난 하나는 `*Screen` 이라 화면
바구니로 가고, 그 바구니의 조건인 **짝이 되는 test 파일**은 이미 있다(`InboxScreen.test.tsx`).
즉 이 변경은 오늘의 production 코드를 붉히지 않으면서, 게이트가 **그 파일에 대해 아무 말도 하지
않던 상태**를 끝낸다(오늘 `InboxScreen` 은 의무도 화면 바구니도 아니다).

**하지 않는 것**(과잉 금지)

- 의무 집합을 「표시 모듈의 내보낸 함수 전부」로 넓히지 않는다 — M9 실측 5 → 13, 질의 목이 필요한
  패널·훅이 섞인다.
- 파일 **사이**의 그래프를 따라가지 않는다. 그러면 모집단이 `src/**` 전체가 되고, 「마운트할 수
  있는 카드」라는 의무의 뜻이 무너진다.
- 출하 코드를 한 줄도 바꾸지 않는다. 이 게이트는 모집단 판정이고, 판정이 넓어져 붉어지는 자리가
  나오면 그 수정은 **새 결정**이다(계약 「승인 경계」).
- `web/vite.config.ts`·`web/eslint.config.js` 를 건드리지 않는다(11D 와 공유하는 자리).

## 구현 전 RED 로 세울 것

폐포·심볼·참조 세 축마다 **합성 원문 대조**를 둔다(기존 `__probe__` 오버레이 방식 — 합성 파일이
실제 표시 모듈을 import 하므로 대조가 진짜 심볼 그래프를 지난다).

| RED | 기대 |
| --- | --- |
| 두 겹 간접 렌더(`Outer` → `Middle` → `Inner` → 어휘) | `['Outer']` — 앞 판은 `[]` |
| `memo(…)` 로 감싼 내보내기 | 그 이름 |
| `export { Inner as Card }` | `['Card']`(내보낸 이름) |
| 클래스 컴포넌트 | 그 이름 |
| `map(instantDisplayOf)` 로 **넘기기** | 그 이름 |
| 순환 참조 | 던지지 않고 유한하게 끝난다 |
| 어휘를 안 쓰는 비공개 컴포넌트를 그리는 내보내기 | `[]`(음성 대조) |
| 비공개 컴포넌트 **자신**은 이름에 없다 | 의무는 내보낸 이름뿐(음성 대조) |
| 어휘 모듈에 분류 안 된 내보낸 함수 하나 | `unclassified` 가 그것을 낸다 |
| 제외 목록에 **이제 없는 함수**가 남아 있다 | `stale` 이 그것을 낸다 |
| `INTERNAL_ASSEMBLER` 제외를 화면이 직접 참조 | `leaked` 이 그것을 낸다 |
