# M11 / web-screen-flakes — ① 설계 검토 (게이트, 구현 전)

대상은 `OPEN-M10-SCREEN-COVERAGE-INDIRECT-RENDER` 와 그 잔여 다섯이다. ②(불안정 두 서명)는
게이트 술어를 만들지 않으므로 이 검토의 대상이 아니다.

## (0) 위협 모델 경계

**방어하는 것 — 평범한 관용구의 표류.** 화면 카드가 금액·시각 어휘를 그리면서 DOM 어휘 게이트
(`screenVocabulary.test.tsx`)의 **마운트 목록 밖에 남는** 일. 기준은 「저자가 이 게이트를 의식하지
않고 쓴 React 코드」다 — 파일을 비공개 하위 컴포넌트로 쪼개기, `memo`·`forwardRef` 로 감싸기
(기본 내보내기 포함), 이름을 바꿔 내보내기, 클래스 컴포넌트, 어휘 함수를 콜백으로 **넘기기**,
**어휘 모듈 셋**에 어휘 함수를 새로 더하기. 이 여섯은 전부 **의도 없이** 게이트를 비우는 꼴이고,
그래서 방어 대상이다.

**r1 F1 정정** — 앞 판은 마지막 줄을 「표시 **모듈**에 더하기」로 적었는데 등식의 모집단은 어휘
모듈 **셋**이고 `src/display/` 는 **열넷**이다. 나머지 열하나를 지나는 축은 닫지 않고 경계 등재
했다(`OPEN-M11-SCREEN-COVERAGE-CROSS-FILE-VOCAB`) — **오늘 실례가 하나 있다**(§(2) 6 번).

**방어하지 않는 것 — 게이트를 알고 숨기는 저자.** 어휘 이름을 런타임에 조립하기
(`display['instant' + 'DisplayOf']`), 카드를 모집단 디렉터리 밖(`src/components/**`)으로 옮기기,
`screen-card-coverage.mjs`·그 게이트 test·마운트 목록 자체를 고치기. 이것은 **등재로 답하고 수정
라운드를 열지 않는다**. 셋 다 diff 에 남고 리뷰 소관이다.

이 경계 밖 finding 은 수정이 아니라 이 절의 참조로 답한다. 경계를 바꾸려면 팀장 결정으로 이
문서를 개정한다.

## (1) 열거인가 구성인가

앞 판에서 **열거**였던 자리 셋과 이 라운드의 처분.

| 자리 | 앞 판 | 이 라운드 |
| --- | --- | --- |
| 내보내기의 **꼴** | `export` 수식자가 붙은 **함수 선언·화살표 초기값**만 열거 | **구성** — 모듈의 내보낸 **심볼**을 검사기에서 받아 선언으로 간다. 꼴을 묻지 않으므로 `memo`·개명 재수출·클래스가 함께 닫힌다 |
| 어휘에 **닿는 길** | 호출식의 **해소된 시그니처**만 | **구성** — 호출 해소 ∪ 맨 **참조**. 부르지 않고 넘기는 꼴이 같은 술어에 든다 |
| 그리는 **깊이** | 내보낸 선언의 **서브트리** 한 겹 | **구성** — 파일 안 지역 선언 그래프의 **전이 폐포**(고정점). 깊이 상수가 없으므로 「왜 1 인가」라는 매직 넘버가 생기지 않는다 |

여전히 **열거**로 남는 자리 하나와 그것을 받는 장치.

- `VOCABULARY_DECLARATIONS` — 어휘 함수 일곱의 **자리** 목록. 「표시 모듈의 내보낸 함수 전부」로
  구성하는 길은 M9 에서 실측됐고 의무 집합이 5 → 13 이 되며 질의 목이 필요한 패널·훅을 삼킨다.
  그래서 **집합을 넓히지 않고 목록이 뒤처지는 축만** 등식으로 막는다 — 어휘 모듈의 내보낸 함수
  전수 == 등재 ∪ **명시 제외**. 새 함수가 생기면 분류될 때까지 붉다.
  **그 등식의 모집단은 어휘 모듈 셋이다**(r1 F1) — `src/display/` 의 열넷 가운데 셋이고, 나머지
  열하나는 등식 밖이다. 그 축은 경계 등재다(§(2) 6 번).
- 그 **제외**가 다시 열거다. 그래서 제외마다 종류를 적고, 종류 하나(`INTERNAL_ASSEMBLER` —
  표시층 내부 조립자)에는 **구조 의무**를 함께 건다: `src/screens/**` 의 어느 파일도 그것을
  참조하지 않는다. 화면이 그 함수를 직접 부르기 시작하면 사유가 거짓이 되고 게이트가 붉어진다.

## (2) 우회 — 각각의 처분

앞 판이 닫은 일곱(별칭·재수출·네임스페이스·지역 변수 · 선언 목록 썩기 · 마운트 목록에서 빼기 ·
하위 디렉터리와 `.ts`)은 그대로다. 이 라운드가 받는 것과 남기는 것만 적는다.

1. **간접 렌더** — 내보낸 `Outer` 가 어휘를 부르는 **비공개 `Inner`** 를 그린다.
   → 전이 폐포가 받는다. 오늘 실재하고(`InboxScreen`), **두 겹**이라 한 겹으로는 닫히지 않는다.
2. **감싸 내보내기** — `export const X = memo(…)`·`forwardRef(…)`, 그리고 **기본 내보내기**
   (`export default memo(Card)` · 이름 없는 함수 · 화살표 — r1 F2).
   → 내보낸 심볼 경유라 초기값 꼴을 묻지 않는다. 기본 내보내기는 파일당 하나라 `#default` 로
   자리를 준다. 오늘 실재 0.
3. **개명 재수출** — `function Inner…; export { Inner as Card }`.
   → 같은 심볼 경유. 의무로 나는 이름은 **내보낸 이름**이다(DOM 게이트가 마운트할 이름). 실재 0.
4. **클래스 컴포넌트** → 같은 심볼 경유 + 클래스 본문도 그래프의 노드다. 실재 0.
5. **함수 참조 전달** — `ats.map(instantDisplayOf)`, 최상위 구조분해 뒤 넘기기, 리터럴 원소
   접근으로 넘기기(r1 F3).
   → 참조 축이 받는다. 구조분해 바인딩이 그래프의 노드이고, 원소 접근은 **리터럴 키일 때만**
   참조다(계산된 키는 경계 밖). 실재 0.
6. **새 어휘 함수** — 표시 모듈에 어휘를 더해 그것만 쓴다.
   → **반만 닫힌다.** 어휘 모듈 **셋** 안에 더하는 꼴은 등재 등식이 받는다(§(1)). 나머지 표시
   모듈 **열하나**에 어휘를 감싼 함수를 더하는 꼴은 등식의 모집단 밖이고 의무 집합도 그것을 보지
   못한다 — **경계 등재**(`OPEN-M11-SCREEN-COVERAGE-CROSS-FILE-VOCAB`).
   **오늘 실례가 하나다**: `editSessionDisplay` 의 비공개 `budgetView` 가 `amountQualifierTextOf`
   (등재)와 `amountTextOf`(제외)로 금액 글자를 만들고, 그 글자가 `STRATEGY_FIELD_VALUE` 를 지나
   `screens/strategyEdit.tsx` 에 그려진다. 그 화면 파일은 의무도 화면 바구니도 아니다.
   닫는 길(어휘 도달을 `src/display/**` 안에서 파일 사이 폐포로 넓히기)의 비용은 실측했다 —
   표시 키 **+2**(`budgetView`·`STRATEGY_FIELD_VALUE`), 의무 **+2**(`StrategyFieldRow`·
   `StrategyEditPanel`). 늘어난 둘이 **마운트 목록 밖**이라 오늘의 production 을 붉히고, 그래서
   계약 「승인 경계」의 새 결정이다(팀장 판정 2026-11-13: 경계 등재로 간다).
7. **지역 그래프의 순환** → 고정점에 방문 집합을 둔다(상호 재귀 트리는 드물지 않다).
8. **타입만 내보내기** → 타입 선언은 그래프의 노드가 아니다. 의무를 내지 않는 것이 맞다.
9. **다른 파일에서 재수출**·**표시 모듈 경유**(§6) → **경계 밖**. 선언이 이 파일에 없어 폐포가
   닿지 않는다. 디렉터리 축과 표시 모듈 축 각각 신설 OPEN 이다.
10. **런타임 조립**(`display['instant' + 'DisplayOf']`) → **경계 밖**(§(0)). 심볼 해소가 서지
    않는다 — 계산된 원소 접근을 참조로 보지 않는 것이 같은 선이다.

## (2b) 값 획득 축 — 새 public 표면 전수

이 모듈에 `object` 커널이 없으므로(JS 모듈이다) 축은 「내보낸 표면마다, 그것을 지나지 않고 같은
값을 얻는 길이 있는가」다. **「경계로 처리」 행도 실측한다.**

기존 표면 넷(`VOCABULARY_DECLARATIONS` · `screenProgram` · `mountedCardsOf` ·
`missingVocabularyDeclarations` · `screenFilesIn` · `collectScreenVocabulary`)은 그대로다.

| 표면 | 새것인가 | 지나지 않고 같은 값을 얻는 길 | 처분 |
| --- | --- | --- | --- |
| `vocabularyComponentsOf(program, source)` | **의미 변경**(시그니처 동일) | 소비자가 자기 훑기를 쓰는 길 — 소비자는 게이트 test 하나이고 그 파일이 in_scope 다 | 그대로 |
| `INTERNAL_ASSEMBLER`·`OTHER_AXIS` | **신설**(제외 종류) | 종류를 새로 만들어 구조 의무를 피하는 길 | 열거이고 diff 에 남는다 — 게이트 test 가 종류를 두 값으로 **소진 단언**한다 |
| `VOCABULARY_MODULE_EXCLUSIONS` | **신설** | 제외를 늘려 새 함수를 조용히 통과시키는 길 | **열거이고 diff 에 남는다** — 경계 밖(「게이트 파일 자체를 고치는 저자」). 다만 종류 `INTERNAL_ASSEMBLER` 는 구조 의무가 붙어 사유가 거짓이면 붉다 |
| `vocabularyRegistryGaps(program, webRoot)` → `{unclassified, stale, leaked}` | **신설**(r1 cr F-1 로 판정이 **꼴 열거 → 타입의 호출 시그니처**가 됐다) | ⓐ 어휘 모듈 **밖**(`src/display/` 의 나머지 열하나 · 새 표시 모듈)에 어휘를 감싼 함수를 두는 길 ⓑ 제외 함수를 화면이 **간접으로** 부르는 길(표시층 다른 모듈을 지나) | **r1 F1 정정 — 앞 판의 두 칸이 거짓이었다.** ⓐ 앞 판은 「어휘 호출이 `screens`·`display` 밖에 0」을 근거로 들었는데, 그 grep 은 우회가 **사는** 자리인 `display/**` 를 처음부터 뺐으므로 아무것도 보이지 않았다. ⓑ 앞 판은 「조립 결과를 내는 함수(`amountDisplayOf`)는 이미 등재돼 있다」고 적었는데, `budgetView` 는 `amountDisplayOf` 를 **지나지 않고** 자기 글자를 만들어 `STRATEGY_FIELD_VALUE` 로 올린다. 둘 다 **경계 등재**로 답한다(§(2) 6 번 · 신설 OPEN). `leaked` 가 보는 것은 화면의 **직접** 참조뿐이고, 그 범위를 게이트 소스 주석에 적었다 |

## (3) 과잉·미달

**미달이었던 자리**: 깊이. 계약 문면의 「한 겹」은 오늘 실재하는 유일한 꼴을 닫지 못한다
(`InboxScreen` → `NotificationGroupBlock` → `NotificationRow`). 팀장 결정으로 전이 폐포로 간다.

**과잉이 아닌 근거 — 집합이 늘지 않는다(TS 실측, 같은 프로그램, 22 파일).**

| 규칙 | 마운트 의무 | 화면 바구니 |
| --- | --- | --- |
| 오늘 | 5 | 1 — WorksheetScreen |
| 한 겹 | 5 | 1 |
| **전이 폐포(채택)** | **5 (불변)** | **2 — + InboxScreen** |

마운트 목록(`GATE_MOUNTED_CARDS`)은 **건드리지 않는다**. 늘어난 하나는 `*Screen` 이라 화면
바구니로 가고, 그 바구니의 조건인 **짝이 되는 test 파일**은 이미 있다(`InboxScreen.test.tsx`).
즉 이 변경은 오늘의 production 코드를 붉히지 않으면서, 게이트가 **그 파일에 대해 아무 말도 하지
않던 상태**를 끝낸다(오늘 `InboxScreen` 은 의무도 화면 바구니도 아니다).

**하지 않는 것**(과잉 금지) — 의무 집합을 「표시 모듈의 내보낸 함수 전부」로 넓히지 않는다
(M9 실측 5 → 13, 질의 목이 필요한 패널·훅이 섞인다) · 파일 **사이**의 그래프를 따라가지 않는다
(모집단이 `src/**` 전체가 되고 「마운트할 수 있는 카드」라는 의무의 뜻이 무너진다 — r1 F1 의
경계 등재가 이 선이다) · 출하 코드를 한 줄도 바꾸지 않는다(판정이 넓어져 붉어지는 자리는 **새
결정**이다) · 11D 와 공유하는 `vite.config.ts`·`eslint.config.js` 를 건드리지 않는다.

## RED 로 세운 것

축마다 **합성 원문 대조**를 둔다(`__probe__` 오버레이 — 합성 파일이 실제 표시 모듈을 import
하므로 대조가 진짜 심볼 그래프를 지난다). 양성은 §(2) 의 우회마다 하나씩이고, 음성은 「폐포가
지나 그리기를 다 삼키지 않는다」를 재는 넷이다. 등재 등식은 구멍 셋의 양성 대조를 **합성 원문을
실제 어휘 모듈 위에 얹어** 한 프로그램에서 함께 낸다. 어느 변이가 어느 칸을 붉히는지는
`commands.md` 의 변이 표가 정본이고, test 이름과 일대일로 옮기지 않는다(그 쌍은 코드가 든다).

기본 내보내기의 의무 이름은 **`<file>#default`** 다 — 이름 공간에서 접히지 않게 파일로 한정한다
(r1 v R2). 마운트 목록과의 규약은 실재가 생기는 날의 일이고 알려진 제한에 적었다.
