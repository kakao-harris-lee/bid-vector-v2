## 이 slice 가 닫는 절반과 남기는 절반

- **7C⑤-a (지금, main 위)**: **공고 단위 개찰 결과 조회** — main 에 이미 수집되는 개찰 결과(V4·V5)로 잠정 1위 · 참가자 수 · 개찰 시각 ·
  낙찰가(확정/잠정 구분) · 유찰을 읽기 전용으로 낸다(SET-02 표시 절반 · COL-02 표면). 잠정 1위가 확정 필드를 바꾸지 않는다는 기존 측정을
  응답 계약에서도 지킨다(잠정/확정을 다른 필드 또는 상태로).
- **7C⑤-b (g1set01 · 7B · 7C④ 머지 뒤 rebase)**: **내 입찰 대사** — 투찰 기록(7B) × 개찰 결과 × 상호 매칭(SET-01 커널, 상호는 7C④)으로
  건별 낙찰/패찰/유찰/판정 불가를 내고, 내 투찰가·차이·고른 안(7B 가 보존)을 붙인다. 집계(투찰 대비 낙찰률)는 **표본 수와 함께, 분모 0 이면
  「부재」**. 「상호 미설정이면 판정하지 않고 외부 조회도 하지 않는다」(SET-01)를 응답 상태로. 낙찰/패찰 **확정 시 알림함 기록**은 7C③ 포트가
  머지된 뒤 배선한다(NOTI-04 의 기록 절반 — 채널은 R-4 밖).
- -b 의 선행 셋이 늦으면 팀장이 -a 만 먼저 PR 할지 판단한다. 선행 slice 의 커널·표를 이 slice 가 흉내 내지 않는다(가짜 대사 금지).

## 산출물 (-a)

1. **OpenAPI**: 공고 단위 개찰 결과 조회 operation(읽기 전용 GET). 응답: 개찰 상태(미개찰 · 개찰 완료 · 유찰) · 잠정 1위 · 참가자 수 ·
   개찰 시각 · 낙찰가(확정/잠정) · 출처 시각. 수집 전/수집 실패/결과 없음을 **서로 다른 상태**로(COL-04 의 「요건 없음 vs 수집 실패」와 같은 원칙).
   생성 타입 재생성(W-5).
2. **Kotlin**: 읽기 포트 + persistence 어댑터(기존 개찰 결과 표 읽기, 읽기 전용 트랜잭션 — 7C① 의 읽기 전용 증인 관례) + controller.
   **쓰기 0 · 마이그레이션 0**.
3. **test**: 상태별(미개찰·완료·유찰·수집 실패) · 잠정 → 확정 전이에서 확정 필드 불변 · 인증 401 · 응답에 다른 업체 사업자번호 등 PII
   필드 0(개찰 결과 원문에 다른 참가자 정보가 있으면 **무엇을 내보내는지 Phase 1 에서 판정**하고 privacy 관점 표적) · 실 DB 출하 조립 E2E.
4. **추적표·capability map**: SET-02(표시 절반) · COL-02(표면) 행에 근거.
