# M7/7C② rollback

**실측 HEAD: `c3649ab5`**(이 slice 의 마지막 산출물 커밋) · **base: `46ac0949`**(7B·7C④ 가 든 main).

되돌림은 range revert 가 아니라 **in_scope 경로 한정 복원**이다. 버릴 clone 에서 실측했고 원본
worktree 는 읽기만 했다(실측 끝에 변경 0 · HEAD 그대로 확인).

## 목록 — 기계 산출

`git diff --name-only <base>..<실측 HEAD>` 에서 **이 slice 의 evidence 디렉터리만** 제외한다
(그 디렉터리는 slice 자신의 장부다 — scope.md). 손 목록이 아니므로 라운드마다 다시 산출된다.

| | 수 |
|---|---|
| 되돌릴 경로 | **40** |
| base 에 있던 것(복원 대상) | 18 |
| 이 slice 가 새로 만든 것(삭제 대상) | 22 |
| 목록 등식 `comm -23`(기계 산출 ↔ 실제 변경) | **빈 출력** |

**둘을 섞으면 안 된다** — base 에 없는 경로에 `git restore --source=<base>` 를 걸면 pathspec 오류로
멈춘다. 복원과 삭제를 갈라 돌린다.

## ①~⑥ 실측

| | 내용 | 결과 |
|---|---|---|
| ① | `git restore --source=<base> --staged --worktree --` (18) · 새 파일 삭제 (22) | exit **0** · exit **0** |
| ② | 되돌린 뒤 실측 HEAD 대비 계수 | D **22** · M **17** · A 1 |
| ③ | `git diff <base> -- <40 경로>` | **0 줄** |
| ③' | 트리 동일성 — base 에 있던 18 의 blob | **같음 18 · 다름 0** |
| ③'' | 새 파일 22 의 존재 | **사라짐 22 · 남음 0** |
| ④⑤⑥ | 되돌린 트리에서 `./gradlew --no-daemon check` | exit **0** · FAILED **0** · 400 task · 22분 43초 |

**갈음은 종료 코드가 아니라 ③·③'·③'' 다.** exit 0 만 보면 「되돌릴 것이 없어서 0」과 구별되지
않는다. ④⑤⑥ 은 되돌린 트리가 **서는지**를 보는 것이고, 되돌림이 옳은지는 트리 동일성이 말한다.

### 블롭 계수 술어를 한 번 고쳤다

첫 산출은 「같음 18 · 다름 22」로 나왔다. 새로 만든 22 개에 대해 base 쪽 blob 을 묻는 명령이
실패하는데 그 실패 출력을 값으로 비교한 탓이다. **파일 종류마다 술어가 다르다**: base 에 있던
것은 「blob 이 같은가」, 이 slice 가 만든 것은 「지금 없는가」. 위 표는 고친 술어의 값이다.

것이다.

## 유효성 술어 (verifier 용)

이 실측이 판정 SHA 에서도 유효한지는 **「실측 HEAD == 판정 SHA」가 아니라**(evidence 커밋은 언제나
뒤에 오므로 둘은 영원히 다르다) **그 사이에 되돌림 대상이 움직였는가**로 본다.

```
git diff --name-only <실측 HEAD>..<판정 SHA> -- <위 40 경로>
```

이 출력이 비어 있으면 유효하고, 한 줄이라도 나오면 미검증이다. 실측 시점 확인값: **빈 출력**
(그 사이 커밋은 이 slice 의 evidence 뿐이고, 그 디렉터리는 되돌림 대상이 아니다).
