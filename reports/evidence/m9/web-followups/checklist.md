## 2. 게이트의 힘 — 무엇이 RED 를 만드는가

변이는 **바꿔치우기**다(더하기만 한 변이는 초록이 되므로 세지 않는다). 각 줄은 「그 층을 앞 판의
꼴로 되돌리면 어느 대조가 깨지는가」다.

| 축 | 바꿔치우기 변이 | 받는 층 |
| --- | --- | --- |
| 명령 원문 | 타임라인이 표를 지나지 않음 | DOM 어휘 게이트(홀로 선 토큰 · 잎 글자 등식) + 화면 C test |
| 명령 어휘 어긋남 | Kotlin 이 늘거나 web 이 줆 | 교차언어 집합 등식(표와 유니온을 **함께** 줄이는 꼴까지) |
| D-day 셈 | 24시간 나눗셈으로 되돌림 | 경계 test 넷(자정 양쪽 1 분 · 같은 날 23시간 58분 · 거울상 · `-0`) |
| D-day **문면** | 화면 설명을 「남은 날(내림)」으로 되돌림 | 화면 B test 의 설명 문면 단언 |
| 모집단 | 호출 이름 술어로 되돌림 / 시그니처 해소 제거 | 양성 대조 넷(별칭·네임스페이스·지역 변수·개명 재수출) |
| 모집단 **범위** | 재귀 제거 / `.ts` 제외 | 버릴 디렉터리 훑기 대조 |
| 시계 표면 | 목록을 `Date` 로 좁힘 / 서식 선택자 제거 / 제외 디렉터리 복원 | 세 변이가 각각 다른 대조를 깬다 |
| 시계 **구조 분해** | 그 선택자 제거 | 구조 분해 대조(`const { Date: D }` · `const { DateTimeFormat: F }`) |
| 시계 **빈 인자** | `undefined`·spread 꼴 제거 | `format(undefined)` · `formatToParts(...xs)` 대조 |
| 시계 **이름 목록** | `DateTimeFormat` 제거 | 인자를 받는 서식 호출 대조(그 선택자 **단독**) |
| 네트워크 전역 | 시계 블록이 목록을 덮음 | 맨 `fetch`·`WebSocket` 대조 둘 |
| Kotlin 읽기 | 못 읽는 조각을 다시 버림 | 「읽지 못하는 항목 꼴은 던진다」 대조 셋 |
| 표 조회 | `Object.hasOwn` 제거 | 프로토타입 키 다섯 대조 |

## 3. 알려진 제한

① **모집단은 「어휘 함수 일곱」의 선언에 걸리고, 「쓴다」는 그 컴포넌트 본문의 직접 호출이다.**
잔여 전수와 근거는 `design-review.md` §③ 「남는 자리」 표에 있다 — 새 어휘 함수 · 감싸 내보내기
(`memo`·`forwardRef`) · 개명 재수출 · 클래스 컴포넌트 · 함수 **참조** 전달 · **간접 렌더**(내보낸
`Outer` 가 어휘를 부르는 비공개 `Inner` 를 그리는 꼴 — PR #132 cr L-4). **오늘 `src/screens/**` 에
그런 꼴이 0 이고** 의무 5 == 마운트 5 를 리뷰가 재현했다. 「표시 모듈의 내보낸 함수 전부」로
넓히는 길은 실측하면 의무가 5 → 13 이 되고 질의 목이 필요한 패널 둘·훅 하나가 섞인다. 목록이
**썩는** 축은 닫혀 있다(항목마다 「그 모듈의 내보낸 이름인가」를 단언한다). 훑기의 **평면·`.tsx`
한정**은 PR #132 v M-3 으로 닫았다(재귀 · `.ts` 포함 · 버릴 디렉터리로 실측).

② **시계 금지 밖에 남는 표면이 있다.** 전수는 `design-review.md` §④ 「남는 자리」 표다 — 시계가
아닌 표면이 나르는 시각(`document.timeline`·`event.timeStamp`·`File.lastModified`·
`document.lastModified`) · 반사 API 와 계산으로 만든 이름 · 구조 분해의 따옴표·계산·템플릿 키 ·
**빈 값을 다른 글자로 적은 인자**(`void 0` · TS 문법으로 감싼 `undefined` — 아래 ③) · test 파일.

**가장 큰 잔여는 「출하 파일이 test 파일을 import 하는 길」**(PR #132 v L-2): `src/display/x.test.ts`
가 시계를 내보내고 화면이 import 하면 제외를 지나고, 「test 는 출하되지 않는다」는 전제를 **지키는
게이트가 없다**(번들 경계는 `web/src` 안이면 통과한다 — lint·tsc·src-tree·canary 전부 0 으로 실측).
그 축은 시계가 아니라 **번들 경계 게이트의 일**이라 그 slice 로 넘긴다.

③ **`Intl` 전역을 통째로 막지 않았다.** `Intl.NumberFormat(…).format(1200)` 은 시계가 아니라 수
서식이고, 막으면 금액 서식이 자기 금지에 걸려 다음 라운드가 규칙을 끈다.

그 선택의 대가를 **사실대로 적는다**(PR #132 v M-2 = cr M-2 로 정정 — 앞 판의 문장이 틀렸다).
앞 판은 「인자를 받은 `format` 은 지금을 읽는 꼴이 아니다」를 근거로 적었는데 **한 입력에서
거짓**이다: `format(undefined)` 은 인자가 하나인데 **지금**을 서식한다. 그 꼴과 spread 꼴을
선택자로 닫았으므로, 남는 것은 **값을 실제로 주는 호출**(`format(someDate)` — 지금을 읽지 않는다)과
**빈 값을 다른 글자로 적은 꼴**이다.

그 「다른 글자」 계열은 둘이고 **같은 성질**이다(v-132-r2 L-1 로 전수를 적는다): ⓐ 식별자가
아닌 표현식(`void 0`) ⓑ **TS 문법으로 감싼 `undefined`** — `undefined as never` · `undefined!` ·
`undefined satisfies undefined`. ⓑ 는 노드가 `Identifier` 가 아니라 `AsExpression`·
`NonNullExpression`·`SatisfiesExpression` 이라 첫 인자 꼴 선택자를 지난다. **술어를 더 늘리지
않는다** — 표기를 열거하면 그 목록이 다음 문법에서 또 뒤처지고, 이 층은 처음부터 「실수로 쓴
직접 호출」을 잡는 보조 층이다(의도적 우회는 리뷰 소관이라는 네트워크 쪽 문장과 같은 자리다).

③b **시계 선택자의 오탐 비용**(PR #132 cr L-5). 속성 이름으로 잡으므로 시계와 무관한 멤버도
걸린다 — `metrics.performance`(실적·성능) · `row.Date` · 인자 없는 `builder.format()`. 특히
`performance` 는 이 도메인에서 충분히 나올 이름이라 다음 라운드가 그 벽에 먼저 부딪친다.
**탈출 경로는 그 줄의 `eslint-disable-next-line` + 리뷰**이고 규칙을 좁히지 않는다(좁히면 소유자
열거로 돌아가고, 그 열거가 앞 판에서 축을 통째로 열어 두었다). 같은 문장이 네트워크 금지 쪽에
있었고 이제 시계 쪽 주석에도 있다.

④ **Kotlin 을 텍스트로 읽는다.** node 에 Kotlin 파서가 없다. 그래서 술어를 「꼴이 바뀌면
**던진다**」로 닫았다 — 헤더가 하나가 아니거나, 열거가 비거나, **비지 않은 조각을 읽지 못하면**
예외다. 한 줄 열거·뒤 쉼표·주석·본문 멤버 선언·인자를 받는 엔트리·소문자 항목은 읽는다.

**앞 판은 못 읽는 조각을 조용히 버렸다**(PR #132 v M-4 = cr L-2): `@Deprecated("x") NEW_CMD` ·
백틱 이름이 초록이었고, 접두사 읽기가 `A(FOO, BAR)` 에서 유령 항목 `BAR` 를 내고 `Won` 을 `W` 로
절삭했다 — 이 게이트가 막으려는 「Kotlin 이 늘었는데 web 이 안 붉어진다」가 **게이트 안에**
있었다. 지금은 인자 목록을 균형 괄호로 먼저 떼고 **전체 일치**로 보며 안 맞으면 던진다. 본문을
가진 항목(`A { … }`)도 던지는 쪽이다(그 꼴이 정본에 없고, 읽기를 넓히는 것보다 RED 로 사람을
부르는 쪽이 이 게이트의 성질에 맞는다). 대조는 합성 원문 **양성 여덟 · 음성 열**이다.

⑤ **D-day 의 뜻이 바뀌었다 — 거울상까지.** 한 시간 전 마감이 달력으로 어제면 `D+1` 이다. 앞 판의
CR L-2 가 「하루 과장」으로 막던 것과 **다른 사실**이다(그때는 24시간 나눗셈의 어림이 문제였고,
지금은 달력일이 실제로 어제다). 그 귀결을 test 와 모듈 주석이 축어로 든다.

⑥ **캡처는 다른 레인과 한 자리를 쓴다.** `docs/usecase/captures/**` 는 저장소에 하나뿐이라 이
slice 의 재촬영이 **알림함 캡처 둘도 함께** 바꾼다(그 화면의 소스는 건드리지 않았다 — 바뀐 것은
촬영 시각이다). 알림함 화면을 만지는 레인이 같은 캡처를 다시 뜨면 **나중 쪽이 이긴다**.

⑦ **manifest 의 `head` 는 캡처 커밋의 앞 커밋을 가리킨다.** 스크립트가 dirty `web/` 를 거부하므로
「코드 커밋 → 촬영 → PNG 커밋」 순서가 강제된다(PR #125 의 제한 ⑩ 과 같은 성질이고 같은 처방을
쓴다).

⑧ **다른 레인의 소유 파일을 건드리지 않았다.** 알림함 화면 둘과 알림 표시 모듈은 이 브랜치의
변경 목록에 없다(`git log --name-only` 전수 대조 — `scope.md` 의 in_scope ⊇ 변경 경로).

⑨ **명령 문면이 출하 경로(e2e 여정)에서는 단언되지 않는다**(PR #132 cr L-7). 여정의 타임라인
절은 상태 문면만 보고 명령 칸을 읽지 않는다. 다만 그 축은 **구조로 이미 닫혀 있다**: DB CHECK ==
`BidCommandTag ∪ 여는 명령` → 교차언어 등식이 web 표·유니온을 같은 집합에 묶는다 → DOM 게이트가
그 키의 원문 0 을 잰다. 여정에 한 줄을 더하면 「알 수 없는 상태(…)」로 degrade 하는 꼴이 출하
경로에서도 붉어진다 — 값싼 보강이고 **다음으로 넘긴다**(`web/e2e/journey/**` 는 in_scope 이지만
이 라운드의 지시 밖이다).

⑩ **명령 열다섯이 손으로 적힌 자리가 셋이다**(PR #132 cr L-9) — 표시 모듈의 유니온 · 표 test 의
목록 · DOM 게이트의 계수 단언. 뒤 둘은 **래칫이고 의도다**(표에서 뽑으면 공허해진다). 어휘가 늘면
세 자리를 손으로 고쳐야 하고, 그것이 교차언어 등식과 함께 「늘었다」를 두 번 말하게 한다.

⑪ **컴파일러 API 게이트의 비용**(PR #132 cr L-8 · 리뷰 실측): 모집단 게이트가 TS 프로그램을
**둘** 연다(본 측정 ~2.3s + probe overlay ~0.7s), node RSS 약 460MB, 전건 vitest 의 ~30%.
**셋째 프로그램을 무심히 더하지 않는다** — 더해야 하면 overlay 를 합치는 쪽을 먼저 본다.

⑫ **`uses` 가 참이 된 뒤에도 서브트리를 끝까지 걷는다**(PR #132 cr L-6). 비용은 ⑪ 안이고
의도 표현의 문제다 — 다음에 그 함수를 만질 때 함께 고친다.

⑬ **DOM 게이트 fixture 의 전이 짝은 뜻이 없다**(PR #132 cr OQ). 명령 열다섯에 상태를 돌려
붙이므로 「마감 지남 표시 → 관심」 같은 줄이 생긴다. 지금 단언은 **글자 존재**만 보므로 해가 없고
상태 어휘 밖 값을 쓰지 않으려는 의도도 주석에 있다. 같은 fixture 로 「전이 문면」을 단언하게 되는
날 그 짝을 먼저 고친다.

## 4. 수정 라운드가 만든 새 파일 ↔ in_scope 대조

이 slice 가 **새로 만든 파일은 둘**이다 — 교차언어 게이트 test(`web/scripts/**`)와 설계 검토
문서(evidence). 둘 다 계약의 in_scope 안이고 계약 갱신이 필요 없다. **PR #132 수정 라운드는 새
파일을 만들지 않았다**(일곱 자리 전부 기존 파일의 수정이다). 변이 라운드도 파일을 만들지 않았다
(원천 파일을 고쳤다 되돌렸다).

## 5. 다음으로 넘기는 것

- **`OPEN-M9-COMMAND-OPENAPI-ENUM`**(PR #132 cr OQ — 새 OPEN). 형제 칸 `actorKind` 는 openapi 에
  `enum` 이 있어 web 이 생성 타입에서 유니온을 끌어오는데 `command` 만 `type: string` 이다. 그래서
  이 slice 가 ① 손 유니온 ② Kotlin 원문의 **JS 텍스트 파싱** 게이트를 세웠다(제한 ④ 의 취약성이
  거기서 나온다). `command` 를 enum 으로 올리면 ①② 가 함께 사라진다 — `openapi/**` 가 in_scope
  밖이라 **계약 slice** 의 일이다.
- **모집단의 잔여 여섯**(제한 ①) — 간접 렌더·감싸 내보내기·개명 재수출·클래스·함수 참조·새 어휘
  함수. 의무 집합이 마운트 가능성과 어긋나기 시작하는 자리라 질의 목 하네스가 먼저다. 화면
  slice 의 일이다.
