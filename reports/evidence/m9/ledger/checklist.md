## 이 장부가 공허해지는 길과 막는 것

| 우회 | 막는 것 |
| --- | --- |
| 「닫혔다」를 근거 없이 적는다 | 행마다 **PR 번호 + 머지 커밋 SHA + 판정 자리**. 기계 대조로 식별자가 처분 자리와 근거 자리 양쪽에 있는지 센다 |
| 종결이 아닌 것을 종결로 접는다 | 6B-3 은 **정책 날짜 개정** 행으로 분리하고 서브 OPEN 여섯의 등재 유지를 같은 행에 적었다. `OPEN-6F4-STR02-REQUIREMENTS-AXIS` 도 「열린 채 상태 갱신」으로 |
| 미머지 PR 이 만들 OPEN 을 미리 단정한다 | 그 둘은 등재하지 않고 **「머지 시 확인」** 문장 하나로만 둔다 + 그 PR 들의 head diff 에 이미 있다는 실측 |
| 처분 후보를 분류 변경으로 밀어 넣는다 | 「후보」 문면 + 추적표 절 끝의 **「이 절이 바꾸지 않는 것」**(집계 · 행 수 61 · 홀더 칸) |
| 닫힌 evidence 를 덮어 이력을 지운다 | 순 추가 — 복원 목록 여섯 경로의 numstat 이 `삭제 0` 이다 |
| 활성 집계를 조용히 움직인다 | 신설 일곱을 **G1~G6 집계 밖**으로 선언하고 머리 줄을 건드리지 않는다(「M6 잔여·메뉴」 별 칸 선례). 병렬 레인 셋이 같은 문서를 고치는 중이라 머리 줄 충돌을 만들지 않는 쪽이 싸다 |
| 열하나를 원 등재 복사로 「처분」한다 | 각 행에 **오늘 상태의 기계 대조**를 붙이고, 재지 못한 것은 「재지 않았다」로 적는다(원 등재의 수를 눈으로 다시 세지 않는다 — open-inventory §7 의 교훈) |

## 알려진 제한

1. **`OPEN-CVE-APT-RETRY`·`OPEN-CVE-APT-RUNBOOK-BRANCH` 의 원천이 PR 코멘트뿐이다.** 두 식별자는
   `reports/evidence/chore/cve-apt-109518/` 에 **없고**(그 checklist·scope 에 `OPEN-` 0건) PR #126 조치
   코멘트가 유일한 정의 자리였다. 이 slice 가 capability map 에 세워 저장소 안에 자리를 만들었지만,
   **그 slice 의 evidence 는 `in_scope` 밖**이라 손대지 않았다. 그래서 두 자리가 어긋난 채다 —
   evidence 만 읽는 쪽에는 그 OPEN 이 없다.
2. **`OPEN-7E3A-OPENING-AXIS-HARNESS`·`OPEN-7C3B-PAPER-BID-NOTIFICATION` 에 registry 행을 만들지 않았다.**
   둘은 열린 채인데 capability map 과 `milestone-6.md` 어디에도 없다(기계 대조). 행을 세우는 것은 집계·분류에
   손대는 일이라 **사실만 적었다**. 이 간격은 등재 공백으로 남는다.
3. **운영 잔여 다섯은 판정이 아니라 후보다.** `OPS-03`·`STR-09`·`OPS-11` 은 빈자리를 채운 것이 실제로
   있는데도 ⓒ 로 남아 있고, 그 재판정은 추적표의 분류 규칙이 할 일이다. 이 slice 는 술어를 돌리지 않았다.
4. **6G-2c 잔여 열하나 가운데 다섯을 재지 못했다**(harness 우회 중복 실행 · 줄 정의 차이 · Python 중복 계산 ·
   원장 이중 파싱 · 두 판독기 한 술어). 원 등재가 자리를 특정하지 않거나 거동 판독이 필요한 축이고,
   **재지 않은 것을 「그대로」로 적지 않았다** — 「재지 않았다」와 「그대로」를 가른다.
5. **「6G-2c-형식 slice 는 열리지 않았다」는 evidence 디렉터리 부재로만 잰 것이다.** 다른 이름으로 열렸다면
   이 판독이 틀린다 — 다만 그 slice 이름은 6G-2c 계약이 지은 것이고 `milestone-6.md` 의 그 문단이 정본이다.
6. **M9 신설 OPEN 일곱의 받는 자리를 지목하지 않았다.** 전부 「다음에 그 자리를 만지는 slice」이고, 그보다
   좁게 지목하려면 다음 web·CI slice 의 범위가 정해져야 한다.
7. **전건 acceptance 는 돌리지 않았다** — 코드 0 이고 로컬 측정은 `leakPatternGate` 표적과 `git grep` 대조뿐이다.
   네 job 의 정본은 PR CI 다.
