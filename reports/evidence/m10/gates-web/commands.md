자체를 드는 단언은 **여전히 없다**. 그래서 미달 ② 는 닫히지 않았고, 설계 검토가 그렇게 적는다.

`git checkout -- . && git clean -fdq` 로 했는데, 적용 단언을 위해 심은 파일을 `git add` 한 탓에
그 파일이 **staged 가 되어 clean 의 대상이 아니었다**. 그래서 앞 케이스의 편집이 뒤로 새고
**통제군까지 1 failed** 가 됐으며 세 케이스는 「치환 실패」로 미적용이 됐다. `git reset --hard` 로
인덱스까지 되돌리고 전건 재측정한 값이 위 표다. **되돌림이 인덱스를 포함하지 않으면 계수는
오염된다** — 앞 라운드(untracked 누락)와 같은 교훈의 다른 얼굴이다.

## r6 표적 변이 — 마이크로 수정이 무엇을 닫았고 무엇이 남았나

| 변이(원형) | 결과 | 판정 |

| **통제군** | **913 passed · 깨진 단언 없음** | — |
| P1/N10 `*.{kt,kts}`(r5 에서 회귀한 꼴) | **1 failed** | 닫힘 |

| **P6 데이터 파일 `{"ext": ".kt"}`** | **913 passed** | **열려 있다** |
| **P7 데이터 파일 `{"glob": "…/*.kt"}`** | **913 passed** | **열려 있다** |

**데이터 파일 축은 닫지 못했고, 그 이유를 측정으로 적는다.** 처방은 「데이터 파일도 같은 단어 축
으로」였다. 단어 꼴(`\bkts?\b`)을 데이터 파일에 그대로 쓰면 **추적 텍스트 파일의 산문**이 붉어진다
— 이 저장소의 `config/gate-tests.txt` 주석과 fixture 가 실제로 걸렸다(실측). 그래서 데이터 파일은
**파일 이름 꼴**(`\b[\w-]+\.kts?\b`)로 두었고, 그 결과 **앞에 단어 문자가 없는 두 꼴**이 남는다 —
`".kt"` 단독과 `*.kt`(별표는 `[\w-]` 가 아니다).

**둘 중 하나를 고르는 자리이고, 이 라운드는 「오탐 0」을 골랐다.** 산문 오탐은 **모든 라운드의 모든
커밋**을 막지만 P6·P7 은 **데이터 파일에 경로를 두고 그것을 읽는 코드를 함께 넣을 때만** 선다.
그 선택을 숨기지 않고 미달로 등재한다 — **게이트의 주장을 실측까지 낮춘다**: 데이터 파일에 대해
이 게이트가 막는 것은 **파일 이름 꼴 경로**이고, 확장자 단독·별표 glob 은 **막지 못한다**.

## 최종 변이 재생 — B·N·V 계열 전건 (부분 재생이 회귀를 숨겼으므로)

**부분 재생이 N10 회귀를 숨겼다**(cr r4 HIGH①). 그래서 마지막 자리에서 경로 축 열둘을 **원형
그대로 전건** 재생했다. 케이스마다 `git reset --hard` + `git clean -fdq`, 적용은 porcelain 단언.
**미적용 0.**

| 변이(원형) | 결과 |

| **통제군** — 주석 한 줄만 | **913 passed · 깨진 단언 없음** |

**brace glob 세 꼴이 전부 RED 다** — r4 가 닫았다가 r5 에서 조용히 회귀한 축이고, 이제 변이와
**상설 양성 대조** 양쪽에 선다. **모집단 하한을 정확 집합으로 바꾼 것도 변이로 확인했다**: 동작이
같은 리팩터(`String(...)` 한 겹)로 sink 가 일곱에서 여섯이 되면 **RED** 다 — 하한이었다면 조용했다.
