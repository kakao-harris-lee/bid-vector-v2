## r2 변이 실측 — 읽기 소유권 게이트가 무엇을 막는가

verifier r1 M-2 가 **초록으로 통과시킨 바로 그 둘**을 버릴 clone 에 다시 심었다. 적용 뒤 파일이
실제로 바뀐 것(`git diff --stat`)을 단언한 다음 돌렸다.

| 변이 | 결과 | 깨진 대조 |
| --- | --- | --- |
| **통제군** — 주석 한 줄만 바꿈 | **10 passed · exit 0** | 없음(거동 0) |
| **ⓐ** 별칭 import + `readFileSync` + `replaceAll` 사본 | **1 failed · exit 1** | `.kt` 경로 리터럴이 공유 모듈 밖 |
| **ⓑ** 별칭 import + `readFileSync` + `indexOf` 줄 절단 사본(옛 URL 절단판) | **1 failed · exit 1** | 같은 단언 |

**왜 r1 에서는 초록이었는가 — 같은 꼴을 옛 술어에 먹여 쟀다.**

| 꼴 | r1 텍스트 술어 |
| --- | --- |
| ⓐ 의 걷기 표기 | **지나간다** |
| ⓑ 의 걷기 표기 | **지나간다** |
| (참고) 앞 판의 정규식 사본 표기 | 걸린다 |

술어가 **사본의 성질**이 아니라 **사본을 쓰는 한 가지 표기**를 재고 있었다. 표기를 바꾸는 것만으로
열리는 술어는 게이트가 아니다 — r2 는 그래서 층을 「원문을 쥘 수 있는가」로 옮겼다.

이 게이트는 vitest 가 돌리므로 **캐시 적중이라는 자리가 없다**(gradle 의 `UP-TO-DATE`·`FROM-CACHE`
에 해당하는 것이 없고, 위 네 줄은 전부 실제 실행이다 — 통제군의 초록도 실행된 초록이다).

## 게이트 자신의 양성 대조

| 무엇 | 대조 | 결과 |
| --- | --- | --- |
| 등록부 한 줄이 힘을 갖는가 | clone 에서 새 게이트 test 파일을 치움 | `gate:tests` **exit 1** |
| 사본 금지 — **선언** 술어가 공허하지 않은가 | 찾는 꼴(`function withoutKotlinComments`)이 공유 모듈에 실제로 있는지 | test 로 상설(음성 단언과 같은 묶음) |
| 사본 금지 — **걷기 정규식** 술어가 공허하지 않은가 (r1, cr r0 MEDIUM) | 그 술어가 **거는 것이 저장소에 하나도 없다**(그것이 정상 상태다) — 사본의 꼴을 **합성 입력** 둘(줄 주석판·블록 주석판)로 넣어 술어가 실제로 걸리는지 | test 로 상설 · 둘 다 **match**. r0 의 양성 대조는 선언 술어만 덮어, 정규식이 드리프트하면 두 소비자 단언이 **조용히 아무것도 재지 않았다** |
| 비밀값 스캔이 도는가 | `grep -rniE -f config/quality/leak-patterns.txt` 를 심은 표본에 | **exit 0**(도구 동작). 이 evidence 에는 **exit 1**(0 건) |
