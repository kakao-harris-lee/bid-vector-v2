## 2. 게이트의 힘 — 무엇이 RED 를 만드는가

변이는 **바꿔치우기**다. 종료 코드는 `commands.md` 에 있다.

| 축 | 바꿔치우기 변이 | 받는 층 |
| --- | --- | --- |
| Kotlin ↔ 계약 | Kotlin 어휘가 늘고 계약은 그대로 | 새 계약 test(`:app:test`) |
| 계약 ↔ Kotlin (역) | 계약의 한 값을 바꿔치움(생성 타입도 재생성 — W-5 는 초록) | 같은 계약 test |
| 계약 ↔ 생성 타입 | 계약을 고치고 재생성하지 않음 | W-5 바이트 등식 |
| 생성 타입 ↔ web 표 | 표의 키를 바꿔치움(**test 목록까지 함께** — 앞 판이 `satisfies` 를 지나던 꼴) | W-3(`satisfies` 의 유니온이 계약 유도다) |
| 어휘를 **다시 염** | 계약의 `enum` 을 걷어 `type: string` 으로 | 계약 test(어휘 읽기가 **던진다**) **그리고** W-3(좁음 가드가 `never` 가 된다) |
| 읽기 자신 | 어휘 읽기가 선언 부재·빈 열거를 조용히 답으로 냄 | 그 test 의 음성 대조 둘(합성 문서) |

**「표와 유니온을 함께 줄이는」 변이는 구성상 불가**다(손으로 쓸 유니온이 없다) — 위 넷째 행이
실측으로 확인한다.

## 3. 알려진 제한

① **상태 두 칸은 그대로 `type: string`** — 같은 꼴의 공백이고 화면이 같은 우회를 쓴다. 신설 OPEN
으로 등재했고(§1), 그 받는 자리는 10B 의 전방 호환 판단을 물려받는다(`scope.md` D-10B-2).
② **조회는 런타임의 자유 문자열을 받는다** — 계약이 어휘를 닫아도 **배포 비틀림**으로 번들이
모르는 값이 닿을 수 있어 표 밖 처리와 그 대조(표 밖 토큰 · 프로토타입 키 다섯)를 유지했다.
③ **어휘 읽기 헬퍼의 사본 셋을 모으지 않았다** — 넷째 사본을 안 만들려 공용 자리에 하나를 세웠고,
기존 셋(계약 test 세 class 의 `private` 사본)은 별 정리다.
④ **교차언어 게이트의 금액 네 축은 남는다**(그 칸들이 아직 계약에서 `string`) —
`OPEN-M9-MONEY-VOCAB-CROSS-LANG` 의 자리이고 10D 가 받는다. 명령 축만 걷었다.
⑤ **W-12·W-13 과 S-20 은 로컬 미실행** — 버릴 Postgres 전제가 이 레인에 없다. PR CI 가 그
자리다(팀장 승인 2026-11-11).
⑥ **공유 파일 셋을 만졌다** — §12.3 · 게이트 등록부 · 교차언어 게이트. 앞 둘은 레인 넷이 각자
덧붙이는 자리, 셋째는 10D 도 만진다. 행을 고치지 않고 자기 자리만 더했다.
