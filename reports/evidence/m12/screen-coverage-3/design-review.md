# M12 / screen-coverage-3 — 설계 검토 (게이트, 구현 전)

대상은 `OPEN-M11-SCREEN-COVERAGE-CROSS-FILE-VOCAB`(ⓐⓑⓒⓓ)와 `OPEN-M11-SCREEN-COVERAGE-POPULATION-DIR`
이다. 팀장 판정(2026-11-14, Q1~Q4 전부 승인)이 이 검토의 입력이다. 수치는 전부 base 트리에서 쟀고
근거는 `commands.md` 가 정본이다.

## (0) 위협 모델 경계

**방어하는 것 — 평범한 관용구의 표류.** M11 의 경계 문장을 승계하고 넷을 더한다. 기준은 「저자가
이 게이트를 의식하지 않고 쓴 React·TS 코드」다.

승계: 파일을 비공개 하위 컴포넌트로 쪼개기 · `memo`·`forwardRef` 로 감싸기(기본 내보내기 포함) ·
이름을 바꿔 내보내기 · 클래스 컴포넌트 · 어휘 함수를 콜백으로 넘기기 · 어휘 모듈에 어휘 함수를
새로 더하기.

더하는 넷: **①** 표시층의 **다른 파일**에 어휘를 감싼 함수를 두기(ⓐ) · **②** 표시층에 **새 모듈**을
만들어 거기에 어휘를 두기(ⓑ, 감싸는 꼴과 바닥부터 쓰는 꼴 둘) · **③** 어휘를 **함수 값 표**·클래스
static·`fn | undefined` 로 내보내기(ⓒ) · **④** 어휘를 그리는 카드를 `src/screens/**` **밖**에 두기
(POPULATION-DIR).

**방어하지 않는 것 — 게이트를 알고 숨기는 저자.** 어휘 이름을 런타임에 조립하기 · 게이트 모듈·
게이트 test·마운트 목록·분류 표 자체를 고치기 · 실제 어휘 함수를 「어휘가 아니다」로 분류하기.
셋 다 diff 에 남고 리뷰 소관이며, **등재로 답하고 수정 라운드를 열지 않는다.** 경계를 바꾸려면
팀장 결정으로 이 문서를 개정한다.

## (1) 열거인가 구성인가

| 자리 | 앞 판 | 이 라운드 |
| --- | --- | --- |
| 어휘 **도달의 범위** | 파일 **안** 전이 폐포 | **구성** — 표시층 **파일 사이** 폐포. 노드 집합을 디렉터리에서 유도하므로 새 모듈이 자동으로 든다 |
| 등식의 **모집단** | 어휘 모듈 **셋**(등재 목록에서 유도) | **구성** — `src/display/**` **디렉터리** 전수 |
| 「부를 수 있는 것」 | 타입의 **직접** 호출 시그니처 | **구성** — 합집합 전개 ∪ **자기/사상 속성 한 홉**. 경계는 꼴 열거가 아니라 **속성의 출처**다 |
| 등식의 **키** | **내보내기** 자리 | **구성** — **해소된 선언** 자리. 자리가 안 나오는 내보내기는 `unkeyed` 로 붉다(조용히 빠지지 않는다) |
| 의무의 **모집단** | `src/screens/**` 디렉터리 | **구성** — `src/**` 전체 |
| 「마운트할 수 있는 카드」 | 디렉터리 + `*Screen` 이름 규약 | **구성** — JSX **앵커 심볼 동일성**(아래 Q1 처분) |

**Q1 처분 — 이름 비교를 구조 비교로 바꿀 수 있다(실측).** 카드 술어의 앵커를 **합성 앵커 파일의
JSX 식 자신**(`<span />`)과 `ReactNode` 의 갈래에서 얻고, 반환 타입의 갈래를 그 **심볼과 동일성**으로
맞댄다. 타입 **이름**도 선언 **경로**도 쓰지 않는다. 클래스 컴포넌트도 이름 없이 본다 — construct
시그니처의 인스턴스에 **앵커를 반환하는 멤버가 있는가**로 판정한다(`'render'` 라는 글자를 쓰지
않는다). 실측 — 앵커는 셋(`Element` · `ReactElement` · `ReactPortal`)이고, 오늘 트리의 카드 전수는
이름 변종과 **같은 42** 이며, 일부러 꼴만 흉낸 반환(`{ type, props }`)은 **거절**된다. 포털·`null`
반환·Fragment·`memo`·`forwardRef`·기본 내보내기·개명 재수출·클래스를 전부 집고, 훅·함수 값 표·
`ReadonlySet`·사상 표·클래스 static·`fn | undefined` 는 카드가 아니다.

**여전히 열거로 남는 자리와 그것을 받는 장치.**

- **씨앗 여덟**(`VOCABULARY_DECLARATIONS`) — 「무엇이 금액·시각 어휘인가」는 사람의 판단이다.
  받는 장치: 등식(모집단 × 술어) · `stale`(가리키는 대상이 사라짐) · **`contradicted`**(신설).
- **분류 표**(제외 일곱 + 새 행 **26**) — 표 자신이 열거다. 받는 장치: 종류마다 사유 · 종류
  `INTERNAL_ASSEMBLER` 에 붙는 구조 의무(`leaked`) · **모든 종류에 붙는 `contradicted`**.
- `*Screen` **이름 규약** — 뺀 이름마다 짝이 되는 test 파일을 세는 기존 장치가 그대로 받는다.

**`contradicted` 가 신설인 사유.** 26 행은 대부분 「이 축이 아니다」라는 사유를 들 텐데, 그 사유에
구조 의무가 없으면 표가 썩는다. 폐포가 그 키에 **닿으면** 「어휘가 아니다」는 구조적으로 거짓이다 —
그때 게이트가 붉어진다. 오늘 `contradicted` 는 **0** 이다. 같은 장치가 분류를 **싸게** 만든다:
폐포가 설명하는 것은 행이 필요 없다(실측 — 표시 키 둘이 그렇게 빠져 행이 28 → 26 이 된다).

## (2) 우회 — 각각의 처분

M11 이 닫은 일곱(별칭·재수출·네임스페이스·지역 변수 · 선언 목록 썩기 · 마운트 목록에서 빼기 ·
하위 디렉터리와 `.ts`)과 M11 의 여섯(간접 렌더 · 감싸 내보내기 · 개명 재수출 · 클래스 · 참조 전달 ·
순환)은 그대로다. 이 라운드가 받는 것과 남기는 것만 적는다.

1. **표시층 다른 파일의 래퍼**(ⓐ) → **파일 사이 폐포가 받는다.** 오늘 실례 하나 — 비공개 조립
   함수가 등재 어휘로 금액 글자를 만들고 그것이 함수 값 표를 지나 화면에 닿는다. 실측: 표시 키
   **+2** · 의무 **5 → 7**.
2. **새 표시 모듈에 감싼 어휘**(ⓑ 앞 꼴) → **같은 폐포가 받는다.** 노드 집합이 디렉터리에서
   유도되므로 모듈을 새로 만드는 것으로는 밖에 서지 못한다.
3. **새 표시 모듈에 바닥부터 쓴 어휘**(ⓑ 뒤 꼴) → **등식이 받는다**(모집단 = 디렉터리). 분류될
   때까지 붉다. **오늘 실례 하나** — 등식 모집단 밖의 내보낸 함수가 씨앗을 지나지 않고 자기 금액
   문면을 만든다. 팀장 판정으로 **씨앗 등재**한다(실측: 카드 술어가 있으면 의무는 7 그대로다).
4. **함수 값 표**(ⓒ) → **속성 한 홉이 받는다.** 사상 타입(`Record<K, fn>`)의 속성 심볼은 **선언이
   없으므로** 속성 타입을 **모듈 소스**에서 묻는다(앞 판이 조용히 건너뛴 자리다).
5. **클래스 static 어휘**(ⓒ) → 같은 술어. 정적 멤버는 **자기 선언**이라 출처 경계를 지난다.
6. **`fn | undefined` 내보내기**(ⓒ) → **합집합 전개**가 받는다(앞 판은 합집합에 호출 시그니처가
   없어 못 보았다).
7. **어휘 모듈이 남의 선언을 재수출**(ⓓ) → **해소된 선언 자리**를 키로 쓴다. 자리가 안 나오는
   내보내기는 `unkeyed` 로 붉다 — 「키가 없어 조용히 빠지는」 길을 막는다. 오늘 실재 0.
8. **어휘를 그리는 카드를 `src/components/**` 나 `src/` 뿌리에 두기**(POPULATION-DIR) →
   **모집단 `src/**`** 가 받는다. 실측: 오늘 그 디렉터리의 도달은 0 이므로 의무가 늘지 않는다.
9. **씨앗이 늘 때 훅·패널이 의무로 끌려오기** → **카드 술어가 받는다.** 실측된 지뢰다 — 이름
   기준으로 ③ 의 함수를 씨앗 등재하면 의무가 8 이 되고 그 여덟째가 마운트할 수 없는 훅이다.
10. **카드 술어가 못 보는 React 꼴** → 열 꼴 실측(위 Q1 처분). 남는 것은 앵커 자신이고, 앵커가
    비면 **모든 등식이 공허해지므로** 비-공허 단언을 둔다.
11. **꼴만 흉낸 반환으로 거짓 의무를 만들기** → 심볼 동일성이 거절한다(구조 변종의 오탐을 이것이
    막는다).
12. **표시층도 카드 파일도 아닌 모듈의 래퍼** → **경계 밖**(계약이 폐포를 `src/display/` 로
    적는다). 오늘 실재 **0** — 표시층 밖에서 씨앗을 참조하는 파일 일곱이 **전부 카드 파일**이다.
    신설 OPEN 후보로 등재한다(§신설 OPEN).
13. **런타임 조립**·**게이트 파일 고치기**·**거짓 분류** → 경계 밖(§(0)).
14. **폐포의 순환**·**빈 프로그램**·**모듈 부재** → 고정점의 방문 집합과 기존 throw 가 받는다.

## RED 로 세울 것

축마다 **합성 원문 대조**를 둔다(`__probe__` 오버레이 — 합성 파일이 실제 표시 모듈을 import 하므로
대조가 진짜 심볼 그래프를 지난다). 양성은 §(2) 의 1~11 마다 하나씩이고, 음성은 「폐포가 표시층을
다 삼키지 않는다」·「카드 술어가 훅·표·컬렉션을 집지 않는다」·「꼴만 흉낸 반환을 집지 않는다」다.
등식의 다섯 버킷은 각각 양성 대조를 갖고, 그 가운데 `contradicted` 와 `unkeyed` 는 **합성 원문을
실제 표시 모듈 위에 얹어** 낸다. 어느 변이가 어느 칸을 붉히는지는 `commands.md` 의 변이 표가
정본이고 test 이름과 일대일로 옮기지 않는다(그 쌍은 코드가 든다).

마운트 +2 의 fixture 는 **네 칸을 비-null 로** 채운다(예산 금액·통화·과세·출처) — 하나라도 비면
그 칸이 「없음」 분기만 그려져 원문 보간이 **미측정**으로 남는다(M11 의 같은 교훈).

## 신설 OPEN 후보 (팀장 판정 대상)

1. **표시층도 카드 파일도 아닌 모듈의 래퍼.** 폐포의 노드 집합이 `src/display/**` 라, 어휘를 감싼
   함수를 그 밖의 비-카드 모듈에 두면 폐포가 닿지 않는다. 오늘 실재 **0**(표시층 밖에서 씨앗을
   참조하는 파일 일곱이 전부 카드 파일이다). 닫는 길은 「카드를 싱크로 두는 `src/**` 폐포」이고,
   그것은 계약 문면 밖이라 이 slice 가 하지 않는다.
2. **카드 술어의 앵커 전제.** 앵커가 비면 카드 집합이 비고 모든 등식이 공허해진다. 비-공허 단언을
   두지만, 그 단언 자신이 이 게이트 안의 마지막 비구조적 전제다(React 타입 꼴이 바뀌는 날의 자리).
