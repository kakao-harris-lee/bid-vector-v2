## (0) 위협 모델 경계 문장

**방어하는 것 — M11 의 셋을 그대로 승계한다.**

1. **판정 모집단의 구멍.** adapters dependency test 축 **열넷 전부**가 바이트코드 층과 이름 층을 둘 다
   갖고 두 층의 허용 뿌리가 집합 등식으로 묶인다.
2. **술어 종류의 미달.** 축의 판정이 소스 텍스트 import 정규식이 아니라 **컴파일 산출물의 상수 풀**이다.
3. **표와 실물의 어긋남.** 두 층 등식의 바이트코드 항이 그 축의 게이트가 **실제로 판정에 쓰는 집합
   그 자체**다.

**이 slice 가 경계를 넓히는 자리 — 3 의 되돌림 하나다.** M11 은 3 의 일부를 경계 밖으로 돌렸다:
「판정을 **다른 이름의 심볼**이나 **호출 자리의 식**으로 옮기는 꼴」은 게이트를 알고 꾸민 저자라 방어
대상이 아니라고 선언했고(M11 (0) · 알려진 제한 9), 그 구조 처방을 이 OPEN 에 넘겼다. 이 slice 는 그
처방을 실행하므로 **그 꼴이 구조적으로 막히고 3 이 온전해진다.** 경계를 **줄이지는** 않는다 — 아래
「방어하지 않는 것」은 M11 그대로다. 또한 방어가 넓어지는 것은 **판정 집합을 바꿔치우는 꼴**까지이고,
「게이트 파일 자신을 고치는 저자」는 여전히 밖이다. 다만 고쳐야 할 자리가 **열네 곳에서 한 곳으로**
줄어 diff 가 보기 쉬워진다.

**방어하지 않는 것**(M11 승계, 변경 0).

- **두 목록이 「옳은가」** — 둘이 **함께** 넓어지면 조용하다. ADR·리뷰 자리다.
- **두 층의 단일 출처화** — 범위 밖(ADR 자리).
- **게이트 자신을 고치는 저자** — 정책 파일·표·판정 test 를 의도적으로 고쳐 숨기는 것.
- **`const val` 인라인 사각** — 이름 층이 덮는 자리다.
- **값이 흐르는 경로 일반** · 축이 없는 adapters 패키지(아래 (3) 신설 OPEN (A)).

## (1) 열거인가 구성인가

**다섯 가운데 넷이 열거를 구성으로 바꾸는 편집이고, 하나(②)는 비용이다.**

| 자리 | 오늘 | 이 slice 뒤 |
| --- | --- | --- |
| 판정 입력(④) | 축 test 가 자기 `ALLOWED_ROOTS` 를 **호출 자리에 적는다** — 표는 장식일 수 있다 | 표를 **순회하는 단일 test** 가 `BYTECODE_LAYER_ROOTS` 의 (key, value) 로 판정한다. 축은 판정 호출을 갖지 않는다 |
| 추출 술어(①③) | 열 축이 정규식·호출 꼴·술어를 **각자 복제**(열 벌) | 공유 헬퍼 **한 벌**. 축 test 에서 그 코드가 사라지므로 「되돌리기」가 공유 자리 한 줄을 고치는 일이 된다 |
| 추출 층 양성 표본(⑤) | 손으로 적은 뿌리 **다섯** | `package.root` + `layer.order` + `layer.<층>` 에서 **구성** — 승인된 모듈 열 전부 |
| 축별 술어 대조 | 축마다 손으로 적은 「허용 밖 표본」·「허용 뿌리」 쌍(기계적 복제 열넷) | 표를 순회하며 **모듈 뿌리 − 축 허용 뿌리**(집합 차)를 양성 표본으로, **축 허용 뿌리**를 음성 표본으로 쓴다 |
| 축 값의 가변성((B)) | `setOf(...)` — 노출된 인스턴스를 cast 해 제자리 변경할 수 있다 | `java.util.Set.copyOf` + **변이 시도 단언**(이름이 아니라 거동) |

**열거가 남는 자리 둘**(둘 다 M11 승계): 축별 허용 뿌리의 **내용**, 그리고 축 고유의 도메인 음성 주장
(`evaluation` 의 알림함 **어댑터** 거부 · `persistence` 의 이웃 접두 · `audit` 의 persistence 거부). 뒤의
것은 기계적 복제가 아니라 **그 축에만 있는 주장**이라 축 test 에 남긴다.

## (2) 우회 — 막히는가

| 우회 | 막히는가 |
| --- | --- |
| **V-dec** 판정 집합을 같은 facade 의 **다른 이름**(`private val JUDGED_ROOTS`)으로 옮기고 `ALLOWED_ROOTS` 는 장식으로 | **막힘 — 이 라운드가 닫는다.** 축 test 에 판정 호출이 **없다**. 다른 이름의 집합을 선언해도 그것으로 판정하는 자리가 없다 |
| **V-call** 판정 호출 자리의 **식**(`disallowedCoordinates(dir, ALLOWED_ROOTS - "…")`) | **막힘 — 이 라운드가 닫는다.** 같은 이유. 단일 test 는 표의 value 를 그대로 넘기고 축은 호출 자리를 갖지 않는다 |
| 단일 test **자신의** 호출 자리에 식을 쓴다 | **안 막힘 — 등재**(경계 밖, M11 과 같은 사유). 비용이 달라진 것은 그 자리가 **열넷에서 하나**로 줄었다는 것이다 |
| **M-1** 표 값을 `(X as MutableSet).apply { add(…) }` 로 제자리 변경 | **막힘 — 이 라운드가 닫는다((B)).** 축 값이 `Set.copyOf` 이고, 표를 순회하며 **cast 후 add 가 `UnsupportedOperationException` 을 던지는가**를 잰다. 이름·클래스명이 아니라 **거동**이다 |
| 축 값을 `Set.copyOf` 에서 `setOf` 로 되돌린다 | **막힘** — 그 축에서 변이 시도 단언이 RED |
| **L-A** 허용 밖 뿌리만 골라 빼는 lookahead 축소(`bidvector[/.](?!decision\|bidding\|…)`) | **막힘 — 이 라운드가 닫는다(⑤).** 양성 표본이 승인된 모듈 **열** 뿌리 전수라 빠진 뿌리가 RED 다. 오늘 표본 밖인 다섯(`qualification`·`bidding`·`decision`·`settlement`·`app`)이 그 변이가 통과한 까닭이다 |
| 좌측 경계를 **비경계로 되돌린다** | **막힘** — `BytecodeConstantPoolTest` 의 음성 대조 둘(중첩 이름공간 · `Classfile` 머리글 경로)이 RED 고, `ml` 축이 쌍 **474** 로 붉는다 |
| 정규식을 과하게 좁혀 **아무것도 못 뽑게** 한다 | **막힘** — 추출 비공허(헤더 제외, 아래 D-12A-4) + 모듈 뿌리 전수 양성 표본 |
| 일괄 호출의 **귀속을 한 칸 민다** | **부분 — 상시로 남는 것은 헤더 계수다.** `헤더 수 == 입력 수` 는 상시 단언이고, (class, 좌표) 쌍 집합 등식은 per-file 비용(47.5초) 때문에 **상시 test 로 두지 않는다**. 전환 측정으로 남기고 알려진 제한에 등재 |
| 단일 판정 test 를 지우거나 `gate-tests.properties` 에서 뺀다 | **막힘** — `gateRegistrationGate` 양방향 등식 |
| 표에서 축을 빼거나 표를 담은 `object` 를 지운다 | **막힘** — key 집합 ↔ `source.scoped-packages` 등식 + 표 값이 **컴파일되는 심볼 참조** |
| 축 패키지에 **같은 이름**의 둘째 보유자를 둔다 | **막힘**(M11) — 보유자 단일성 |
| 표 값을 **값 식**으로 적는다(`A_ROOTS + B_ROOTS`) | **막힘**(M11) — 리플렉션 `===` 동일성 |
| 축을 `source.scoped-packages` 에서 뺀다 · 열다섯째 축을 정책에만 더한다 | **막힘**(M11) — 모집단 등식 |
| 정책 파일을 `:adapters:test` 의 **선언 입력에서 뺀다** | **안 막힘 — 등재**(10C·M11 승계, 같은 사유·같은 비용. 이 slice 는 그 줄을 만지지 않는다) |
| 양쪽 목록을 **함께** 넓힌다 | **안 막힘 — 구조적**((0) 가 경계로 선언) |
| **축이 없는 adapters 패키지**로 코드를 옮겨 거기서 층 밖에 닿는다 | **안 막힘 — 신설 OPEN (A)**(팀장 판정 2026-11-14: 범위 밖 유지 + 등재). 1급 패키지 **20** ↔ 축 **14** |
| 소스 import 정규식을 **지우지 않고** 상수 풀 술어를 남긴다 | **해당 없어진다** — 열 축에서 소스 정규식이 **사라진다**(이 slice 가 지운다). 「부재를 재는 상시 게이트 0」은 M11 그대로이고 이식 완료는 실측으로 남긴다 |
| `const val` 인라인 | **안 막힘 — 등재**(이름 층이 덮는 분담) |

**열아홉 행 가운데 막힘 열둘 · 안 막힘 다섯 · 부분 하나 · 해당 없어짐 하나**(기계 계수 — 판정
낱말로 센다). 안 막히는 다섯은 단일 test 자신의 호출 자리 식 · 선언 입력 제거 · 양쪽 함께 넓히기 ·
**축 없는 패키지**(신설 OPEN (A)) · `const val` 이고, 부분 하나는 귀속 민 꼴(상시는 헤더 계수뿐),
해당 없어지는 하나는 소스 정규식 공존(이 slice 가 그 정규식을 지운다)이다.
**새로 막히는 것은 넷**이다: V-dec · V-call · M-1 · L-A.

## (3) 과잉·미달

### 과잉 후보 — 하지 않는다

- **per-file ↔ 일괄 쌍 집합 등식을 상시 test 로.** 한 번에 **47.5초**(140 class)를 `:adapters:test` 에
  되돌려 넣는 일이고, 이 slice 의 목적이 바로 그 비용을 없애는 것이다. 전환 측정으로 남기고 등재한다.
- **「허용 뿌리가 실재하는 패키지인가」 단언** — M11 과 같은 사유(뿌리 대부분이 adapters 밖 모듈
  좌표라 전 모듈 출력을 뒤지는 축이 된다 · 정당한 선행 등재를 막는다).
- **「소스 import 정규식 0」 상시 단언** — 술어의 **부재**를 재는 게이트는 그 자체가 텍스트 술어다
  (M11 과 같은 판단). 이식 완료는 실측으로.
- **축이 없는 여섯 패키지에 축을 세우기** — 모집단 확장이라 새 결정이다(팀장 판정: 범위 밖).
- **main class 디렉터리를 리소스에서 구조적으로 찾기.** `bidvector.adapters.ModuleBoundaryAnchor` 를
  앵커로 쓰면 상대 경로가 사라지지만, 그 class 의 KDoc 이 **「실제 타입이 들어오면 지운다」** 라 지워질
  예정인 심볼에 게이트를 매는 일이 된다. 리터럴을 열넷에서 하나로 줄이는 것까지만 한다.
- **두 층의 단일 출처화** — 범위 밖 유지.

### 미달 — 유지

- 두 목록이 옳은가 · 값이 흐르는 경로 · `const val` 인라인 · 선언 입력 한 줄.
- **main class 디렉터리의 작업 디렉터리 의존.** 오늘과 같다(`check(isDirectory)` 가 명시 실패를 낸다).
  리터럴이 하나로 줄었으므로 바뀌는 자리도 하나다.
- **일괄 귀속의 쌍 집합 등식은 상시가 아니다.** 상시는 헤더 계수뿐이다.

### 미달 — 등재(신설 OPEN 하나)

- **축이 없는 adapters 패키지 여섯** — `access`·`bidding`·`notificationinbox`·`result`·`retention`·
  `snapshot`. 1급 패키지 **20** ↔ dependency test 축 **14**(실측). 두 층 등식은 **축이 있는 열넷**을
  잠그고 「열넷이 adapters 의 패키지 전부」라는 주장은 하지 않는다. 받는 자리는 팀장 판정대로
  **「그 패키지들의 의존 규칙을 정하는 slice」** 다.

## 측정 계획 — 이 설계가 무엇으로 검증되는가

   처방 뒤 각각 **그 단언에서** RED 임을 짝으로 남긴다.
2. **전환 등식**(판정 집합 불변): 축마다 per-file ↔ 일괄 **(class, 좌표) 쌍 집합 등식**과
   **`U \ A` == 헤더 쌍 집합** 등식. 착수에서 이미 전수 True 로 쟀고(`scope.md`), 구현 뒤 같은 꼴로 다시 잰다.
3. **비용**: `:adapters:test --rerun` 동일 조건 전후. **전 = 345초**(exit 0, 이 호스트, 다른 빌드 0).
4. **점검 불변**(D-12A-4): 머리글 제거가 오늘 답을 바꾸지 않음 — 점검 바늘 전수 ↔ 해당 class 의 머리글 줄.
5. **음성 대조**: 더하기만 한 변이가 아니라 **바꿔치우기**로, 커밋 뒤 `--rerun` 으로, 적용 단언과 함께.
