# M12 / adapters-javap-unify — 측정

## 1. 착수 실측 — 열네 축의 추출 집합과 호출 꼴

수치와 읽는 법은 `scope.md` 「착수 실측」이 정본이다. 요지만 둔다.

- 비경계 정규식 복제 축 **10** == per-file 호출 축 **10**(같은 집합, 전수) · 공유 헬퍼 축 **4**.
- 술어 본문은 열 벌이 **인자 이름 하나만** 다르다(`persistence` 가 `coordinate`, 아홉이
  `importedPackage`).
- `javap` 벽시계(정규식 비용 제외, 이 호스트 따뜻한 셸): 형제 열 축 **140 class · per-file 47.5초 ↔
  일괄 5.8초**. 이미 일괄인 네 축은 260 class · 일괄 3.5초(같은 class 를 per-file 로 재면 111.0초).
- 경계 고정 ↔ 비경계의 (class, 좌표) 쌍 집합: `A \ U` = **0**(부분집합) · 열세 축에서
  `U \ A` == **`Classfile` 머리글 경로 쌍 집합**(전수 True, 헤더 밖 잔차 0) · `ml` 만 헤더 72 +
  중첩 오탐 **474**. 판정은 네 조합 전부 **위반 0**(열 축).

## 2. RED 선행 — 네 우회가 **오늘** 어떻게 판정되는가

조건을 먼저 적는다(조건이 다르면 수가 다르다).

- 실행: `./gradlew --no-daemon :adapters:test --rerun --tests '*KonepsAdapterDependencyTest*'
  --tests '*ScopedAllowedRootsParityTest*' --tests '*BytecodeConstantPoolTest*'` — **13 test**.
- **탐침**: `koneps` production 에 그 축의 허용 뿌리 밖 좌표(`bidvector.bidding` 의 타입)를 참조하는
  함수 하나를 더한다. 탐침은 **더하기**다(그것이 심는 결함이다). 우회 변이는 **바꿔치우기**이고,
  적용 단언이 「옛 글자가 남지 않았음」을 센다(끼워 넣기 꼴은 자리 수가 늘지 않았음을 센다).
- 이름 층(`domainSourceReferenceGate`)은 **다른 task** 이고 이 측정에 들지 않는다 — 재는 것은
  바이트코드 층 축의 판정이다.
- 각 판은 `git reset --hard && git clean -fdq` 로 시작하고 끝난다. 산출물은 **먼저 커밋**돼 있다.

| 판 | 꼴 | 오늘 | 붉은 단언 |
| --- | --- | --- | --- |
| **통제군 C** | 탐침만 | **exit 1 · 13/1** | `koneps` 축의 판정 test |
| **V-dec** | 판정 인자를 **별도 심볼** `JUDGED_ROOTS`(= `ALLOWED_ROOTS` + 한 뿌리)로 바꿔치움 | **exit 0 · 13/0** | — |
| **V-call** | 판정 인자를 **호출 자리의 식**(`ALLOWED_ROOTS + "…"`)으로 바꿔치움 | **exit 0 · 13/0** | — |
| **M-1** | 표 항목만 `(KONEPS_ROOTS as MutableSet).apply { add(…) }` 로 바꿔치움 | **exit 1 · 13/1** | 두 층 **집합 등식** |
| **M-1b** | 위 + **이름 층 정책 한 줄**을 함께 넓힘. 축의 `ALLOWED_ROOTS` **선언은 그대로** | **exit 0 · 13/0** | — |
| **L-A** | `SELF_COORDINATE` 를 **뿌리 겨냥 lookahead** 로 바꿔치움 | **exit 0 · 13/0** | — |

**통제군이 건전하다** — 탐침만 심은 판이 붉고, 붉은 자리가 바로 그 축의 판정 test 다. 그래서 뒤의
초록 넷은 「게이트에 닿지 않아서 조용한 것」이 아니다.

**M11 알려진 제한 10 의 문면을 한 자리 바로잡는다.** M11 은 그 꼴을 「`===` 가 성립해 exit 0」으로
적었는데, **표만 제자리 변경하면 두 층 집합 등식이 잡는다**(위 M-1, 실측 exit 1). 열려 있는 것은
**M-1b** 다 — 이름 층 정책을 한 줄 넓히고 표를 제자리 변경하면서 **축의 선언은 건드리지 않는** 꼴이고,
그때 읽는 사람은 뿌리 **셋**을 보고 게이트는 **넷**으로 판정한다. (B) 가 막으려는 것이 그 속임이다.
「양쪽을 함께 넓힌다」(경계 밖)와 갈리는 지점은 **축의 선언이 거짓이 되는가**다.
