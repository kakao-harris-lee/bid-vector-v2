## 2. RED 선행 — 네 우회가 **오늘** 어떻게 판정되는가

조건을 먼저 적는다(조건이 다르면 수가 다르다).

- 실행: `./gradlew --no-daemon :adapters:test --rerun --tests '*KonepsAdapterDependencyTest*'
  --tests '*ScopedAllowedRootsParityTest*' --tests '*BytecodeConstantPoolTest*'` — **13 test**.
- **탐침**: `koneps` production 에 그 축의 허용 뿌리 밖 좌표(`bidvector.bidding` 의 타입)를 참조하는

  적용 단언이 「옛 글자가 남지 않았음」을 센다(끼워 넣기 꼴은 자리 수가 늘지 않았음을 센다).
- 이름 층(`domainSourceReferenceGate`)은 **다른 task** 이고 이 측정에 들지 않는다 — 재는 것은
  바이트코드 층 축의 판정이다.
- 각 판은 `git reset --hard && git clean -fdq` 로 시작하고 끝난다. 산출물은 **먼저 커밋**돼 있다.

## 6. 전환 등식 — 출하 본문(`Constant pool:` 에서 시작)에서

위 §1 의 「`U \ A` == 머리글 쌍」은 **머리글 줄만 떼던 본문**을 잰 것이다. cr MEDIUM-1 뒤 본문이
`Constant pool:` 에서 시작하므로 그 비교를 **출하 본문에서 다시 쟀고, 답이 더 단순해졌다.**

| 재는 것 | 열세 축 | `ml` |
| --- | --- | --- |
| per-file ↔ 일괄 (class, 좌표) 쌍 집합 | **같다**(전수 14/14) | 같다 |
| `A \ U`(경계 고정이 더 뽑는가) | **0** | **0** |
| `U \ A`(비경계가 더 뽑는가) | **0** | **474**(중첩 이름공간 오탐) |
| 위반 수(per/일괄 × 비경계/경계) | **네 조합 전부 0** | 비경계 474 · 경계 0 |

읽는 법: **상수 풀만 보면 경계 고정과 비경계가 열세 축에서 쌍 단위로 완전히 같다.** 경계가 버리는
것은 `ml` 의 오탐 474 뿐이고 실제 좌표의 손실은 **0** 이다. 머리말을 담던 앞 판에서 보이던 「class
하나당 한 쌍」의 차이는 그 머리말이 만들던 것이었다.

「위반 0 == 위반 0」만 보면 이 사실이 보이지 않는다 — 그래서 잠금이 쌍 집합 등식이다.

### MEDIUM-1 — 본문이 javap 머리말을 담아 추출 비공허가 상수 풀 없이도 섰다

cr 의 실측: 머리글 줄만 떼면 `Constant pool:` 앞의 **class 선언 줄**(`public final class
bidvector.adapters.<축>.X`)과 `this_class`·`super_class` 가 남고, 그래서 슬래시 꼴을 버리는 축소
변이가 적중을 **56500 → 3953** 으로 줄여도 **추출 0 인 class 가 534 중 0** 이라 가드가 초록이었다.

**처방: 본문을 `Constant pool:` 줄에서 끊는다.** 그 자리가 없으면 명시 실패다(모든 class 는 상수
풀을 갖는다 — 출력 형태가 바뀐 것이고 조용히 넘기면 안 된다).

**끊은 뒤 전수로 다시 쟀다.**

| 재는 것 | 결과 |
| --- | --- |
| 축별 (class, 좌표) 쌍 집합 — 끊기 전 ↔ 후 | **열네 축 전부 같다**(차집합 0). 머리말의 좌표는 상수 풀 항목과 **같은 쌍**이라 집합이 안 움직인다 |
| 판정(허용 밖 좌표 수) | **열네 축 전부 0 → 0** |
| 축 고유 `contains` 점검 | 답 불변(바늘이 전부 상수 풀·`Code` 쪽이다. 표적 test 전수 초록) |

**가드의 한계는 실측대로 적었다 — 처방이 그 변이를 붉히지는 못한다.** 가드는 **디렉터리 합**이고
상수 풀에도 점 표기 문자열이 남아, 같은 축소 변이에서 축별 합이 **8~680**(0 이 아님)이다. 바뀐 것은
**세는 수가 상수 풀 적중이 됐다**는 것이고, 정규식의 **모양**을 지는 것은 `BytecodeConstantPoolTest`
의 구성 표본이다(cr 도 같은 결론). 과장돼 있던 문면 셋(헬퍼 주석 · checklist ③ · capability map ③)을
이 실측으로 낮췄다.
