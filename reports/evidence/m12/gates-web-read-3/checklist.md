## 알려진 제한

1. **ⓑ⑤ 거부의 문면이 원인을 말하지 않는다.** 번들러 적재가 Kotlin 을 끌어오면 적재는 실패하지만
   표면에 뜨는 오류는 vite 의 `ENOENT`(상대 경로)다. 통제군이 「실패가 Kotlin 축에서만 일어난다」를
   들지만 사람이 읽는 문면은 층의 거부가 아니다. 신설 OPEN ⑤.
2. **`eval: true` worker 는 층 밖이다**(r2 에 좁혔다). 앞 판은 「worker 에 서지 않는다」로 적었는데
   **너무 넓었다** — 다시 재니 **파일 worker 는 `execArgv` 상속으로 층이 선다**(거부됨). 코드
   문자열로 띄운 worker 만 밖이다(읽힘 1613). vitest 의 스레드 풀 워커도 파일 worker 라 층이
   선다 — 그래서 `test.setupFiles` 배선은 **하중이 없어 지웠다**(두 풀에서 각각 실측). 신설 OPEN ①.
3. **자식 프로세스 텍스트 검색은 층 밖이다**(`grep`·`git grep`). node 안에 가로챌 자리가 없고
   경로 리터럴도 필요 없다. 신설 OPEN ①.
4. **`node_modules` 아래로 복사한 뒤 읽기는 열려 있다.** 층의 남은 유일한 위치 예외이고, 지우지
   않은 이유가 측정에 있다(전건 9.19s → 10.44s). 평범한 관용구가 아니라 의도적 은닉이라 경계
   밖이다. 신설 OPEN ②.
5. **AST 경로 술어는 대소문자를 가린다** — 데이터 파일 술어와 짝이 맞지 않는다. `i` 를 붙이면 그
   술어가 식별자도 보므로 게이트 자신의 상수 이름이 걸린다(실측). 데이터 파일 쪽도 **일률 무시가
   아니라** 경로·glob 구두점 뒤에서만 다른 대소문자를 든다(r3 — 상호·산문이 걸렸다). 신설 OPEN ③.
6. **`.npmrc` 가 싣는 지정자는 상대 경로다.** 층이 적재되는 즉시 **자기 절대 URL 로 바로잡아**
   자식에게 넘기므로 cwd 가 다른 자식도 뜬다(대조로 잠갔다). 바로잡기가 자기 토큰을 **이름으로**
   고르는 것이 약한 고리인데, 못 고르면 층이 조용히 사라지는 것이 아니라 **자식이 죽어서** 붉어진다.
   (앞 판이 여기 적었던 「공백 있는 경로에서 전파가 꺼진다」는 **사실이 아니었다** — `import.meta.url`
   이 공백을 `%20` 으로 인코딩해 그 분기는 죽어 있었고, r3 에 지웠다.)
7. **npm 밖에서 직접 띄운 node 는 층이 닿지 않는다**(사람이 셸에서 띄우는 프로세스 · IDE 러너 ·
   **Node 24 내장 `node --run <script>`** — npm 을 거치지 않아 `.npmrc` 를 읽지 않는다. 실측 READ).
   층을 싣는 것이 `.npmrc` 이기 때문이고, 저자의 의도와 무관한 **기구의 범위**다. CI 의 web 명령은
   전부 `npm run …` 임을 실측했다. 신설 OPEN ④ · `scope.md` §위협 모델 경계.
8. **커널의 호출자 판정은 두 층의 합이다**(r2 — cr HIGH). 직접 호출은 프레임이, 읽기를 통한
   호출은 **한 발 악수**가 거부한다. 프레임만으로는 `bind` 처럼 프레임을 남기지 않는 래퍼가
   지나간다 — 이 slice 가 허용 호출자를 입구에서 읽기로 옮기며 **새로 연** 자리이고, K5 대조가
   상설로 잰다. 악수는 **읽기 경유 호출에만** 걸리므로 단위 test 의 합성 입력 대조는 그대로다.

9. **ⓒ 는 좁아졌을 뿐 닫히지 않았다.** 원문에 이름을 붙일 자리가 넘긴 함수의 매개변수 하나로
   줄었고, 흔한 표기는 기존 완화 층이 든다. 경계로 둘로 갈린다(정규화는 경계 안의 부분 · 걷기
   재구현·항등 함수는 경계 밖). **항등 후조건이 보는 것은 반환값 자체의 동일성뿐이다** — 원문을
   담아 내보내는 꼴(`[t]` · `{ source: t }` · `async t => t` · `t => () => t`)은 지나간다(r3 실측
   넷). 그릇·promise·클로저 열거는 끝나지 않으므로 등재한다.
10. **ⓕ-2 가 쓰기 규율을 하나 만든다** — 추적되는 데이터 파일의 산문은 Kotlin 확장자를 축어로 적을
   수 없다(술어에 주석 개념이 없다). 탈출구는 파일별 값 차감이다.
