# M12 / gates-web-read-3 — 설계 검토 (Phase 2.5)

받는 것은 `OPEN-M11-KOTLIN-READ-GATE-RESIDUALS-2` ⓐ~ⓕ 다. 팀장 착수 판정(2026-11-14)이 처분을
확정했다 — **닫음** ⓐ·ⓑ③·ⓑ⑤·ⓕ-1, **정적 층 보강** ⓕ-2, **등재 유지** ⓑ①②④·ⓒ·ⓓ·ⓔ·ⓕ-3,
**승인(마지막·별 커밋)** ⓑ⑥. 이 문서는 그 판정을 설계로 옮기고 남는 자리를 미리 센다.

## (0) 위협 모델 경계 — M11 계약을 그대로 승계한다

**방어하는 것:** web test·스크립트가 **평범한 관용구로** Kotlin 원문을 읽게 되는 표류 — 새 test 가
경로 문자열·glob·데이터 파일·심볼릭 링크·대소문자 차이로 원문을 여는 것. 「저자가 게이트를
의식하지 않고 쓴 코드」가 기준이다.

**방어하지 않는 것:** 게이트를 알고 **의도적으로 숨기는** 저자 — 경로를 런타임에 조립해
난독화하거나, 게이트 파일·vitest setup·eslint 설정 자체를 고치는 것. 경계 밖은 **등재로 답하고
수정 라운드를 열지 않는다.**

## (1) 열거인가 구성인가

| 축 | 열거였다면 | 이 판 |
| --- | --- | --- |
| **ⓐ** 단언을 부르지 않는 추출 함수 | Kotlin 값이 흘러드는 호출을 **데이터 흐름**으로 쫓고, 홉 수·별칭·`.trim()`·spread·콜백·메서드 피호출자마다 처방을 더한다(M10/10D 가 상한을 넘긴 축이고 M11 이 한 홉에서 멈춘 자리다) | 원문을 얻는 길을 **키 + 추출 함수** 하나로 둔다. 「단언을 부르는가」라는 **질문이 사라진다** — 부를 수 없으면 텍스트가 없다. **모집단이라는 개념 자체가 없어지므로** 꼴을 세는 자리가 남지 않는다 |
| **ⓑ③** 저장소 밖 복사 뒤 읽기 | 「저장소 밖 자리」 목록(tmp·홈·형제 worktree…) | 층에서 **위치를 묻는 분기를 지운다** — 해석된 실경로의 확장자만 본다. 남는 예외는 `node_modules` 하나이고 그 사유는 성능이 아니라 **모듈 적재가 전부 실경로를 탄다**는 것이다 |
| **ⓑ⑤** 번들러 적재 | 접미 목록(`?raw`·`?worker`·`?url`…) 또는 「`import.meta.glob` 금지」 린트 — 다음 접미·플러그인 하나로 열린다(같은 저장소의 `module-graph-boundary` 머리 주석이 그 실패를 적는다) | **그 프로세스에 층을 세운다.** 어느 접미로 들어오든 파일을 여는 것은 vite 메인 프로세스이고, 층은 여는 행위를 본다 |
| **ⓑ⑥** vitest 밖 프로세스 | 진입점 **손 목록**(M11 이 그래서 고르지 않았다). **첫 판이 그 자리로 돌아갔다** — 명령마다 플래그·config 마다 import 를 요구하고 의무를 **텍스트 꼴**로 셌다(r1 H-1 이 평범한 표기 넷으로 열었다) | **선언 한 줄**(`web/.npmrc` 의 `node-options`)로 옮긴다. npm 이 그것을 **모든 스크립트의 `NODE_OPTIONS`** 에 실으므로 명령의 모양도 config 의 자리도 술어에서 빠진다 — 모집단을 「뽑는」 일 자체가 없어진다. 술어는 **선언이 있는가**(구조)와 **실제로 거부하는가**(거동) 둘 |
| **ⓕ-1** 대문자 확장자 | 대소문자 꼴 목록 | 런타임 층과 **같은 성질**(대소문자 무시)을 쓴다 — 플래그 하나 |
| **ⓕ-2** `#` 데이터 줄 | 형식마다 주석 구문 표(`#` · `//` · `<!-- -->`). 그 표가 곧 목록이고, **문자열 안의 `//` 를 주석으로 읽는 함정**이 딸려 온다 — 이 저장소가 Kotlin 에서 밟아 `kotlin-comment-strip.mjs` 를 만든 바로 그 함정이다 | **주석 개념을 술어에서 없앤다.** 추적 비 AST 파일의 토큰 전부를 보고 예외는 **파일별 값 차감** 하나뿐이다. 오늘 차감을 0 으로 두려고 등록부 산문 한 줄을 고친다(그 줄이 이 술어가 거르던 유일한 자리다 — 실측 1 건) |

**값 한 줄이 아니라 구조를 바꾸는 변경이므로**, 각 축의 주장은 아래 (2) 의 되돌림 대조로 잠근다.

## (2b) 값 획득 축 — 새 public 표면 전수

| 표면 | 값을 어디서 얻는가 |
| --- | --- |
| `withKotlinSource(key, extract, …rest)` — 신설, 원문을 얻는 **유일한** 길 | **인자뿐**. 키는 비공개 표의 키여야 하고(모르면 던진다), `extract` 는 함수여야 하고(아니면 던진다), `rest` 는 그대로 넘긴다. 시계·네트워크·환경변수·경로를 읽지 않는다 |
| **그 함수에 주입되는 값**(`extract` 가 받는 것) | **걷힌 텍스트 하나와 호출자가 준 `rest`뿐**. 경로·키 표·읽기 핸들·모듈 참조를 주지 않는다 — 주입 자리에서 새는 것이 없다 |
| 읽기의 **결과 후조건** | **그 호출의 텍스트와 결과값뿐**(문자열 동일성 한 번). 밖에서 켜고 끄는 입구를 두지 않는다 |
| `KOTLIN_SOURCE_KEYS` | 비공개 표의 **키 전수**. 경로는 내보내지 않는다(앞 판 그대로) |
| 층 모듈의 `NOT_WRAPPED` · 위치 분기 | 분기가 **하나 줄어든다**(저장소 경계). 남는 값은 `node_modules` 구분자 한 문자열 |
| setup 모듈 — `NODE_OPTIONS` 정규화(r1 변경) | **자기 절대 URL 과 현재 `NODE_OPTIONS` 토큰뿐**. 변수를 덮어쓰지 않고 **자기 지정자만** 골라 절대 URL 로 바꾼다(남이 실은 `--import` 는 보존). `.npmrc` 가 싣는 상대 지정자를 그대로 물려주면 **cwd 가 다른 자식이 뜨지 못한다**(실측) — 고르는 기준이 파일 이름이라, 못 고르면 층이 조용히 사라지는 것이 아니라 **자식이 죽는 쪽**으로 실패한다 |
| **`web/.npmrc` 의 `node-options`**(r1 신설 — 모집단 둘을 대신한다) | **값은 지정자 한 줄**이고 그것을 읽는 것은 **npm** 이다. 저장소 코드가 그 값을 읽거나 바꾸지 않는다 — 게이트는 그 줄이 층을 가리키는지(구조)와 그 아래 프로세스가 실제로 거부하는지(거동)를 본다. 앞 판의 모집단 둘(`git ls-files` 의 뿌리 `*.config.*` · `scripts` 의 `node` 명령)은 **술어에서 사라졌다** |
| 데이터 파일 술어 | **인자 텍스트 + 그 파일의 차감 값 집합**. 파일시스템을 다시 읽지 않는다 |
| **커널의 비공개 in-flight 슬롯**(r2 신설) | **읽기가 건 텍스트 하나**. 거는 자리는 호출자 프레임으로 **읽기 모듈 하나**로 고정되고, 호출이 끝나면 **비운다**(`finally`). 밖에서 읽을 수 있는 것은 「이 텍스트가 걸린 것인가」라는 **불리언**뿐이다 — 값을 내주지 않는다 |
| **읽기의 악수 호출**(r2 신설) | **그 호출의 텍스트뿐**. 중첩 호출은 **금지**한다(걸려 있는데 또 걸면 던진다) — 허용하면 안쪽 호출이 바깥 슬롯을 덮어 두 값이 섞인다 |
| **탐침 둘**(`scripts/kotlin-read-probe.mjs` · `e2e/probe-config/playwright.probe.config.ts`) — r1 신설 | 탐침은 **읽기를 시도하고 결과를 한 줄로 낸다**. 정본 경로를 적지 않고 `git` 에게 묻는다. 탐침 config 는 **스모크 레인의 그 spec** 을 돌린다(새 spec 을 만들지 않는다) |
| (경계로 처리) `web/vite.config.ts` · `web/package.json` · `web/config/gate-tests.txt` | 12B·12D 와 겹칠 수 있는 자리 — `scope.md` §공유 파일의 **계수**로 병합을 확인한다. `vite.config.ts` 는 import **한 줄**만 더하고 `test:` 블록을 건드리지 않는다 |

**없어지는 표면 둘**: `readKotlinSource`(원문을 **문자열로** 내주던 자리)와
`assertStrippedKotlin`(저자가 **잊을 수 있던** 호출). 공개 표면이 셋에서 **둘**로 줄고, 그 수는
기존 export 집합 등식이 든다.

## (3) 과잉·미달

### 과잉이 될 수 있는 것

**ⓑ⑥ 이 층을 싣는 프로세스의 범위.** r1 뒤로 그 범위는 **npm 이 띄우는 전부**다 — `eslint`·
`tsc`·`vite build`·`preview`·playwright·게이트 스크립트. 좁히려면 다시 명령이나 config 를 열거해야
하므로 좁히지 않고 **비용을 잰다**(W-2 lint · W-8 build · W-9 카나리 · W-11 스모크 · W-13 여정).
M11 의 미달 Ⅰc 를 승계한다: 넓은 층의 비용은 **그 층이 보는 값의 크기**에 달려 있어 일반화하지
않는다.

**넓힌 층 범위(저장소 밖).** vitest 전건으로 쟀다(44 파일·987 test 초록, 소요가 기준과 잡음 안).
`build`·`lint`·여정은 ⓑ⑥ 커밋에서 같이 잰다 — **앞 커밋의 측정을 뒤 커밋에 옮겨 적지 않는다.**

### 미달 — 등재하는 자리

### 「넘긴 함수 안의 변형」은 경계 안인가 — 보고

**둘로 갈린다.**

- **경계 안**: 저자가 추출 전에 텍스트를 **정규화**하는 꼴(공백 정리·줄 끝 통일). 게이트를
  의식하지 않은 평범한 손질이고, 그것이 걷기 보증을 무르게 한다는 것을 저자가 모를 수 있다.
  이 꼴의 **흔한 표기**는 기존 완화 층(주석 표지를 인자로 넘기는 치환·탐색)이 전 추적 파일에서
  든다 — 그래서 「부분」이다.
- **경계 밖**: 걷기를 **다시 구현**하거나 항등 함수로 원문을 빼내는 꼴. 추출과 무관한 수술이고
  목적이 게이트 회피다.

**그래서 ⓒ 는 「등재 유지 + 자리가 좁아졌다」로 적는다.** 앞 판에서는 원문 문자열이 소비자 쪽에
**이름으로 존재**해 어느 줄에서든 손댈 수 있었다. 새 판에서는 이름 붙일 자리가 **넘긴 함수의
매개변수 하나**뿐이고, 그 함수는 diff 에 남는다.

### 지우는 대조와 그 대체 주장 (죽은 분기와 그 test)

입구가 텍스트를 받지 않게 되면 「입구가 손댄 텍스트를 거부한다」 묶음은 **주어를 잃는다**. 지우지
않고 **주장을 바꾼다**.

| 지금 재는 것 | 새 판에서 그 자리가 재는 것 |
| --- | --- |
| 입구가 **걷히지 않은** 텍스트를 거부한다 | 입구에 텍스트를 **넘길 자리가 없다** — 커널에 손댄 텍스트가 닿는 길 **둘**이 막힌다(r2): 직접 호출은 **호출자 프레임**이, 읽기를 통한 호출은 **한 발 악수**가 거부한다. 앞 판은 프레임 하나로 적었고 `bind` 세탁이 그것을 지나갔다 |
| 입구가 **가린 원문**(재현 사본)을 거부한다 | 추출의 결과가 **원문 자체이면** 읽기가 거부한다(신설 후조건) |
| 입구가 **합성 텍스트**를 거부한다 | 공개 표면이 **둘**이다(기존 export 집합 등식 — 셋에서 둘로) |
| 모집단 등식(추출 함수 전수가 단언을 부른다) | **없어진다.** 그 질문의 전제(원문을 문자열로 받는 소비자)가 사라진다 — 지우는 사유를 그 자리에 적는다 |

## r1 추가 — verifier 가 연 네 꼴과 그 닫힘 (2026-11-15)

H-1 은 **술어의 미달**이었다(깨진 게이트가 아니다). 그래서 「깨지면 그 커밋만 되돌리고 등재」
조항이 아니라 **구조로 옮기는** 쪽으로 처리했다. 아래가 그 전후이고 넷 다 **상설 대조**로 남는다.

| 꼴 | 첫 판 | 지금 | 대조가 사는 자리 |
| --- | --- | --- | --- |
| `NODE_ENV=test node …`(환경변수 접두) | 게이트 초록 · **READ** | **REFUSED** | 탐침 스크립트 — 첫 줄 |
| `true; node …`(`;` 로 이은 둘째 명령) | 게이트 초록 · **READ** | **REFUSED** | 같은 탐침 — 둘째 줄 |
| `env FOO=1 node …` | 게이트 초록 · **READ** | **REFUSED** | 같은 탐침 — 셋째 줄 |
| 하위 디렉터리 config 로 띄운 spec | 게이트 초록 · **READ** | **REFUSED** | 탐침 config + 스모크 spec |
| (음성) 층 없이 같은 탐침 | — | **READ** | 같은 묶음 |

**왜 열거가 아니라 선언인가.** 앞의 셋은 셸 문법의 변형이고 넷째는 파일의 자리다 — 그 넷을 술어에
더하는 길은 다섯째를 부른다(`&&` 로 이은 셋째 명령 · `sh -c` · 심볼릭 링크로 건 config…).
`.npmrc` 는 **그 모두가 거쳐 가는 한 자리**이고, 「npm 이 띄운 프로세스」라는 조건은 셸 문법이나
파일 자리로 바꿀 수 없다. 남는 것은 **npm 밖에서 직접 띄운 node** 하나이고 그것은 경계 문장과
신설 OPEN 이 받는다.

**그 대가 하나를 같이 적는다.** `.npmrc` 의 지정자는 상대 경로이고 자식은 그것을 **자기 cwd
기준**으로 푼다 — 그대로 물려주면 cwd 가 다른 자식이 `ERR_MODULE_NOT_FOUND` 로 **뜨지도 못한다**
(실측). 층이 자기 절대 URL 로 바로잡아 싣고, 그 자리를 **cwd 가 다른 자식** 대조가 잠근다.

## r2 추가 — cr HIGH 가 연 세탁 경로와 그 닫힘 (2026-11-15)

**이 slice 가 새로 연 자리다.** M11 판에서 커널의 허용 호출자는 `opening-axis.mjs` 와 그 단위
test 였고 **둘 다 직접 호출**이라 `bind` 로 넘길 것이 없었다. ⓐ 가 허용 호출자를 **읽기 모듈**로
옮기면서, 읽기가 **호출자가 건넨 임의의 함수**를 부르는 구조가 됐다 — 그 함수가 `bind` 로 인자를
미리 채운 네이티브 래퍼면 스택에 프레임이 남지 않아 커널이 보는 호출자가 읽기가 된다.

| 꼴 | cr 실측 | 처방 뒤 |
| --- | --- | --- |
| F1 람다 래퍼(`(t) => kernel.fn(bad)`) | **THROW**(프레임 거부) | 그대로 THROW |
| F2 `kernel.fn.bind(null, bad)` | **통과 — 손댄 값이 나온다** | **THROW**(악수 불일치) |
| F3 `kernel.fn.call.bind(kernel.fn, bad)` | **통과** | **THROW** |
| F4 통제군(진짜 값) | 통과 | **통과**(값이 같다 — 일률 거절이 아니다) |

**왜 ①(한 발 악수)인가.** ②(주장을 내리고 등재)는 「닫힘(구조)」 판정을 그만큼 무르게 한다 —
그 판정이 모집단 기계 **150 줄**을 지운 사유이므로, 대체 주장 셋 가운데 하나가 무너지면 지운
근거가 약해진다. ① 은 값 동일성을 **전역으로** 되돌리는 것이 아니라 **읽기 경유 호출에만** 거는
것이라, M11 이 커널을 가른 사유(합성 입력 대조)를 깨지 않는다 — 단위 test 는 허용 호출자로서
합성 조각을 그대로 먹인다.

**비동기 추출은 받지 않는다**(팀장 지시로 r2 에 실측하고 정했다). 악수와 호출자 프레임은 둘 다
**그 동기 호출 구간**에만 선다 — `await` 뒤에 커널을 부르면 둘 다 닫혀 있어 거부되는데, 그 거부의
문면이 **원인을 잘못 말했다**(실측: 「직접 불렀다」). 그래서 읽기가 먼저 막고 문면이 원인을 말하게
한다. 덤으로 **ⓒ 의 우회 꼴 하나가 닫힌다**(`async (t) => t` — 앞 판은 원문 251 자를 그대로 냈다).
**병행은 막지 않는다**: 읽기 구간이 동기라 두 읽기가 겹치지 않는다(동시 둘 통과 — 실측). 「중첩
금지」가 정당한 병행을 던지는 자리는 **없다**.

**대체 주장 #3 의 문면을 실측대로 다시 세운다.** 「커널은 읽기 모듈과 자기 단위 test 만 **부를 수
있다**」는 프레임만 보는 주장이었다. 지금 주장은 둘이다 — ⓐ 직접 호출은 **프레임**이 거부하고
ⓑ 읽기를 통한 호출은 **악수**가 거부한다. 그 둘의 합이라야 「손댄 텍스트가 커널에 닿지 않는다」가
선다.
