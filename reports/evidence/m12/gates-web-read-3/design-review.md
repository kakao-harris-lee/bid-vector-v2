# M12 / gates-web-read-3 — 설계 검토 (Phase 2.5)

받는 것은 `OPEN-M11-KOTLIN-READ-GATE-RESIDUALS-2` ⓐ~ⓕ 다. 팀장 착수 판정(2026-11-14)이 처분을
확정했다 — **닫음** ⓐ·ⓑ③·ⓑ⑤·ⓕ-1, **정적 층 보강** ⓕ-2, **등재 유지** ⓑ①②④·ⓒ·ⓓ·ⓔ·ⓕ-3,
**승인(마지막·별 커밋)** ⓑ⑥. 이 문서는 그 판정을 설계로 옮기고 남는 자리를 미리 센다.

## (0) 위협 모델 경계 — M11 계약을 그대로 승계한다

**방어하는 것:** web test·스크립트가 **평범한 관용구로** Kotlin 원문을 읽게 되는 표류 — 새 test 가
경로 문자열·glob·데이터 파일·심볼릭 링크·대소문자 차이로 원문을 여는 것. 「저자가 게이트를
의식하지 않고 쓴 코드」가 기준이다.

**방어하지 않는 것:** 게이트를 알고 **의도적으로 숨기는** 저자 — 경로를 런타임에 조립해
난독화하거나, 게이트 파일·vitest setup·eslint 설정 자체를 고치는 것. 경계 밖은 **등재로 답하고
수정 라운드를 열지 않는다.**

## (1) 열거인가 구성인가

| 축 | 열거였다면 | 이 판 |
| --- | --- | --- |
| **ⓐ** 단언을 부르지 않는 추출 함수 | Kotlin 값이 흘러드는 호출을 **데이터 흐름**으로 쫓고, 홉 수·별칭·`.trim()`·spread·콜백·메서드 피호출자마다 처방을 더한다(M10/10D 가 상한을 넘긴 축이고 M11 이 한 홉에서 멈춘 자리다) | 원문을 얻는 길을 **키 + 추출 함수** 하나로 둔다. 「단언을 부르는가」라는 **질문이 사라진다** — 부를 수 없으면 텍스트가 없다. **모집단이라는 개념 자체가 없어지므로** 꼴을 세는 자리가 남지 않는다 |
| **ⓑ③** 저장소 밖 복사 뒤 읽기 | 「저장소 밖 자리」 목록(tmp·홈·형제 worktree…) | 층에서 **위치를 묻는 분기를 지운다** — 해석된 실경로의 확장자만 본다. 남는 예외는 `node_modules` 하나이고 그 사유는 성능이 아니라 **모듈 적재가 전부 실경로를 탄다**는 것이다 |
| **ⓑ⑤** 번들러 적재 | 접미 목록(`?raw`·`?worker`·`?url`…) 또는 「`import.meta.glob` 금지」 린트 — 다음 접미·플러그인 하나로 열린다(같은 저장소의 `module-graph-boundary` 머리 주석이 그 실패를 적는다) | **그 프로세스에 층을 세운다.** 어느 접미로 들어오든 파일을 여는 것은 vite 메인 프로세스이고, 층은 여는 행위를 본다 |
| **ⓑ⑥** vitest 밖 프로세스 | 진입점 **손 목록**(M11 이 그래서 고르지 않았다) | 의무의 **모집단을 선언에서 뽑는다** — 추적된 뿌리 `*.config.*` **전수**와 `package.json` `scripts` 의 `node` 명령 **전수**. 기구는 **하나**(`--import`)이고, 층 모듈이 자기를 `NODE_OPTIONS` 에 실어 자식 프로세스로 **전파**하므로 진입점마다 처방이 다르지 않다 |
| **ⓕ-1** 대문자 확장자 | 대소문자 꼴 목록 | 런타임 층과 **같은 성질**(대소문자 무시)을 쓴다 — 플래그 하나 |
| **ⓕ-2** `#` 데이터 줄 | 형식마다 주석 구문 표(`#` · `//` · `<!-- -->`). 그 표가 곧 목록이고, **문자열 안의 `//` 를 주석으로 읽는 함정**이 딸려 온다 — 이 저장소가 Kotlin 에서 밟아 `kotlin-comment-strip.mjs` 를 만든 바로 그 함정이다 | **주석 개념을 술어에서 없앤다.** 추적 비 AST 파일의 토큰 전부를 보고 예외는 **파일별 값 차감** 하나뿐이다. 오늘 차감을 0 으로 두려고 등록부 산문 한 줄을 고친다(그 줄이 이 술어가 거르던 유일한 자리다 — 실측 1 건) |

**값 한 줄이 아니라 구조를 바꾸는 변경이므로**, 각 축의 주장은 아래 (2) 의 되돌림 대조로 잠근다.

## (2b) 값 획득 축 — 새 public 표면 전수

| 표면 | 값을 어디서 얻는가 |
| --- | --- |
| `withKotlinSource(key, extract, …rest)` — 신설, 원문을 얻는 **유일한** 길 | **인자뿐**. 키는 비공개 표의 키여야 하고(모르면 던진다), `extract` 는 함수여야 하고(아니면 던진다), `rest` 는 그대로 넘긴다. 시계·네트워크·환경변수·경로를 읽지 않는다 |
| **그 함수에 주입되는 값**(`extract` 가 받는 것) | **걷힌 텍스트 하나와 호출자가 준 `rest`뿐**. 경로·키 표·읽기 핸들·모듈 참조를 주지 않는다 — 주입 자리에서 새는 것이 없다 |
| 읽기의 **결과 후조건** | **그 호출의 텍스트와 결과값뿐**(문자열 동일성 한 번). 밖에서 켜고 끄는 입구를 두지 않는다 |
| `KOTLIN_SOURCE_KEYS` | 비공개 표의 **키 전수**. 경로는 내보내지 않는다(앞 판 그대로) |
| 층 모듈의 `NOT_WRAPPED` · 위치 분기 | 분기가 **하나 줄어든다**(저장소 경계). 남는 값은 `node_modules` 구분자 한 문자열 |
| setup 모듈 — 신설 역할(자기를 `NODE_OPTIONS` 에 싣는다) | **자기 모듈 경로와 기존 `NODE_OPTIONS` 값뿐**. 이미 실려 있으면 다시 싣지 않는다(중첩 누적 금지). 설정 파일·환경변수로 켜고 끄는 입구는 두지 않는다 |
| 의무 게이트의 모집단 둘 | **`git ls-files` 의 뿌리 `*.config.*`** 와 **`package.json` 의 `scripts` 값**. 손 목록이 없다 |
| 데이터 파일 술어 | **인자 텍스트 + 그 파일의 차감 값 집합**. 파일시스템을 다시 읽지 않는다 |
| (경계로 처리) `web/vite.config.ts` · `web/package.json` · `web/config/gate-tests.txt` | 12B·12D 와 겹칠 수 있는 자리 — `scope.md` §공유 파일의 **계수**로 병합을 확인한다. `vite.config.ts` 는 import **한 줄**만 더하고 `test:` 블록을 건드리지 않는다 |

**없어지는 표면 둘**: `readKotlinSource`(원문을 **문자열로** 내주던 자리)와
`assertStrippedKotlin`(저자가 **잊을 수 있던** 호출). 공개 표면이 셋에서 **둘**로 줄고, 그 수는
기존 export 집합 등식이 든다.

## (3) 과잉·미달

### 과잉이 될 수 있는 것

**ⓑ⑥ 이 층을 싣는 프로세스의 범위.** 뿌리 config 전수가 모집단이므로 `eslint` 프로세스와
`vite build`·`vite preview` 까지 층 아래서 돈다. 읽기 축에서 그 프로세스들은 **저장소가 쓴
코드를 적재**하므로(eslint 설정·vite 설정) 범위에서 빼면 그 자리가 구멍이 된다 — 그래서 넣고
**비용을 잰다**(W-2 lint · W-8 build · W-9 카나리 · W-11 스모크 · W-13 여정). M11 의 미달 Ⅰc 를
승계한다: 넓은 층의 비용은 **그 층이 보는 값의 크기**에 달려 있어 일반화하지 않는다.

**넓힌 층 범위(저장소 밖).** vitest 전건으로 쟀다(44 파일·987 test 초록, 소요가 기준과 잡음 안).
`build`·`lint`·여정은 ⓑ⑥ 커밋에서 같이 잰다 — **앞 커밋의 측정을 뒤 커밋에 옮겨 적지 않는다.**

| **ⓑ①② 자식 프로세스** | vitest 안에서 원문 99 줄이 읽혔다. 가로챌 자리가 node 밖이고 경로 리터럴이 필요 없다 |

| **ⓓ ⓔ** | 경계 밖(팀장 승인 2026-11-13). ⓔ 의 그 주석은 추적 파일에서 **0 건** |
| **ⓕ-3 두 글자 토큰** | 오늘 오탐 0. 미래 fixture 의 탈출구는 값 차감뿐이고, 술어를 좁히면 확장자 단독 값과 glob 이 다시 열린다 |

### 「넘긴 함수 안의 변형」은 경계 안인가 — 보고

**둘로 갈린다.**

- **경계 안**: 저자가 추출 전에 텍스트를 **정규화**하는 꼴(공백 정리·줄 끝 통일). 게이트를
  의식하지 않은 평범한 손질이고, 그것이 걷기 보증을 무르게 한다는 것을 저자가 모를 수 있다.
  이 꼴의 **흔한 표기**는 기존 완화 층(주석 표지를 인자로 넘기는 치환·탐색)이 전 추적 파일에서
  든다 — 그래서 「부분」이다.
- **경계 밖**: 걷기를 **다시 구현**하거나 항등 함수로 원문을 빼내는 꼴. 추출과 무관한 수술이고
  목적이 게이트 회피다.

**그래서 ⓒ 는 「등재 유지 + 자리가 좁아졌다」로 적는다.** 앞 판에서는 원문 문자열이 소비자 쪽에
**이름으로 존재**해 어느 줄에서든 손댈 수 있었다. 새 판에서는 이름 붙일 자리가 **넘긴 함수의
매개변수 하나**뿐이고, 그 함수는 diff 에 남는다.

| 입구가 **걷히지 않은** 텍스트를 거부한다 | 입구에 텍스트를 **넘길 자리가 없다** — 커널을 직접 부르면 호출자 프레임이 거부한다(기존 구조 층, 허용 호출자가 읽기 모듈로 바뀐다) |
| 입구가 **가린 원문**(재현 사본)을 거부한다 | 추출의 결과가 **원문 자체이면** 읽기가 거부한다(신설 후조건) |
| 입구가 **합성 텍스트**를 거부한다 | 공개 표면이 **둘**이다(기존 export 집합 등식 — 셋에서 둘로) |
| 모집단 등식(추출 함수 전수가 단언을 부른다) | **없어진다.** 그 질문의 전제(원문을 문자열로 받는 소비자)가 사라진다 — 지우는 사유를 그 자리에 적는다 |

### 12D 와 공유하는 자리 — 기동 비용

`kotlin-source-ownership.test.mjs` 에서 데이터 흐름 기계(모집단 수집 + 선언 호출 표)를 지운다.
