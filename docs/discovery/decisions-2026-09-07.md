# 운영자 결정 기록 — 2026-09-07 (UX 여정 · 학습 가치 · 데이터 위치 후속)

- **지위**: 결정 기록. 세션 모델이 열린 물음을 선택지+추천으로 모아 제시했고, 운영자가 답했다 —
  「Q1.(c) 접속 없이 서버 담당자가 스냅샷을 만들어 전달. 추천대로 결정.」 나머지는 추천안 그대로다.
- **선행 문서**: `docs/discovery/ux-journey-research.md` §9 (D-UX-1~4) ·
  `docs/discovery/ml-value-and-data-locality.md` §4 (D-DL-1~3, D-ML-1~4).
- **이 문서가 하지 않는 것**: 여기 적힌 결정을 milestone·ADR·capability map 에 옮기지 않는다. 옮기는
  시점은 Q-7·Q-8 이 정한다. 각 문서의 정본 지위는 불변이다.

## 이 결정들이 여는 후속 (담당 slice 가 집는다)

- **지금**: 서버 담당자에게 `ml-value-and-data-locality.md` §5 를 반출 계획으로 전달 (Q-1·Q-3). 스냅샷이 오면
  저장소 밖 디렉터리에 두고 manifest·checksum 만 evidence 에 적는다(`data-extract.md` §7).
- **M5 착수 slice**: milestone-5·ADR 0010·capability map 에 D-ML-1~3 반영 (Q-8), 5C 첫 산출물 = 결정 실험 (Q-3).
- **`bidding` 모듈 slice**: `BID-01` 등재 + `ADR 0006` D-2 되살림 + Q-11·Q-12 를 acceptance·정책 데이터로 (Q-7).
- **M6 6A**: 화면 데이터 요구(D-UX-1) 대조, 프런트 스택 판정 (Q-6), `milestone-7.md` 저작과 `ADR 0008` D-1 개정 (Q-4·Q-5).

## 여전히 열린 것

- `OPEN-ADR-09` 의 문면 자체는 capability map §14.3 행이 정본이라 **이 문서가 닫지 않는다** — Q-2·Q-4 의 답을
  그 행에 옮기는 것은 6A(그 행이 지목한 자리)의 몫이다.
- 서버 담당자가 누구이고 스냅샷을 언제 만들 수 있는지는 운영자 밖의 일정이다.
